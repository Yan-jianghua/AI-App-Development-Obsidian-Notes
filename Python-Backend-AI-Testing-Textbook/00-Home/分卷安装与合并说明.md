# 最终整合包安装说明

本项目已经把 Part00–Part09 合并为一个完整压缩包，不需要再下载或合并分卷。

1. 解压最终 ZIP。
2. 得到顶层文件夹 `Python-Backend-AI-Testing-Textbook`。
3. 打开 Obsidian，选择“打开本地仓库”。
4. 选中这个顶层文件夹。
5. 从 [[00-Home/Project Home]] 或 [[00-Home/总导航]] 开始学习。

仓库不包含 `.obsidian` 私有配置，因此不会覆盖你的主题、插件或快捷键。若要放入已有 Vault，可复制顶层文件夹中的课程目录；文件链接全部使用标准 Markdown 与 Wikilink。
