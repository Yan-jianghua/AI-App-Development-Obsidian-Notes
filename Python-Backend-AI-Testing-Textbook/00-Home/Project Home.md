# Python 后端与 AI 应用测试教材

这是一套可直接在 Obsidian 中打开的中文教材型知识库，面向从未系统学习测试的人，也覆盖生产级 Python 后端、LLM、RAG 与 Agent 测试。

## 从这里开始

1. 打开 [[00-Home/总导航]] 选择学习路线。
2. 初学者从 [[01-测试基础与pytest/00-学习导航]] 开始。
3. 每篇笔记完成“动手练习”，不要只阅读。
4. 学完各卷后完成 [[09-CICD与综合实战/02-综合项目/生产级AI后端测试综合项目]]。

## 编写规则

- 一个核心关键词一篇独立笔记。
- 一个重要 Python 包、框架或工具一篇独立笔记。
- 每篇包含白话解释、定义、例子、步骤、常见错误、最佳实践、练习和面试题。
- 所有章节通过 Wikilink 相互连接，不依赖 Obsidian 私有配置。
- 官方资料集中放在 `90-Sources`，工具用法变化时以官方文档为准。

## 重要提示

示例是教学用最小代码。真实项目还要加入权限、隐私、错误处理、资源清理、版本锁定和运行环境隔离。安全与高风险 AI 应用必须由具备领域资质的人复核。
