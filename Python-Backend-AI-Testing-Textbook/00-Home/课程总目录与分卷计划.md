# 课程总目录与分卷计划

> 状态：Part00–Part09 已全部完成并合并。最终仓库共 533 篇受管理 Markdown 笔记，另含 1 份 Forge 检查点，正文规模超过 100 万字符。以下清单既是课程范围，也可作为查漏补缺索引。

## Part01：测试基本概念与 pytest 核心

独立术语：软件测试、测试用例、测试预言、单元测试、集成测试、系统测试、端到端测试、回归测试、冒烟测试、验收测试、正向测试、负向测试、边界值分析、等价类划分、状态转换、决策表、AAA、Given-When-Then、测试金字塔。

pytest 核心：pytest、测试发现、assert、pytest.raises、pytest.approx、pytest.mark.parametrize、Fixture、Fixture scope、yield Fixture、conftest.py、mark、skip、xfail、命令行运行与失败排查。

## Part02：pytest 高级功能与重要测试包

关键词：Mock、Stub、Fake、Spy、Patch、Monkeypatch、依赖注入、时间控制、随机种子、测试数据工厂、属性测试、Shrinking、Snapshot、Golden Test、覆盖率、分支覆盖率、Mutation Testing、并行测试、Flaky Test。

独立包：`unittest`、`unittest.mock`、`pytest-mock`、`freezegun`、`time-machine`、`Faker`、`Factory Boy`、`Hypothesis`、`pytest-cov`、`coverage.py`、`mutmut`、`pytest-xdist`、`pytest-randomly`、`syrupy`、`inline-snapshot`、`tox`、`nox`。

## Part03：Python 后端与 API 测试

关键词：HTTP、REST、请求、响应、状态码、Header、Cookie、JSON、JSON Schema、OpenAPI、ASGI、WSGI、同步、异步、事件循环、生命周期、中间件、依赖覆盖、认证、授权、RBAC、ABAC、JWT、OAuth2、CORS、CSRF、分页、游标、幂等、限流、文件上传、SSE、WebSocket、后台任务、合约测试、E2E。

独立包：`FastAPI`、`Starlette TestClient`、`HTTPX`、`AnyIO`、`pytest-asyncio`、`Pydantic`、`PyJWT/python-jose`、`passlib/bcrypt`、`respx`、`responses`、`tenacity`、`Schemathesis`、`Pact`、`Playwright`、`Celery`、`RQ`、`Dramatiq`。

## Part04：数据库、中间件与基础设施

关键词：CRUD、ORM、Repository、ACID、事务、回滚、隔离级别、并发、死锁、乐观锁、悲观锁、唯一约束、迁移、Expand-Contract、缓存、TTL、缓存穿透/击穿/雪崩、分布式锁、消息确认、幂等消费、死信、Outbox、Saga、最终一致性、对象存储、搜索索引、备份、RPO、RTO。

独立包/系统：`SQLAlchemy`、`Alembic`、`psycopg`、`asyncpg`、`PostgreSQL`、`MySQL`、`SQLite`、`Testcontainers Python`、`redis-py`、`fakeredis`、`RabbitMQ`、`Kafka`、`boto3`、`moto`、`MinIO`、`Elasticsearch/OpenSearch`、`Docker Compose`。

## Part05：AI、机器学习与 LLM 评测

关键词：数据集、训练/验证/测试集、数据泄漏、Accuracy、Precision、Recall、F1、ROC-AUC、PR-AUC、MAE、RMSE、校准、漂移、Prompt、System Prompt、结构化输出、Function Calling、Grader、LLM-as-Judge、人工评测、Pairwise、非确定性、置信区间、Pass@k、幻觉、事实性、拒答、引用、多语言、长上下文、Token、TTFT、成本、微调、多模态。

独立包/平台：`NumPy`、`pandas`、`scikit-learn`、`PyTorch`、`Transformers`、`sentence-transformers`、`OpenAI Python SDK`、`tiktoken`、`MLflow`、`Evidently`、`DeepEval`、`Ragas`、`TruLens`、`LangSmith`、`Langfuse`、`Guardrails AI`、`Presidio`。

## Part06：RAG 与检索系统测试

关键词：解析、OCR、Chunk、Overlap、Metadata、Embedding、向量索引、Cosine Similarity、Top-K、Recall@K、Precision@K、MRR、nDCG、BM25、混合检索、Query Rewrite、Reranker、Context Recall/Precision、Groundedness、Faithfulness、Citation Accuracy、知识新鲜度、数据投毒、间接 Prompt Injection。

独立包/系统：`PyMuPDF`、`pdfplumber`、`Unstructured`、`Tesseract/pytesseract`、`FAISS`、`Chroma`、`Qdrant`、`Milvus`、`Pinecone`、`rank-bm25`、`LlamaIndex`、`LangChain`。

## Part07：Agent、工具调用与多 Agent

关键词：Agent、Tool、Tool Schema、工具选择、参数验证、轨迹、状态机、短期记忆、长期记忆、幂等、副作用、Human-in-the-loop、最小权限、沙箱、预算、终止条件、Tracing、委派、交接、冲突处理、多 Agent。

独立包/框架：`OpenAI Agents SDK`、`LangGraph`、`PydanticAI`、`AutoGen`、`CrewAI`、`smolagents`。

## Part08：安全、性能、可靠性与可观测性

关键词：SAST、DAST、Fuzzing、SSRF、SQL 注入、XSS、命令注入、路径穿越、供应链、SBOM、Load/Stress/Spike/Soak、RPS、P50/P95/P99、Chaos、日志、Metrics、Tracing、告警、Liveness、Readiness、审计日志。

独立包/工具：`Bandit`、`Semgrep`、`pip-audit`、`Gitleaks`、`Trivy`、`OWASP ZAP`、`Locust`、`pytest-benchmark`、`py-spy`、`OpenTelemetry`、`Prometheus Client`、`Sentry SDK`。

## Part09：CI/CD、综合项目与最终索引

关键词：CI、CD、质量门禁、Pre-commit、Lint、类型检查、测试分片、测试工件、Nightly、Shadow、Canary、A/B、Feature Flag、自动回滚、灾难恢复。

独立工具：`GitHub Actions`、`GitLab CI`、`pre-commit`、`Ruff`、`mypy`、`Pyright`、`Docker`。包含从零搭建 FastAPI+PostgreSQL+RAG+Agent 项目的全流程练习、答案思路、面试题、总术语表和最终导航。
