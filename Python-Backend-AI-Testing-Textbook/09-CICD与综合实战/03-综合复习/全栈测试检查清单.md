# 全栈测试检查清单

## 功能与 API

- [ ] 正常、边界、异常、权限和并发路径都有用例。
- [ ] 状态码、Header、响应 schema、持久状态和副作用都有断言。
- [ ] 错误体稳定且不泄露内部堆栈。

## 数据与基础设施

- [ ] 测试数据隔离，事务或临时资源可靠清理。
- [ ] 生产数据库版本有真实集成测试。
- [ ] 缓存、队列、迁移、备份和恢复均有失败路径。

## AI、RAG 与 Agent

- [ ] 数据集版本、模型、Prompt、参数和评分器可追溯。
- [ ] 同时评测平均质量、长尾、高风险和多语言样本。
- [ ] RAG 分层评测解析、召回、排序、生成与引用。
- [ ] Agent 验证轨迹、权限、副作用、预算和停止条件。

## 安全、性能与运维

- [ ] SAST、DAST、依赖、密钥和镜像扫描已接入。
- [ ] 容量目标用 P50、P95、P99、错误率和资源共同描述。
- [ ] 日志脱敏，指标无高基数，Trace 可跨服务关联。
- [ ] 告警可操作，运行手册和回滚演练已验证。

## CI/CD

- [ ] 快速检查优先，昂贵测试分层运行。
- [ ] 所有失败都有负责人、证据和明确处理方式。
- [ ] 构建产物不可变、可追溯、可回滚。
