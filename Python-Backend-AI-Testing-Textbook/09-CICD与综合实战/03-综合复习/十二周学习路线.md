# 十二周学习路线

| 周次 | 学习内容 | 产出 |
|---|---|---|
| 1 | 测试术语、AAA、边界值、pytest | 30 条基础测试 |
| 2 | Fixture、参数化、Mock、属性测试 | 可复用测试夹具 |
| 3 | HTTP、FastAPI、认证授权 | 完整 API 测试套件 |
| 4 | SQLAlchemy、事务、迁移 | 真实数据库集成测试 |
| 5 | Redis、消息队列、对象存储 | 基础设施故障测试 |
| 6 | ML 指标、数据切分、统计 | 可复现模型评测报告 |
| 7 | LLM Grader、安全、多语言 | 黄金数据集与回归门禁 |
| 8 | RAG 解析、召回、排序 | 分层 RAG 评测 |
| 9 | Agent 工具、轨迹、权限 | 工具调用安全测试 |
| 10 | SAST、DAST、Prompt Injection | 威胁模型与安全回归 |
| 11 | 负载、故障、可观测性 | 性能基线与告警 |
| 12 | CI/CD、灰度、综合项目 | 可发布的最终项目 |

每天采用“阅读 30 分钟、运行 30 分钟、独立改写 30 分钟、记录失败 15 分钟”的节奏。若某篇练习无法完成，不急着背答案，先缩小输入并读失败报告。
