# 边界值分析

## 核心思想

Bug 经常出现在允许范围的边缘，例如少一位、多一位、恰好到期。边界值分析专门选择边界附近输入，而不是只测中间值。

## 数值例子

规则：年龄允许 18–60 岁。推荐值：17、18、19、59、60、61。它们分别代表下界外、下界、下界内、上界内、上界、上界外。

```python
@pytest.mark.parametrize(
    "age,allowed",
    [(17, False), (18, True), (19, True), (59, True), (60, True), (61, False)],
)
def test_age_boundary(age, allowed):
    assert can_register(age) is allowed
```

## 其他边界

- 字符串：空、1 个字符、最大长度、超 1 位。
- 集合：0、1、最大容量、超限。
- 时间：到期前一瞬、恰好到期、到期后一瞬。
- 分页：第一页、最后一页、空页、非法页。
- 金额：0、最小货币单位、最大值、精度边界。

## 开区间和闭区间

先写清 `>=` 还是 `>`。规则“满 100 元优惠”包含 100；“超过 100 元”不包含 100。测试恰好等于边界才能发现混淆。

## 常见错误

- 只测 50 这种中间值。
- 说“接近过期”却未固定具体时间。
- 忘记浮点精度和时区。
- 只测上界不测下界。

## 练习与面试题

练习：密码长度 8–64，列出最小边界测试集。

面试：为什么边界值通常比随机中间值更容易发现 Bug？
