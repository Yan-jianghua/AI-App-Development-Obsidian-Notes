# 决策表测试

## 定义

决策表把多个条件组合和对应动作放进表格，适合折扣、权限、风控等组合规则。

## 示例

规则：VIP 且订单满 100 元享八折；有优惠券再减 10 元，但实付不能为负。

| VIP | 满100 | 有券 | 结果 |
|---|---|---|---|
| 否 | 否 | 否 | 原价 |
| 否 | 是 | 是 | 原价减10 |
| 是 | 否 | 是 | 原价减10 |
| 是 | 是 | 否 | 八折 |
| 是 | 是 | 是 | 八折后减10 |

```python
@pytest.mark.parametrize(
    "vip,total,coupon,expected",
    [
        (False, 80, False, 80),
        (False, 120, True, 110),
        (True, 80, True, 70),
        (True, 120, False, 96),
        (True, 120, True, 86),
    ],
)
def test_discount_rules(vip, total, coupon, expected):
    assert price(vip, total, coupon) == expected
```

## 设计方法

列出条件、可能值、动作，删除业务上不可能或等价的组合；对高风险组合保留明确用例。条件很多时可结合 Pairwise，但安全规则不能仅靠抽样。

## 常见错误

- 表中遗漏一个条件，导致规则理解不同。
- 没写条件优先级，例如先打折还是先减券。
- 把“不适用”误写成否。

## 练习与面试题

练习：用角色、资源所有权、资源状态三个条件制作权限决策表。

面试：决策表最适合解决什么类型的测试问题？
