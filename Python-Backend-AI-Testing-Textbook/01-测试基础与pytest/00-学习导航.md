# Part01 测试基础与 pytest 核心学习导航

## 本卷目标

本卷假设你会最基础的 Python 变量、函数和 `if`，但没有学过测试。完成后，你应该能够解释常见测试术语，安装 pytest，写出正常、异常、边界、参数化和 Fixture 测试，并看懂测试失败报告。

## 推荐练习项目

创建一个 `calculator.py`，实现加、除法和折扣计算；使用本卷知识覆盖正常输入、除零异常、边界、参数化和 Fixture。不要直接复制答案，每写一项先预测测试结果。
