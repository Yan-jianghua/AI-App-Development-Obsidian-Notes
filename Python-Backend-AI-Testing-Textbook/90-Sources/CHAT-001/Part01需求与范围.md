# CHAT-001 Part01 需求与范围记录

## 用户要求

用户指出旧版笔记粒度不足，要求即使没有学习过的人也能看懂；每个关键字、每个重要包单独建立笔记；每篇提供例子，达到可以当教材使用的级别。

## 本卷边界

Part01 只处理测试基本概念、测试设计方法、Python 测试环境准备和 pytest 核心功能。Mock、属性测试、覆盖率、并行测试和相关第三方包延期到 Part02，以保证每篇正文完整而不是再次压缩。

## 落实方式

- 一个术语或功能一个稳定 `knowledge_id`。
- 白话解释后再给专业定义。
- 代码主题至少一个可运行或接近可运行的最小示例。
- 解释代码与结果，不只展示代码。
- 包含常见错误、最佳实践、练习和面试问题。
