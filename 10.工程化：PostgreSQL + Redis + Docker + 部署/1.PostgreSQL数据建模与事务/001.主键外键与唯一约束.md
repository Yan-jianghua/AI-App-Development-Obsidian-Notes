# 主键外键与唯一约束

## 是什么

主键标识实体，外键维护引用关系，唯一约束防止业务重复。应用层先检查再写入不能替代数据库约束，因为并发请求可能同时通过检查。

## 实践步骤

为用户、租户、消息、文档和任务明确内部 ID 与外部 ID；幂等键、来源 ID 等设置组合唯一约束。迁移前检查旧数据冲突。

## 容易错与验收

测试并发插入、跨租户重复键与软删除后的唯一性规则。
