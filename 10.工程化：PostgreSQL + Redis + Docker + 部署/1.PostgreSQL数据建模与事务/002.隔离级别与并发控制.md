# 隔离级别与并发控制

## 是什么

事务隔离控制并发可见性；常见异常包括丢失更新、不可重复读与写偏差。不要假设加了事务就自动没有竞争。

## 实践步骤

为业务不变量选择唯一约束、乐观锁、行锁或更高隔离级别；缩短事务时间，死锁和序列化失败做有界重试。

## 容易错与验收

用并发测试验证库存、余额、任务领取等不变量；外部 API 调用不应夹在长事务中。
