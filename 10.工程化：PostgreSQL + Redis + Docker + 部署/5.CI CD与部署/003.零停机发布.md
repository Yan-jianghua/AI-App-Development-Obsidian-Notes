# 零停机发布

## 是什么

零停机发布需要旧新版本同时兼容数据、API 和消息格式。

## 何时用、怎么做

先完成兼容迁移，再逐步切换流量并观察错误率与延迟。

## 易错点与验收

若数据库结构只适配新版本，回滚应用也可能失败。

## 自测
