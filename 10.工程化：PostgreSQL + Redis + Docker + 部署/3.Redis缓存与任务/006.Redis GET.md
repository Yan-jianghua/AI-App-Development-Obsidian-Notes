# Redis GET

## 含义

GET 读取字符串键，不存在时返回空结果。

## 最小用法

`GET job:42`

## 易错点

未命中不等于上游数据不存在，需区分缓存缺失与业务不存在。

## 检查自己是否掌握

改动示例中的一个输入或条件，预测结果，再用真实环境核对。解释这个术语与同章节相邻术语的区别。
