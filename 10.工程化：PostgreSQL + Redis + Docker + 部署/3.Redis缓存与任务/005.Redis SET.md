# Redis SET

## 含义

SET 写入字符串值，可带 NX 与 EX 等条件和过期选项。

## 最小用法

`SET job:42 running NX EX 60`

## 易错点

写入已存在键可能覆盖并移除旧过期时间，按需求显式设置。

## 检查自己是否掌握

改动示例中的一个输入或条件，预测结果，再用真实环境核对。解释这个术语与同章节相邻术语的区别。
