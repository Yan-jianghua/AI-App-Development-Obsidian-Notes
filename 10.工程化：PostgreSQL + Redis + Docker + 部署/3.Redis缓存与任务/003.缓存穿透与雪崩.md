# 缓存穿透与雪崩

## 是什么

穿透是大量查询不存在的键，雪崩是大量缓存同时过期或不可用。

## 何时用、怎么做

对不存在结果短暂缓存，过期时间加抖动，并限制回源并发。

## 易错点与验收

缓存故障时数据库能否承受回源流量需压测。
