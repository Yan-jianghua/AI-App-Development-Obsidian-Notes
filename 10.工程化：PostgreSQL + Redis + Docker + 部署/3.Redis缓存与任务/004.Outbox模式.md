# Outbox模式

## 是什么

Outbox 将业务状态变化与待发事件写入同一数据库事务，再异步投递。

## 何时用、怎么做

消费者以事件 ID 去重并接受至少一次投递，监控积压和失败重试。

## 易错点与验收

直接先提交数据库再发消息会产生双写不一致窗口。
