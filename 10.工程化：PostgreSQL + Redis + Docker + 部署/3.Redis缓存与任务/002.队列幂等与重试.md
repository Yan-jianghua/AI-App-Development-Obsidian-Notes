# 队列幂等与重试

## 是什么

后台队列通常提供至少一次投递，消费者可能重复执行。业务层应设计幂等、超时、重试和死信处理。

## 实践步骤

任务携带唯一 ID、版本、截止时间与尝试次数；消费者用数据库唯一约束或任务状态防重。可重试错误退避，永久错误进死信并可人工处理。

## 容易错与验收

测试宕机时刻、消息乱序、外部调用超时与重复扣费；不要假设队列自然保证 exactly-once。
