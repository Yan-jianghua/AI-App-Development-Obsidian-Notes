# Redis TTL

## 含义

TTL 返回键剩余过期秒数，并用特殊值表示不存在或无过期。

## 最小用法

`TTL job:42`

## 易错点

监控逻辑要区分无过期与已删除状态。

## 检查自己是否掌握

改动示例中的一个输入或条件，预测结果，再用真实环境核对。解释这个术语与同章节相邻术语的区别。
