# 缓存键与失效

## 是什么

缓存减少读延迟，但错误的键或失效策略可能返回跨用户、过期或撤权后的数据。

## 实践步骤

键包含租户、权限范围、版本与查询参数；设置合理 TTL，写入后主动失效。缓存未命中、击穿和雪崩可用限流、抖动 TTL 与单飞策略缓解。

## 容易错与验收

测试授权变更、数据更新、多租户同名键与 Redis 故障；缓存故障不能破坏核心正确性。
