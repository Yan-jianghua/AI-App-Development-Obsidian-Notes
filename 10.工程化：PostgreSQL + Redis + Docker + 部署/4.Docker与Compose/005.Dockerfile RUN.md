# Dockerfile RUN

## 含义

RUN 在镜像构建时执行命令，结果进入镜像层。

## 最小用法

`RUN python -m pip install -r requirements.txt`

## 易错点

构建命令不要写入长期秘密，注意缓存和层体积。

## 检查自己是否掌握

改动示例中的一个输入或条件，预测结果，再用真实环境核对。解释这个术语与同章节相邻术语的区别。
