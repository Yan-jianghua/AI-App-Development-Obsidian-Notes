# Dockerfile USER

## 含义

USER 设置后续构建指令和运行阶段的默认用户。

## 最小用法

`USER app`

## 易错点

非 root 用户仍需对所需目录有正确读写权限。

## 检查自己是否掌握

改动示例中的一个输入或条件，预测结果，再用真实环境核对。解释这个术语与同章节相邻术语的区别。
