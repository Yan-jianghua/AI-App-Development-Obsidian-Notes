# Dockerfile FROM

## 含义

FROM 选择构建阶段的基础镜像，可建立多阶段构建。

## 最小用法

`FROM python:3 AS build`

## 易错点

生产构建应固定可信镜像版本或摘要。

## 检查自己是否掌握

改动示例中的一个输入或条件，预测结果，再用真实环境核对。解释这个术语与同章节相邻术语的区别。
