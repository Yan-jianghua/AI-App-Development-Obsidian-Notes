# Dockerfile COPY

## 含义

COPY 把构建上下文中的文件放进镜像。

## 最小用法

`COPY pyproject.toml /app/`

## 易错点

不要将 .env 和私钥复制入镜像，检查 .dockerignore。

## 检查自己是否掌握

改动示例中的一个输入或条件，预测结果，再用真实环境核对。解释这个术语与同章节相邻术语的区别。
