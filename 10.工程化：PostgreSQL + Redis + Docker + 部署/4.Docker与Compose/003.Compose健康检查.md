# Compose健康检查

## 是什么

Compose 能声明服务依赖和健康检查，但健康代表什么由应用定义。

## 何时用、怎么做

数据库可检查连接，API 可区分存活与就绪，部署脚本等待就绪后发流量。

## 易错点与验收

仅检查进程存在不能证明迁移完成或依赖可用。

## 自测
