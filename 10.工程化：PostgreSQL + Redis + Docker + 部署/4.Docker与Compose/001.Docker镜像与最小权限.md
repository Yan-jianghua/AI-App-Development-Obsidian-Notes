# Docker镜像与最小权限

## 是什么

镜像把应用和依赖打包为可重复运行的环境；Compose 用于组合本地服务。容器隔离不是安全边界的全部。

## 实践步骤

锁定依赖与基础镜像版本，使用多阶段构建、非 root 用户、只读文件系统和最小端口暴露。密钥由运行环境注入，不写进镜像层。

## 容易错与验收

扫描依赖漏洞，验证镜像可从零启动、健康检查有效且无开发密码。
