# 多阶段构建

## 是什么

多阶段构建用构建阶段安装依赖和编译，再仅把运行所需内容复制到运行镜像。

## 何时用、怎么做

固定基础镜像来源并审计依赖，运行阶段使用非 root 用户。

## 易错点与验收

镜像变小不等于安全，仍需扫描漏洞与验证启动。

## 自测

用本节的场景举一个正常用例、一个边界用例和一个失败用例；说明你会观察哪些结果或指标来判断实现正确。
