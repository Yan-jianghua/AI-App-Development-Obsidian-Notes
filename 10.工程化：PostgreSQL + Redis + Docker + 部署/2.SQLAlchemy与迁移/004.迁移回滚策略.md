# 迁移回滚策略

## 是什么

数据库迁移可能包含无法轻易逆转的数据变化，发布时需考虑旧新版本并存。

## 何时用、怎么做

先扩展兼容列，再双写或回填，确认稳定后收缩旧字段。

## 易错点与验收

不能仅靠反向 SQL 证明可回滚，备份与恢复演练同样必要。

## 自测

用本节的场景举一个正常用例、一个边界用例和一个失败用例；说明你会观察哪些结果或指标来判断实现正确。
