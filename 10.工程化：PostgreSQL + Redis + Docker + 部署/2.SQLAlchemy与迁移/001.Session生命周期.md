# Session生命周期

## 是什么

数据库 Session 表示一次工作单元，包含对象状态与事务边界；不应作为跨请求共享的全局对象。

## 实践步骤

按请求或业务操作创建 Session，成功提交，异常回滚，最后关闭。异步 Session 与同步 Session 不混用；延迟加载需注意连接已关闭的情况。

## 容易错与验收

测试异常路径连接是否归还、事务是否回滚、测试之间是否互相污染。
