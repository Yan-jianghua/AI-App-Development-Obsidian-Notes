# N加一查询

## 是什么

读取一组父对象后逐个读取子对象会产生随数据量增长的查询次数。

## 何时用、怎么做

用明确的预加载策略与查询计数测试，必要时做分页。

## 易错点与验收

盲目 JOIN 大集合也会放大行数，比较返回量和延迟。
