# AsyncSession

## 含义

AsyncSession 是 SQLAlchemy 异步 ORM 会话，封装事务和身份映射。

## 最小用法

`每个并发任务使用独立会话并明确提交或回滚`

## 易错点

同一 AsyncSession 不能跨并发任务共享。
