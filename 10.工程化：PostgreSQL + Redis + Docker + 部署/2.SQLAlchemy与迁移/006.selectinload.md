# selectinload

## 含义

selectinload 通过额外的批量 SELECT 预加载关系，常用于减少 N 加一查询。

## 最小用法

`查询父对象时显式声明 selectinload 对应关系`

## 易错点

仍需检查实际 SQL 次数与大集合内存。
