# 路由、依赖注入与中间件

## APIRouter 拆分模块

```python
from fastapi import APIRouter

router = APIRouter(prefix="/notes", tags=["notes"])

@router.get("")
async def list_notes() -> list[dict]:
    return []
```

在应用工厂或 `main.py` 中 `include_router`。版本前缀如 `/api/v1` 应统一配置，避免散落在每个端点。

## 依赖注入

依赖是请求处理前需要得到的值或执行的检查，例如当前用户、数据库会话、分页参数和业务服务。

```python
from typing import Annotated
from fastapi import Depends

def get_note_service() -> "NoteService":
    return NoteService()

NoteServiceDep = Annotated["NoteService", Depends(get_note_service)]

@router.get("/{note_id}")
async def get_note(note_id: int, service: NoteServiceDep):
    return await service.get(note_id)
```

使用 `yield` 的依赖可在请求后清理数据库会话。测试可覆盖依赖，替换为 fake 或测试数据库。依赖不要暗中做过多工作，否则执行顺序、缓存和异常难以理解。

## 中间件

中间件包围整个请求，适合 request ID、耗时、统一 Header、追踪和 CORS。业务权限通常更适合作为显式依赖，因为每条路由的要求不同且更易测试。

```text
请求 → 外层中间件 → 内层中间件 → 路由依赖 → 端点
响应 ← 外层中间件 ← 内层中间件 ← 路由依赖清理
```

## 分页与过滤

列表接口应限制 `limit` 上限。偏移分页易用但大偏移变慢且并发插入会造成漂移；游标分页使用稳定排序键，适合持续增长的数据。任何排序字段都应使用白名单，不能把用户输入直接拼入 SQL。

## OpenAPI 与版本

为端点填写摘要、响应模型、错误响应和弃用信息。破坏兼容的字段变化应通过新版本或迁移期发布；新增可选字段通常更安全，但客户端也应忽略未知字段。

## 常见错误

- 在中间件读取流式 Body 后未正确转发。
- 依赖返回单例可变对象，导致请求间数据串扰。
- 只在界面隐藏按钮，不在 API 做授权。
- 在路由中直接拼 SQL 或调用多个外部服务，无法独立测试。

## 练习

实现一个分页依赖、当前用户依赖和管理员依赖；在测试中覆盖当前用户依赖，验证普通用户不能访问管理路由。
