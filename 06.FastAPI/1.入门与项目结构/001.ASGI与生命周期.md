# ASGI与生命周期

## 是什么

ASGI 是 Python 异步 Web 服务的应用接口；FastAPI 应用由 ASGI 服务器承载，请求通过中间件、路由、依赖与响应链。生命周期负责启动/关闭共享资源。

## 实践步骤

启动时建立数据库连接池、HTTP 客户端或模型客户端；关闭时释放。用 lifespan 管理资源，避免模块导入时连接外部服务。健康检查区分进程存活与依赖就绪。

## 容易错与验收

测试启动失败、优雅停机与在途请求；不要在每次请求新建连接池。
