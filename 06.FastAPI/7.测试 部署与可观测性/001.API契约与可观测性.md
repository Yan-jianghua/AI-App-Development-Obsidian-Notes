# API契约与可观测性

## 是什么

API 契约包括状态码、错误体、分页、幂等与版本；可观测性要让用户报错能定位到请求与下游依赖。

## 实践步骤

对关键路由做契约测试和 OpenAPI 检查；日志使用 request ID、租户/用户标识的脱敏版本与错误类别。指标观察成功率、P95、连接池、任务队列与模型调用。

## 容易错与验收

测试发布前后的兼容性、限流和故障告警；不要把 Prompt、令牌或个人信息原样写入追踪。
