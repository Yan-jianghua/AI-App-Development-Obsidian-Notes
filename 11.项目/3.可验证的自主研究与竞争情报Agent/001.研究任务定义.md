# 研究任务定义

## 是什么与为什么

研究任务应先确定问题、范围、时间窗口、允许来源、交付对象和停止条件。模糊目标会让 Agent 无限搜索或输出不可核验的结论。

## 实现要点

用结构化任务保存主题、地区/行业、必须回答的问题、预算、截止时间、来源许可及禁用动作。将用户原话和澄清后的范围同时保存；可变更范围，但每次变更要留版本。

## 边界、测试与验收

验收看任务是否有明确完成定义：覆盖哪些问题、每项需要多少独立来源、何时可说证据不足。测试模糊、矛盾、超预算和高风险请求。

## 动手练习

把“研究竞争对手”改写成包含地区、时间、五个问题、允许来源和预算的任务；对无法确认的范围提出澄清问题。

把输入、预期、实际结果、版本和失败样本写入测试记录；只有可重复运行才算掌握。
