# Checkpoint与可恢复执行

## 是什么与为什么

Checkpoint 保存 Agent 的任务状态，使长流程在超时、进程重启和人工审批后可继续，而非从头运行。

## 实现要点

持久化任务 ID、节点状态、输入输出引用、工具调用结果、版本、预算与待审批动作；节点以幂等键避免重复外部副作用。恢复时检查代码、Prompt 和工具版本兼容性。

## 边界、测试与验收

不要把密钥或大原文直接塞入状态快照。故障注入测试节点执行前、中、后宕机与重复投递，验证恢复后证据和费用不重复。

## 动手练习

在检索成功但状态尚未提交时终止进程，然后恢复任务；检查同一来源没有被重复付费抓取，任务结果仍完整。

把输入、预期、实际结果、版本和失败样本写入测试记录；只有可重复运行才算掌握。
