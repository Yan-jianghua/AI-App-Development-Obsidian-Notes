# 工具沙箱

## 是什么与为什么

工具沙箱限制 Agent 的网络、文件、代码与浏览器能力，防止外部网页通过间接提示注入诱导越权操作。

## 实现要点

工具以最小权限声明域名、方法、参数 Schema、速率、资源限制和审计字段。抓取内容一律当作不可信数据；代码执行与主服务隔离，并限制 CPU、内存、时间、文件系统和网络。

## 边界、测试与验收

测试访问禁用域、私网地址、文件路径穿越、恶意重定向及超大响应。任何写入外部系统、发消息或支付动作都需要独立授权与人工确认。

## 动手练习

让工具尝试访问私网地址、读取本地密钥、执行超时脚本和访问未授权域名，确认每种行为被独立阻断并记录。

把输入、预期、实际结果、版本和失败样本写入测试记录；只有可重复运行才算掌握。
