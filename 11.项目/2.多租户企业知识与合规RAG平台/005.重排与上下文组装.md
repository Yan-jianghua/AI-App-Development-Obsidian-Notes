# 重排与上下文组装

## 是什么与为什么

重排器对初召回候选重新排序；上下文组装决定最终给模型哪些证据、以什么顺序和粒度。两者影响答案质量、时延与成本。

## 实现要点

先召回较多候选，再对授权且去重的片段重排。上下文按主题与原文顺序适度合并，附来源 ID、文档版本、页码/段落和时间。为系统指令、问题、证据、回答各预留 token 预算。

## 边界、测试与验收

重排不能引入未授权文档；跨页拼接要避免抹掉条件句。监控重排前后命中率、P95 增量和 token 成本。缺关键证据时拒答或澄清，不强行填满上下文。

## 动手练习

固定 20 条初召回候选，比较重排前后前五条证据的命中率、总 token 和 P95；缺关键限定句时应拒答。

把输入、预期、实际结果、版本和失败样本写入测试记录；只有可重复运行才算掌握。
