# 可验证引用

## 是什么与为什么

引用不是模型输出的 `[1]` 字符串，而是指向本次授权检索结果中真实存在的文档版本和段落。用户应能打开并核对原文。

## 实现要点

服务端维护证据 ID 到文档、版本、位置的映射；生成后检查引用 ID 存在、仍有权限、所述事实与原段落有关。引用链接再次鉴权，不把永久公开 URL 当作证据。对关键结论要求逐句来源。

## 边界、测试与验收

测试伪造引用、引用错位、断章取义、文档更新、权限撤销和链接过期。无法核验的句子标成推断或删除；不要只检查引用数量。

## 动手练习

让模型故意引用不存在的 D99、引用过期版本和引用错误段落。服务端应剔除或标记问题，用户点击合法引用能看到确切原文。

把输入、预期、实际结果、版本和失败样本写入测试记录；只有可重复运行才算掌握。
