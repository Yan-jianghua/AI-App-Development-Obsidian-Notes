# Agent运行时

## 是什么与为什么

Agent 运行时提供状态、工具注册、任务调度、人工审批、重试和超时的统一执行环境，使各业务 Agent 不重复造基础设施。

## 实现要点

运行实例保存工作流版本、步骤输入输出、工具调用、预算与审批状态。工具声明权限、参数 Schema、幂等性和副作用等级；执行引擎按策略决定同步、异步或人工接管。长期任务用 checkpoint 恢复。

## 边界、测试与验收

测试循环规划、工具超时、审批过期、执行节点重启和重复消息。运行时必须有硬停止条件和总预算，不允许 Agent 无限自主执行。

## 动手练习

注册只读查询和需审批发信两个工具，让 Agent 连续调用、超时并重启；验证预算上限和发信幂等。

把输入、预期、实际结果、版本和失败样本写入测试记录；只有可重复运行才算掌握。
