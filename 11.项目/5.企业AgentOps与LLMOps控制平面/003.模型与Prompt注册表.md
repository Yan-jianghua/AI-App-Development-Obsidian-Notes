# 模型与Prompt注册表

## 是什么与为什么

注册表保存模型能力、版本、供应商、价格与限制，以及 Prompt 模板、变量、输出 Schema、评测结果和使用者。它是可审计的发布源。

## 实现要点

版本应不可变；新版本产生新 ID，绑定模型参数和依赖工具版本。记录创建者、审批者、生效范围、发布时间与回滚目标。下线版本要处理已有运行任务与可复现性。

## 边界、测试与验收

测试引用不存在版本、意外覆盖、跨租户可见、回滚后缓存污染。不能用“latest”作长期生产依赖而没有锁定规则。

## 动手练习

发布 Prompt v1/v2，尝试覆盖已发布的 v1 和引用不存在版本；应拒绝覆盖，并能按请求追溯实际版本。

把输入、预期、实际结果、版本和失败样本写入测试记录；只有可重复运行才算掌握。
