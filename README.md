## 如何阅读

- 在 GitHub 上从 [总目录](00.首页/目录.md)进入，按主题浏览 Markdown 文件。部分笔记使用 Obsidian 的 `[[双向链接]]`，在 GitHub 上不会转换为可点击链接。
- 在 Obsidian 中选择“打开文件夹为库”，选取本仓库文件夹，即可使用双向链接浏览主笔记。`Python-Backend-AI-Testing-Textbook` 也可以按其[使用说明](Python-Backend-AI-Testing-Textbook/README-START-HERE.md)单独作为一个库打开。

Obsidian 的本地设置和插件目录 `.obsidian/` 已排除在版本控制之外，打开笔记不需要安装仓库中的插件。
