# 生成器和迭代器的关系

整个关系非常重要：

```text
可迭代对象
Iterable
    ↓
iter()
    ↓
迭代器
Iterator
    ↓
next()
    ↓
获取数据
```

生成器：

```text
生成器
Generator
↓
本身就是一种特殊的迭代器
↓
可以直接 next()
```

例如：

```python
def number():
    yield 1
    yield 2

g = number()
```

可以直接：

```python
next(g)
```

不需要：

```python
iter(g)
```

才能使用。
