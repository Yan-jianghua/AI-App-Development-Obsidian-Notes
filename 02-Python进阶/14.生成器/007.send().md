# `send()`

`send()` 是生成器的高级操作。

普通：

```python
next(g)
```

只能告诉生成器：

> 继续运行。

而：

```python
g.send(value)
```

不仅可以让生成器继续运行，还可以：

> **向生成器内部传入一个值。**

---

## 典型例子

```python
def test():
    value = yield 10

    print("收到：", value)

    yield 20
```

创建：

```python
g = test()
```

首先：

```python
print(next(g))
```

结果：

```text
10
```

程序暂停在：

```python
value = yield 10
```

然后：

```python
g.send("hello")
```

这里的：

```text
"hello"
```

会成为：

```python
yield 10
```

这个表达式的结果。

所以：

```python
value = "hello"
```

于是输出：

```text
收到： hello
```

然后继续运行到：

```python
yield 20
```

---

## 理解关键

看到：

```python
value = yield 10
```

可以理解成两个阶段。

第一阶段：

```text
yield 10
↓
向外返回 10
↓
暂停
```

第二阶段：

```python
send("hello")
↓
"hello" 传回来
↓
value = "hello"
```

---

### `next()` 与 `send()`

```python
next(g)
```

可以近似理解成：

```python
g.send(None)
```

---

### 注意

刚创建的生成器：

```python
g = test()
```

通常不能直接：

```python
g.send("hello")
```

需要先启动：

```python
next(g)
```

然后才能发送真正的数据。

### 记忆

```text
next()
→ 继续运行

send(value)
→ 继续运行 + 向生成器发送数据
```
