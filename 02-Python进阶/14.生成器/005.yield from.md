# `yield from`

`yield from` 用于：

> 从另一个可迭代对象或生成器中连续产生数据。

例如：

```python
def number():
    yield from [1, 2, 3]
```

相当于：

```python
def number():
    for x in [1, 2, 3]:
        yield x
```

---

使用：

```python
for x in number():
    print(x)
```

结果：

```text
1
2
3
```

---

## 普通 `yield`

```python
yield [1, 2, 3]
```

产生的是：

```text
[1, 2, 3]
```

整个列表。

而：

```python
yield from [1, 2, 3]
```

产生：

```text
1
2
3
```

每个元素。

---

### 对比

```python
yield [1, 2, 3]
```

相当于：

```text
产生一次
↓
[1, 2, 3]
```

而：

```python
yield from [1, 2, 3]
```

相当于：

```text
yield 1
yield 2
yield 3
```

### 记忆

```text
yield
→ 产生一个值

yield from
→ 从另一个可迭代对象中逐个产生值
```
