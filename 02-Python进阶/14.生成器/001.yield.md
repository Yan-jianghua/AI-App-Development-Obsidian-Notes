## `yield`

### 作用

`yield` 用于创建**生成器函数**。

普通函数使用：

```python
return
```

返回结果后，函数直接结束。

生成器函数使用：

```python
yield
```

返回一个值之后，函数会**暂停**，并保存当前运行状态。

下一次继续执行时，会从上一次 `yield` 后面继续。

---

### 典型例子

```python
def number():
    yield 1
    yield 2
    yield 3
```

调用：

```python
g = number()
```

此时：

```python
print(g)
```

得到的不是：

```text
1
2
3
```

而是一个：

```text
generator
```

也就是**生成器对象**。

需要使用：

```python
next(g)
```

才能一个一个取值。

```python
print(next(g))
print(next(g))
print(next(g))
```

结果：

```text
1
2
3
```

---

### 执行过程

第一次：

```python
next(g)
```

执行：

```python
yield 1
```

返回：

```text
1
```

然后暂停。

第二次：

```python
next(g)
```

从：

```python
yield 1
```

后面继续运行，直到：

```python
yield 2
```

返回：

```text
2
```

然后再次暂停。

---

### `yield` 和 `return` 的区别

|`return`|`yield`|
|---|---|
|返回结果|返回一个值|
|函数结束|函数暂停|
|状态不会继续保留|保存当前执行状态|
|普通函数|生成器函数|

### 记忆

```text
return
→ 返回并结束

yield
→ 返回并暂停
```

> [!IMPORTANT]  
> 函数中只要出现 `yield`，这个函数就不再是普通函数，而是**生成器函数**。
