# `StopIteration`

当迭代器已经没有数据时，再调用：

```python
next()
```

Python 会抛出：

```python
StopIteration
```

例如：

```python
data = iter([1, 2])

print(next(data))
print(next(data))
print(next(data))
```

前两次：

```text
1
2
```

第三次：

```text
StopIteration
```

因为已经没有下一个元素。

---

## 生成器同样如此

```python
def number():
    yield 1
    yield 2
```

```python
g = number()

next(g)
next(g)
next(g)
```

第三次同样产生：

```text
StopIteration
```

---

## 为什么 `for` 不会报错？

例如：

```python
for x in [1, 2, 3]:
    print(x)
```

底层可以简单理解为：

```python
it = iter([1, 2, 3])

while True:
    try:
        x = next(it)
        print(x)

    except StopIteration:
        break
```

也就是说：

> `for` 会自动捕获 `StopIteration`，然后结束循环。
