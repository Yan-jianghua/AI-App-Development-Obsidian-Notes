# Generator Expression

Generator Expression 中文：

**生成器表达式**

它可以理解为：

> 列表推导式的生成器版本。

列表推导式：

```python
nums = [x * x for x in range(5)]
```

生成：

```python
[0, 1, 4, 9, 16]
```

生成器表达式：

```python
nums = (x * x for x in range(5))
```

注意区别：

```text
[]
→ 列表推导式

()
→ 生成器表达式
```

---

## 使用

```python
g = (x * x for x in range(5))

print(next(g))
print(next(g))
```

结果：

```text
0
1
```

---

## 最大区别

列表推导式：

```python
[x * x for x in range(1000000)]
```

会直接创建：

```text
1000000 个结果
```

保存到内存。

生成器表达式：

```python
(x * x for x in range(1000000))
```

不会立即计算全部数据。

而是：

```text
需要一个
↓
计算一个
```

所以更加节省内存。

---

### 记忆

```text
[]
→ 列表推导式
→ 一次性创建全部数据

()
→ 生成器表达式
→ 用一个算一个
```

> [!IMPORTANT]  
> 处理大量数据时，生成器最大的优势就是**节省内存**。
