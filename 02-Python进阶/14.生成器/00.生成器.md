## 什么是生成器

**生成器是一种“边用边生成数据”的特殊迭代器。**

普通列表会先把所有数据一次性创建出来：

```
nums = [1, 2, 3, 4, 5]
```

而生成器不会一次性把所有数据放进内存，而是：

> 需要一个 → 生成一个 → 暂停 → 下次继续生成。

所以生成器特别适合：

- 大量数据
- 文件逐行读取
- 数据流处理
- AI / 后端中的批量数据处理
- 不想一次性占用太多内存的场景

---

## 2. 生成器最核心的关键字：`yield`

只要一个函数中出现：

```
yield
```

这个函数就不再是普通函数，而是一个**生成器函数**。

例如：

```
def my_generator():
    yield 1
    yield 2
    yield 3
```

调用：

```
g = my_generator()

print(g)
```

此时**不会执行函数体**，而是得到一个生成器对象：

```
<generator object my_generator ...>
```

---

## 3. 怎么取生成器里的数据

使用：

```
next()
```

例如：

```
def my_generator():
    yield 1
    yield 2
    yield 3


g = my_generator()

print(next(g))
print(next(g))
print(next(g))
```

结果：

```
1
2
3
```

执行过程实际上是：

```
next(g)
↓
执行到 yield 1
↓
返回 1
↓
暂停

next(g)
↓
从上次暂停的位置继续
↓
执行到 yield 2
↓
返回 2
↓
再次暂停
```

这就是生成器最核心的特点：

> **`yield` 不只是返回数据，还会保存函数当前的运行状态。**
