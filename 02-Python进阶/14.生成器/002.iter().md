# `iter()`

`iter()` 用于：

> **获取一个对象的迭代器。**

例如：

```python
data = [10, 20, 30]
```

列表本身是：

```text
可迭代对象
```

使用：

```python
it = iter(data)
```

得到：

```text
迭代器对象
```

然后：

```python
print(next(it))
print(next(it))
```

结果：

```text
10
20
```

---

## 可迭代对象和迭代器

例如：

```python
list
tuple
str
dict
set
```

都属于：

```text
Iterable
可迭代对象
```

可以：

```python
for x in data:
    ...
```

但不一定可以直接：

```python
next(data)
```

例如：

```python
data = [1, 2, 3]

next(data)
```

会报错。

需要：

```python
it = iter(data)

next(it)
```
