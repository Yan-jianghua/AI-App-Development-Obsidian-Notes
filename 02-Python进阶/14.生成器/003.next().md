# `next()`

`next()` 用于：

> 从迭代器或生成器中获取**下一个值**。

例如：

```python
data = [10, 20, 30]

it = iter(data)

print(next(it))
print(next(it))
print(next(it))
```

结果：

```text
10
20
30
```

每执行一次：

```python
next(it)
```

迭代器都会向后移动一次。

---

## 生成器中

```python
def number():
    yield 10
    yield 20
    yield 30
```

创建：

```python
g = number()
```

调用：

```python
next(g)
```

生成器运行到：

```python
yield 10
```

然后返回：

```text
10
```

再次：

```python
next(g)
```

从上次暂停的位置继续。
