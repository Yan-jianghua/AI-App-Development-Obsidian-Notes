# `close()`

`close()` 用于：

> **提前关闭生成器。**

例如：

```python
def number():
    yield 1
    yield 2
    yield 3
```

```python
g = number()

print(next(g))

g.close()
```

此时已经关闭生成器。

再执行：

```python
next(g)
```

会产生：

```text
StopIteration
```

---

## 使用场景

例如生成器正在：

```text
读取大量数据
处理文件
持续产生任务
处理数据流
```

如果不再需要继续生成数据，可以：

```python
g.close()
```

提前结束。

### 记忆
