# `itertools`

`itertools` 是 Python 标准库中的：

> **迭代器工具模块。**

它提供了很多处理：

```text
迭代器
生成器
数据流
组合数据
```

的工具。

导入：

```python
import itertools
```

---

## 常见方法

### `count()`

创建无限计数器。

```python
from itertools import count

for x in count(1):
    print(x)
```

会不断产生：

```text
1
2
3
4
5
...
```

所以一般需要配合停止条件。

---

### `cycle()`

不断循环一个可迭代对象。

```python
from itertools import cycle

c = cycle(["A", "B", "C"])
```

不断产生：

```text
A
B
C
A
B
C
...
```

---

### `repeat()`

重复一个值。

```python
from itertools import repeat

for x in repeat("hello", 3):
    print(x)
```

结果：

```text
hello
hello
hello
```

---

### `chain()`

把多个可迭代对象连接起来。

```python
from itertools import chain

data = chain([1, 2], [3, 4])
```

产生：

```text
1
2
3
4
```

---

### `islice()`

对迭代器进行类似切片的操作。

```python
from itertools import islice

data = range(100)

print(list(islice(data, 5)))
```

结果：

```text
[0, 1, 2, 3, 4]
```
