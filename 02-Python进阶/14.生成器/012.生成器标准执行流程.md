# 生成器标准执行流程

```python
def generator():
    yield 1
    yield 2
    yield 3
```

调用：

```python
g = generator()
```

此时：

```text
函数代码基本还没有真正向下执行
```

第一次：

```python
next(g)
```

流程：

```text
开始运行
↓
yield 1
↓
返回 1
↓
暂停
```

第二次：

```python
next(g)
```

流程：

```text
从上次位置继续
↓
yield 2
↓
返回 2
↓
暂停
```

第三次：

```text
yield 3
↓
返回 3
↓
暂停
```

第四次：

```text
函数结束
↓
StopIteration
```
