# `for` 循环底层原理

例如：

```python
for x in [10, 20, 30]:
    print(x)
```

可以简单理解成：

```python
it = iter([10, 20, 30])

while True:

    try:
        x = next(it)

        print(x)

    except StopIteration:
        break
```

所以 `for` 背后的核心就是：

```text
iter()
↓
next()
↓
next()
↓
next()
↓
StopIteration
↓
结束循环
```

> [!IMPORTANT]  
> 理解这一段以后，你就真正理解了 Python 的 `for` 循环、迭代器和生成器之间的关系。
