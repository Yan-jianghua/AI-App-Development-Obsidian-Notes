# 方法重写

## 什么是重写

子类定义一个和父类**同名的方法**，从而替换继承来的行为。

### 示例

```python
class Animal:
    def speak(self):
        print("动物叫")


class Cat(Animal):
    def speak(self):
        print("喵喵")
```

调用：

```python
cat = Cat()
cat.speak()
```

输出：

```text
喵喵
```

Python优先找到：

```python
Cat.speak()
```

所以父类方法被子类重写。

---

## 重写后仍然调用父类

```python
class Cat(Animal):
    def speak(self):
        super().speak()
        print("喵喵")
```

调用：

```python
cat.speak()
```

结果：

```text
动物叫
喵喵
```

### 一句话记忆

> override = 子类重新定义父类的同名方法。
