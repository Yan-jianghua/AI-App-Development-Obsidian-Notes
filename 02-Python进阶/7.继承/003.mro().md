# mro()

## 作用

查看某个类的 MRO。

### 示例

```python
print(D.mro())
```

结果类似：

```text
[
    D,
    B,
    C,
    A,
    object
]
```

也就是说 Python 查找方法时按照：

```text
D
↓
B
↓
C
↓
A
↓
object
```

查找。

---

## 也可以使用

```python
print(D.__mro__)
```

查看 MRO。

不过学习和调试时：

```python
D.mro()
```

更加直观。

### 一句话记忆

> `Class.mro()` = 查看类的方法查找顺序。
