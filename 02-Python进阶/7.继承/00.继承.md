# 继承

子类继承父类接口并可重写行为。`super()` 按方法解析顺序（MRO）调用下一个实现，尤其在多重继承中不是简单地“直接调用父类”。

```python
class Animal:
    def speak(self) -> str:
        raise NotImplementedError

class Dog(Animal):
    def speak(self) -> str:
        return "woof"
```

继承适合稳定的“是一个”关系。为复用几行代码而建立深继承层级会增加耦合；组合通常更灵活。重写时保持父类接口契约，不能让调用方突然必须传入新参数或接收完全不同的结果。

## 练习

为通知系统设计 Email/SMS 两种实现，比较继承与组合策略的扩展成本。
