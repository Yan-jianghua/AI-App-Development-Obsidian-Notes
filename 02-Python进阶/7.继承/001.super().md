# `super()`

## 作用

在子类中调用父类的功能。

最常见用途：

> 调用父类的 `__init__()`。

### 示例

```python
class Person:
    def __init__(self, name):
        self.name = name


class Student(Person):
    def __init__(self, name, score):
        super().__init__(name)
        self.score = score
```

创建：

```python
s1 = Student("张三", 90)
```

这里：

```python
super().__init__(name)
```

会调用父类：

```python
Person.__init__()
```

初始化：

```python
self.name
```

然后子类继续初始化：

```python
self.score
```

---

## 为什么用 `super()`

虽然也能看到：

```python
Person.__init__(self, name)
```

但是更推荐：

```python
super().__init__(name)
```

因为 `super()` 会按照 MRO 查找下一个类，在多继承中更加可靠。

### 注意

`super()` 不应该简单死记成：

> “父类对象”。

更准确：

> `super()` 根据 MRO 找当前类之后的下一个类。

### 一句话记忆

> `super()` = 按 MRO 调用下一层父类功能。
