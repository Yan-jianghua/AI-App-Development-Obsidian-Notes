## `copy.copy()`

### 作用

创建对象的**浅拷贝**。

需要先：

```python
import copy
```

### 示例

```python
import copy

a = [[1, 2], [3, 4]]

b = copy.copy(a)
```

此时：

```text
a 和 b
```

最外层列表不是同一个对象。

但是里面的子列表仍然共享。

可以理解成：

```text
a ──→ [ 子列表1, 子列表2 ]
        ↑        ↑
b ──→ [ 同一个    同一个 ]
```

### 验证

```python
print(a is b)
```

结果：

```text
False
```

但是：

```python
print(a[0] is b[0])
```

结果：

```text
True
```

### 一句话记忆

> `copy.copy()` = 只复制最外层，里面的对象仍然共享。
