# 浅拷贝底层理解

假设：

```python
a = [[1, 2], [3, 4]]
```

对象关系：

```text
a
↓
外层列表
├──→ 子列表1
└──→ 子列表2
```

执行：

```python
b = a.copy()
```

得到：

```text
a → 外层列表A
     ├──→ 子列表1
     └──→ 子列表2

b → 外层列表B
     ├──→ 子列表1
     └──→ 子列表2
```

所以：

> 外层复制了，内层还是同一个。
> # 四种浅拷贝方式

对于列表：

```python
import copy

b = copy.copy(a)

b = a.copy()

b = a[:]

b = list(a)
```

通常都属于：

> 浅拷贝。
