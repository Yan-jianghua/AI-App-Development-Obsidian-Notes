# `copy.deepcopy()`

## 作用

创建对象的**深拷贝**。

### 示例

```python
import copy

a = [[1, 2], [3, 4]]

b = copy.deepcopy(a)
```

这时：

```python
print(a is b)
```

结果：

```text
False
```

而：

```python
print(a[0] is b[0])
```

通常也是：

```text
False
```

因为内部可变对象也被递归复制了。

### 可以理解成

```text
原对象
↓
复制外层
↓
继续复制内部对象
↓
继续递归
```

### 一句话记忆

> `deepcopy()` = 递归复制整个对象结构。
