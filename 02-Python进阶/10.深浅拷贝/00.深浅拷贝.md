# 深拷贝、浅拷贝与引用

赋值只增加一个引用；浅拷贝创建外层容器但共享内部对象；深拷贝递归复制可复制对象。`is` 比较身份，`==` 比较值。

```python
import copy
original = [[1], [2]]
shallow = copy.copy(original)
deep = copy.deepcopy(original)
original[0].append(3)
print(shallow[0])  # [1, 3]
print(deep[0])     # [1]
```

深拷贝可能昂贵，也未必适合数据库连接、锁、文件句柄等资源。优先明确数据所有权和不可变结构，必要时只复制会被修改的部分。
