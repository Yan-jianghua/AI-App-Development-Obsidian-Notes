# `memo`

## 什么是 memo

`deepcopy()` 内部需要记录：

> 哪些对象已经复制过了。

这个记录结构通常称为：

```text
memo
```

可以简单理解成一个内部字典：

```text
原对象
↓
已经复制的新对象
```

---

## 为什么需要 memo

假设同一个对象被引用两次：

```python
x = [1, 2]

a = [x, x]
```

这里：

```python
a[0] is a[1]
```

结果：

```text
True
```

如果：

```python
import copy

b = copy.deepcopy(a)
```

Python 不应该把 `x` 错误地复制成两个完全不同的列表。

借助 `memo`，它可以记住：

```text
x 已经复制过了
```

所以之后再次遇到 `x` 时，复用之前复制出的对象。

因此：

```python
b[0] is b[1]
```

通常仍然是：

```text
True
```

---

# memo 还能处理循环引用

例如：

```python
a = []

a.append(a)
```

这里：

```text
a
↓
列表
└──→ 自己
```

形成循环引用。

如果 `deepcopy()` 不记录已经复制过的对象，就可能：

```text
复制 a
↓
里面又有 a
↓
继续复制 a
↓
无限循环
```

`memo` 就是用来避免这种情况的。

### 一句话记忆

> `memo` = `deepcopy()` 内部记录“这个对象是否已经复制过”。
