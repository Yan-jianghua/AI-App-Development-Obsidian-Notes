# `is`

## 作用

判断两个变量是否指向**同一个对象**。

### 示例

```python
a = [1, 2]
b = a

print(a is b)
```

结果：

```text
True
```

如果：

```python
a = [1, 2]
b = [1, 2]
```

那么：

```python
print(a == b)
```

结果：

```text
True
```

但：

```python
print(a is b)
```

结果：

```text
False
```

因为：

```text
值相同
≠
同一个对象
```

---

# `is` 和 `==`

```python
==
```

判断：

> 值是否相等。

```python
is
```

判断：

> 是否为同一个对象。

### 核心记忆

```text
==  比值

is  比身份
```

### 常见正确用法

判断 `None`：

```python
if value is None:
    ...
```

而不是：

```python
if value == None:
    ...
```

### 一句话记忆

> `is` = 判断对象身份是否相同。
