# 不可变对象需要注意

深拷贝不代表：

> 所有东西都会生成一个全新对象。

例如一些不可变对象：

```python
int
str
tuple 中的不可变内容
```

可能直接复用。

因为它们不能原地修改，所以共享通常没有问题。

因此学习 `deepcopy()` 时更重要的理解是：

> 它会递归处理对象结构，使可变内部数据不再和原对象发生不必要的共享。

## 1. 普通元组

```python
import copy

a = (1, 2, 3)

b = copy.copy(a)
```

判断：

```python
print(a is b)
```

通常结果：

```text
True
```

### 为什么？

因为：

```python
tuple
```

本身不可修改。

Python 没必要重新创建一个完全相同的不可变元组，所以浅拷贝可能直接返回原对象。

可以理解：

```text
a ──┐
    ├──→ (1, 2, 3)
b ──┘
```

---

# 2. `copy.copy(tuple)`

即使元组里面有可变对象：

```python
import copy

lst = [1, 2]

a = (lst, 10)

b = copy.copy(a)
```

通常：

```python
print(a is b)
```

结果：

```text
True
```

里面的列表当然也是同一个：

```python
print(a[0] is b[0])
```

结果：

```text
True
```

因为 `copy.copy()` 只做浅拷贝，而 tuple 本身又不可变，因此通常直接复用整个 tuple。

### 一句话记忆

> `copy.copy(tuple)` 通常不会创建新的 tuple。

---

# 3. `copy.deepcopy(tuple)`

这时候要看：

> tuple 内部有没有需要深拷贝的可变对象。

---

## 情况一：内部全是不可变对象

```python
import copy

a = (1, "Python", (2, 3))

b = copy.deepcopy(a)
```

因为里面都是不可变对象：

```python
print(a is b)
```

可能得到：

```text
True
```

Python 没必要创建新的对象。

---

# 情况二：tuple 内部有可变对象

例如：

```python
import copy

a = ([1, 2], 10)

b = copy.deepcopy(a)
```

这时：

```python
print(a is b)
```

结果：

```text
False
```

因为里面：

```python
[1, 2]
```

是可变列表，需要真正深拷贝。

再看：

```python
print(a[0] is b[0])
```

结果：

```text
False
```

说明里面的列表也被复制了。

---

# 4. 最容易理解的图

原对象：

```python
a = ([1, 2], 10)
```

## `copy.copy()`

```text
a ──┐
    │
    └──→ ( [1,2], 10 )
b ──┘
```

通常连外层 tuple 都直接复用。

---

## `copy.deepcopy()`

```text
a → tuple A
     ↓
   list A

b → tuple B
     ↓
   list B
```

因为内部列表需要独立，所以新的 tuple 也需要重新创建。

---

# 5. 修改内部列表

```python
import copy

a = ([1, 2], 10)

b = copy.copy(a)
c = copy.deepcopy(a)
```

修改：

```python
a[0].append(3)
```

此时：

```python
print(a)
print(b)
print(c)
```

结果类似：

```text
([1, 2, 3], 10)

([1, 2, 3], 10)

([1, 2], 10)
```

为什么？

```text
a 和 b
→ 共享里面的列表

c
→ 有自己独立的列表
```

---

# 6. 注意：tuple 不可变 ≠ 内部对象不可变

非常重要。

```python
a = ([1, 2], 10)
```

不能：

```python
a[0] = [3, 4]
```

因为不能修改 tuple 保存的引用。

但是可以：

```python
a[0].append(3)
```

因为你修改的是：

```text
tuple 里面那个 list
```

而不是 tuple 本身。

所以：

> tuple 不可变，只代表它保存的对象引用不能被替换，不代表里面的对象也一定不可变。

---

# 总结

|情况|`copy.copy()`|`copy.deepcopy()`|
|---|---|---|
|tuple 全是不可变对象|通常原对象|通常可能原对象|
|tuple 含可变对象|通常原 tuple，内部共享|创建需要的新对象，内部可变对象独立|
