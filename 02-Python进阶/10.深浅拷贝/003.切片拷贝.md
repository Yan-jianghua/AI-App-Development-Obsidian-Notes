# 切片拷贝

## 作用

对于列表，可以通过：

```python
[:]
```

创建浅拷贝。

### 示例

```python
a = [1, 2, 3]

b = a[:]
```

此时：

```python
a is b
```

结果：

```text
False
```

---

## 嵌套列表

```python
a = [[1, 2], [3, 4]]

b = a[:]
```

仍然只是浅拷贝。

所以：

```python
a[0] is b[0]
```

结果：

```text
True
```

### 一句话记忆

> `list[:]` = 列表浅拷贝。
