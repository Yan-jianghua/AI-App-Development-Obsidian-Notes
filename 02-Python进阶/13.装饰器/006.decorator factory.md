## `decorator factory`

`decorator factory` 中文叫：

**装饰器工厂**。

作用：

> 让装饰器本身也可以接收参数。

普通装饰器：

```python
@decorator
def test():
    pass
```

装饰器工厂：

```python
@repeat(3)
def hello():
    print("hello")
```

这里：

```python
repeat(3)
```

就是装饰器工厂。

---

### 典型结构

```python
from functools import wraps


def repeat(count):

    def decorator(func):

        @wraps(func)
        def wrapper(*args, **kwargs):

            for _ in range(count):
                func(*args, **kwargs)

        return wrapper

    return decorator
```

使用：

```python
@repeat(3)
def hello():
    print("hello")
```

结果：

```text
hello
hello
hello
```

---

### 三层结构

```text
repeat(count)
    ↓
decorator(func)
    ↓
wrapper(*args, **kwargs)
```

分别负责：

```text
repeat(count)
→ 接收装饰器自己的参数

decorator(func)
→ 接收被装饰的函数

wrapper(*args, **kwargs)
→ 接收原函数调用时的参数
```

---

### 本质

```python
@repeat(3)
def hello():
    pass
```

等价于：

```python
hello = repeat(3)(hello)
```

拆开：

```python
decorator = repeat(3)

hello = decorator(hello)
```

### 记忆

> decorator factory = 用来生成装饰器的函数。
