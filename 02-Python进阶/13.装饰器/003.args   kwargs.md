## `*args / **kwargs`

装饰器中的 `wrapper` 通常写成：

```python
def wrapper(*args, **kwargs):
    return func(*args, **kwargs)
```

原因是：

> 原函数可能有不同数量、不同类型的参数。

例如：

```python
def add(a, b):
    return a + b
```

如果写：

```python
def wrapper():
    return func()
```

那么：

```python
add(10, 20)
```

就会报错。

---

### `*args`

接收所有**位置参数**。

例如：

```python
add(10, 20)
```

那么：

```python
args = (10, 20)
```

---

### `**kwargs`

接收所有**关键字参数**。

例如：

```python
add(a=10, b=20)
```

那么：

```python
kwargs = {
    "a": 10,
    "b": 20
}
```

---

### 标准写法

```python
def wrapper(*args, **kwargs):
    return func(*args, **kwargs)
```

含义：

```text
接收原函数的所有参数
↓
再原样传递给原函数
```

### 记忆

```text
*args
→ 位置参数

**kwargs
→ 关键字参数
```

> [!IMPORTANT]  
> 实际开发中的通用装饰器，基本都会使用 `*args, **kwargs`。
