## `stacking order`

`stacking order` 表示：

**多个装饰器叠加时的顺序。**

例如：

```python
@A
@B
def test():
    pass
```

本质上：

```python
test = A(B(test))
```

---

## 装饰顺序

装饰器应用时：

```text
从下往上
```

例如：

```python
@A
@B
def test():
    pass
```

顺序：

```text
B
↓
A
```

因为：

```python
A(B(test))
```

---

## 调用顺序

例如：

```python
def A(func):

    def wrapper():
        print("A 开始")

        func()

        print("A 结束")

    return wrapper


def B(func):

    def wrapper():
        print("B 开始")

        func()

        print("B 结束")

    return wrapper
```

使用：

```python
@A
@B
def test():
    print("test")
```

等价于：

```python
test = A(B(test))
```

执行：

```python
test()
```

结果：

```text
A 开始
B 开始
test
B 结束
A 结束
```

结构可以理解为：

```text
A
└── B
    └── test
```
