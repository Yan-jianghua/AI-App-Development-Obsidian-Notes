装饰器（Decorator）可以理解成：

> **在不修改原函数代码的前提下，给函数“额外加功能”。**

它本质上通常就是一个**接收函数、返回新函数的高阶函数**。你刚学过的“函数对象、高阶函数、闭包”，其实就是理解装饰器的基础。

---

## 1. 为什么需要装饰器？

假设有一个函数：

```
def login():
    print("用户登录")
```

现在你希望每次执行 `login()` 前，都记录一下“函数开始执行”。

最直接的写法是：

```
def login():
    print("开始执行")
    print("用户登录")
```

但这样相当于**修改了原函数**。

如果以后有 20 个函数都要加日志，你就要改 20 次。

装饰器就是为了解决这个问题：

> 把“日志、权限检查、计时、缓存”等公共功能单独写出来，然后批量加到其他函数身上。

常见用途包括：日志记录、权限验证、运行时间统计、缓存、重试、事务处理，以及 Web 框架中的路由注册等。

# 2. 最基本的装饰器

先看一个完整例子：

```
def decorator(func):

    def wrapper():
        print("函数执行前")

        func()

        print("函数执行后")

    return wrapper


@decorator
def hello():
    print("Hello")


hello()
```

运行结果：

```
函数执行前
Hello
函数执行后
```

这里最重要的结构是：

```
def decorator(func):

    def wrapper():
        ...

        func()

        ...

    return wrapper
```

你可以理解为：

```
decorator
    ↓
接收原函数
    ↓
创建 wrapper
    ↓
wrapper 中调用原函数
    ↓
返回 wrapper
```
