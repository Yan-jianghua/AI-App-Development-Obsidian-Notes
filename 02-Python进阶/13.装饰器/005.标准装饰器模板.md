## 标准装饰器模板

实际开发中推荐写成：

```python
from functools import wraps


def decorator(func):

    @wraps(func)
    def wrapper(*args, **kwargs):

        print("原函数执行前")

        result = func(*args, **kwargs)

        print("原函数执行后")

        return result

    return wrapper
```

使用：

```python
@decorator
def add(a, b):
    return a + b
```
