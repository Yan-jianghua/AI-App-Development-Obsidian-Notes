##  `wrapper`

`wrapper` 是装饰器内部的**包装函数**。

典型结构：

```python
def decorator(func):

    def wrapper():
        print("执行前")

        func()

        print("执行后")

    return wrapper
```

使用：

```python
@decorator
def hello():
    print("你好")

hello()
```

结果：

```text
执行前
你好
执行后
```

### 原理

装饰之后：

```python
hello = decorator(hello)
```

而 `decorator()` 返回的是：

```python
wrapper
```

所以最终：

```text
hello → wrapper
```

调用：

```python
hello()
```

实际上是在执行：

```python
wrapper()
```

然后 `wrapper()` 内部再调用原来的：

```python
func()
```

### 注意

`wrapper` 只是常用名字，不是 Python 关键字。

可以写成：

```python
def decorator(func):

    def abc():
        func()

    return abc
```

但一般推荐使用：

```text
wrapper
```

因为含义更清楚。

> [!NOTE]  
> `wrapper` 的作用就是在原函数外面“包一层”，从而给原函数增加额外功能。
