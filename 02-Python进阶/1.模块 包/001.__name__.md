# `__name__`

### 作用

表示当前模块的名称。

例如文件：

```text
test.py
```

里面：

```python
print(__name__)
```

如果直接运行：

```bash
python test.py
```

结果：

```text
__main__
```

如果被其他文件导入：

```python
import test
```

那么 `test.py` 中：

```python
__name__
```

通常是：

```text
test
```

### 一句话记忆

> `__name__` = 当前模块叫什么。

---

# `if __name__ == "__main__"`

### 作用

判断当前文件是不是**直接运行**。

### 示例

```python
def test():
    print("执行函数")


if __name__ == "__main__":
    test()
```

如果直接运行这个文件：

```text
会执行 test()
```

如果这个文件被其他模块：

```python
import
```

则里面这部分：

```python
if __name__ == "__main__":
```

不会执行。

### 实际作用

防止：

> 模块被导入时，把测试代码、启动代码一起执行。

### 常见写法

```python
def main():
    print("程序启动")


if __name__ == "__main__":
    main()
```

### 一句话记忆

> `if __name__ == "__main__"` = 只有直接运行当前文件时才执行。
