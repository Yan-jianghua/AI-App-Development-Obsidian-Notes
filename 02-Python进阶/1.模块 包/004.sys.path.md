# `sys.path`

### 作用

查看 Python 去哪些目录中寻找模块。

首先：

```python
import sys
```

然后：

```python
print(sys.path)
```

结果会是一个目录列表。

Python 执行：

```python
import demo
```

时，就会根据模块搜索路径去寻找：

```text
demo.py
```

或者对应包。

### 为什么重要

如果出现：

```text
ModuleNotFoundError
```

经常和：

```text
模块不存在
路径不对
项目运行位置不对
```

有关。

### 一句话记忆

> `sys.path` = Python 查找模块的路径列表。
