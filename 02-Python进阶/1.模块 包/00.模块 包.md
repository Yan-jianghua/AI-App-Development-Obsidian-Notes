# 模块与包

模块是 `.py` 文件，包组织多个模块。`import` 首次执行模块顶层代码并缓存模块对象；后续导入通常复用缓存。运行入口用 `if __name__ == "__main__":`，避免被导入时执行演示代码。

从项目根目录用 `python -m myapp.main` 运行有助于保持包导入一致。不要靠修改 `sys.path` 修补不清晰的项目结构；包名避免与标准库同名。循环导入通常说明模块职责需要拆分。
