# `python -m package.module`

### 作用

按照**模块方式**运行 Python 文件。

例如项目：

```text
project/
│
└── app/
    ├── __init__.py
    ├── main.py
    └── utils.py
```

可以在项目根目录运行：

```bash
python -m app.main
```

这里：

```text
app.main
```

表示：

```text
app 包
 ↓
main 模块
```

---

## 和直接运行的区别

直接：

```bash
python app/main.py
```

是把它当一个普通脚本运行。

而：

```bash
python -m app.main
```

是告诉 Python：

> 按照包和模块关系运行它。

在多文件项目中，`-m` 经常能减少导入路径问题。

### 一句话记忆

> `python -m package.module` = 按包结构运行模块。

---

# 模块和包的区别

## 模块 Module

一个：

```text
.py 文件
```

就是一个模块。

例如：

```text
student.py
```

---

## 包 Package

包含多个模块的目录。

例如：

```text
student/
├── __init__.py
├── model.py
└── service.py
```

可以理解：

```text
包
↓
装多个模块的文件夹
```
