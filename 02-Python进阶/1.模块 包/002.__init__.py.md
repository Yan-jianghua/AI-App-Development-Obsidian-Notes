# `__init__.py`

### 作用

放在包目录中的特殊文件。

例如：

```text
project/
│
├── main.py
│
└── student/
    ├── __init__.py
    ├── model.py
    └── service.py
```

这里：

```text
student
```

就是一个包。

### `__init__.py` 可以做什么

可以：

```text
初始化包
控制包对外暴露的内容
简化导入
```

例如：

```python
# student/__init__.py

from .model import Student
```

之后可能直接：

```python
from student import Student
```

而不用：

```python
from student.model import Student
```

### 注意

现代 Python 中某些情况下没有 `__init__.py` 也能形成命名空间包，但普通项目中仍然非常常见。

### 一句话记忆

> `__init__.py` = 包的初始化文件。
