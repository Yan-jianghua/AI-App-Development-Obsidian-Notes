# `__all__`

### 作用

控制：

```python
from 模块 import *
```

时哪些名字可以被导入。

### 示例

```python
__all__ = ["add", "sub"]
```

模块中：

```python
def add():
    pass

def sub():
    pass

def test():
    pass
```

如果：

```python
from demo import *
```

主要导入：

```text
add
sub
```

而不导入：

```text
test
```

### 一句话记忆

> `__all__` = 控制模块对外公开哪些名字。
