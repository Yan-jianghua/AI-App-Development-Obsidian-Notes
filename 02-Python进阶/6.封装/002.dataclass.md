# `dataclass`

## 什么是 dataclass

如果一个类主要作用是：

> 保存数据

可以使用：

```python
@dataclass
```

减少大量重复代码。

需要：

```python
from dataclasses import dataclass
```

---

## 普通类

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age
```

使用 dataclass：

```python
from dataclasses import dataclass


@dataclass
class Student:
    name: str
    age: int
```

创建：

```python
s1 = Student("张三", 20)
```

Python 会自动帮你生成很多基础功能，包括常用的：

```text
__init__()
__repr__()
__eq__()
```

---

## 示例

```python
from dataclasses import dataclass


@dataclass
class Student:
    name: str
    age: int


s1 = Student("张三", 20)

print(s1)
```

输出类似：

```text
Student(name='张三', age=20)
```

不需要自己写 `__repr__()`。

---

## 什么时候适合用

例如：

```text
用户信息
学生数据
配置对象
API 请求/响应数据
简单的数据模型
```

如果类里面包含大量复杂业务逻辑，就不能简单理解成“所有类都应该用 dataclass”。

### 一句话记忆

> `dataclass` = 专门简化“主要用来保存数据”的类。
