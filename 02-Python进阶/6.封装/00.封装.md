# 封装

封装把状态和规则放在同一边界内，只暴露有意义的操作。Python 的 `_name` 是“内部使用”的约定，`__name` 会触发名称改写，但都不是安全边界。

```python
class Cart:
    def __init__(self) -> None:
        self._items: list[tuple[str, int]] = []

    def add(self, sku: str, quantity: int) -> None:
        if quantity <= 0:
            raise ValueError("数量必须为正")
        self._items.append((sku, quantity))

    def items(self) -> tuple[tuple[str, int], ...]:
        return tuple(self._items)
```

返回只读视图或副本可减少外部意外修改；仍要注意嵌套可变对象。`dataclass` 适合数据载体，但业务不变量依然要明确检查。

## 练习

设计购物车 API，使外部代码无法通过拿到内部列表就绕过“数量必须为正”的规则。
