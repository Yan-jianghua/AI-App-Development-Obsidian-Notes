# 实例方法、类方法与静态方法

实例方法接收 `self`，操作对象状态；`@classmethod` 接收 `cls`，常用于替代构造器或类级配置；`@staticmethod` 不自动接收实例或类，仅把相关辅助函数放在类命名空间。

```python
from datetime import date

class Event:
    def __init__(self, day: date) -> None:
        self.day = day

    @classmethod
    def from_iso(cls, text: str) -> "Event":
        return cls(date.fromisoformat(text))

    @staticmethod
    def is_weekend(day: date) -> bool:
        return day.weekday() >= 5
```

类方法用 `cls(...)` 能尊重子类构造；静态方法若与类状态无关且复用广，独立模块函数可能更清晰。
