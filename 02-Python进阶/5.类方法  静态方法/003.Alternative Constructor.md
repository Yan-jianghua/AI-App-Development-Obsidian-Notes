# Alternative Constructor

## 什么是替代构造器

Alternative constructor 可以翻译成：

> 替代构造器 / 替代构造方法

它通常使用：

```python
@classmethod
```

让类可以通过**另一种数据格式创建对象**。

---

## 普通创建对象

```python
class Student:

    def __init__(self, name, age):
        self.name = name
        self.age = age
```

正常创建：

```python
s1 = Student("张三", 20)
```

---

## 替代构造器

假设数据是：

```python
"张三-20"
```

我们可以写：

```python
class Student:

    def __init__(self, name, age):
        self.name = name
        self.age = age

    @classmethod
    def from_string(cls, data):
        name, age = data.split("-")
        return cls(name, int(age))
```

调用：

```python
s1 = Student.from_string("张三-20")
```

实际上：

```python
cls(name, int(age))
```

相当于：

```python
Student(name, int(age))
```

最终还是调用：

```python
__init__()
```

创建对象。

### 一句话记忆

> 替代构造器 = 换一种输入方式创建对象。

---

# 为什么替代构造器常用 `@classmethod`

因为：

```python
cls(...)
```

可以自动表示当前类。

例如：

```python
return cls(name, age)
```

比直接写：

```python
return Student(name, age)
```

更灵活。

以后如果有子类继承：

```python
class CollegeStudent(Student):
    pass
```

调用：

```python
CollegeStudent.from_string(...)
```

里面的：

```python
cls
```

会自动变成：

```python
CollegeStudent
```

这也是类方法的重要优势。
