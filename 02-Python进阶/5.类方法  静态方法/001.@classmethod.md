## ## `@classmethod`

### 作用

把一个方法定义成**类方法**。

类方法的第一个参数通常写：

```python
cls
```

而不是：

```python
self
```

### 示例

```python
class Student:

    school = "河北金融学院"

    @classmethod
    def show_school(cls):
        print(cls.school)
```

调用：

```python
Student.show_school()
```

输出：

```text
河北金融学院
```

### 一句话记忆

> `@classmethod` = 这个方法主要操作“类本身”。

# `cls`

## 作用

`cls` 表示：

> 当前这个类。

例如：

```python
class Student:

    school = "河北金融学院"

    @classmethod
    def show_school(cls):
        print(cls.school)
```

这里：

```python
cls
```

基本可以理解成：

```python
Student
```

所以：

```python
cls.school
```

相当于：

```python
Student.school
```

### 注意

`cls` 只是惯例名字，不是关键字。

理论上可以写：

```python
@classmethod
def test(x):
    print(x)
```

但不推荐。

### 一句话记忆

> `cls` = 当前类。
