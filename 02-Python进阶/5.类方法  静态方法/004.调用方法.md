# `ClassName.method`

## 作用

表示通过**类名调用方法或访问内容**。

例如：

```python
Student.show_school()
```

这里：

```text
Student
= 类名

show_school
= 方法
```

---

## 类方法

非常常见：

```python
Student.show_school()
```

---

## 静态方法

也通常这样调用：

```python
Student.is_valid_score(90)
```

---

## 实例方法不推荐这样直接调用

普通实例方法：

```python
class Student:

    def hello(self):
        print("hello")
```

正常：

```python
s1 = Student()
s1.hello()
```

虽然底层可以写：

```python
Student.hello(s1)
```

但日常开发通常写：

```python
s1.hello()
```
