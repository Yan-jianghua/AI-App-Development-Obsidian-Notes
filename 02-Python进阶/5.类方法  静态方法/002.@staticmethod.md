# `@staticmethod`

## 作用

定义**静态方法**。

静态方法：

- 不自动接收 `self`
    
- 不自动接收 `cls`
    

### 示例

```python
class Student:

    @staticmethod
    def is_valid_score(score):
        return 0 <= score <= 100
```

调用：

```python
print(Student.is_valid_score(90))
```

结果：

```text
True
```

### 为什么放在类里

因为这个功能：

```text
和 Student 有关系
```

但它又不需要：

```text
具体对象 self
```

也不需要：

```text
当前类 cls
```

所以可以写成静态方法。

### 一句话记忆

> `@staticmethod` = 和类有关，但不需要 self 和 cls。

---

# `@classmethod` 和 `@staticmethod`

|方法|第一个参数|主要用途|
|---|---|---|
|实例方法|`self`|操作具体对象|
|类方法|`cls`|操作类|
|静态方法|无固定参数|与类相关的独立功能|

记忆：

```text
self
= 当前对象

cls
= 当前类

staticmethod
= 谁都不自动传
```
