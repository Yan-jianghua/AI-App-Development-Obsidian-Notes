# Composition 组合

## 什么是组合

组合就是：

> 一个对象内部包含另一个对象。

也可以理解成：

> “有一个”关系。

例如：

```text
学生 有一个 地址
汽车 有一个 发动机
订单 有一个 用户
```

---

## 示例

```python
class Engine:

    def start(self):
        print("发动机启动")


class Car:

    def __init__(self):
        self.engine = Engine()
```

创建汽车：

```python
car = Car()
```

调用发动机：

```python
car.engine.start()
```

这里：

```text
Car
```

里面包含：

```text
Engine
```

所以叫组合。
