# 类与对象

类定义数据与行为的共同结构，实例是具体对象。`__init__` 初始化实例状态；实例方法第一个参数通常叫 `self`，由对象调用时自动传入。

```python
class BankAccount:
    def __init__(self, balance: int = 0) -> None:
        if balance < 0:
            raise ValueError("余额不能为负")
        self.balance = balance

    def deposit(self, amount: int) -> None:
        if amount <= 0:
            raise ValueError("金额必须为正")
        self.balance += amount
```

有状态和不变量时类很有价值；单纯转换输入输出的逻辑用函数可能更清晰。组合是“拥有一个对象”，继承是“属于某一类”，优先按真实关系选择。
