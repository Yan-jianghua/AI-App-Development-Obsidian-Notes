# `factory function` 工厂函数

### 是什么

工厂函数就是：

> 一个函数负责“制造并返回另一个函数”。

所以叫：

```
factory
工厂
```

就像：

```
汽车工厂 → 生产汽车
```

而：

```
函数工厂 → 生产函数
```

例如：

```
def multiplier(n):

    def multiply(x):
        return x * n

    return multiply
```

使用：

```
double = multiplier(2)
triple = multiplier(3)
```

现在：

```
double(10)
```

得到：

```
20
```

而：

```
triple(10)
```

得到：

```
30
```

这里：

```
multiplier()
```

就是：

```
factory function
```

因为它专门创建：

```
multiply()
```

这样的函数。

并且：

```
double
```

保存：

```
n = 2
```

而：

```
triple
```

保存：

```
n = 3
```

所以实际上：

```
multiplier(2)
      ↓
创建一个记住 n=2 的函数
      ↓
double
```

### 记忆

> factory function = 用一个函数生产另一个函数。
