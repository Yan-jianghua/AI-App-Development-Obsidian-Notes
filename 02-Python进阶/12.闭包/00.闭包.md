# 闭包（Closure）

## 1. 什么是闭包

闭包可以理解为：

> **内层函数使用了外层函数的变量，并且即使外层函数已经执行结束，内层函数仍然能够继续使用这个变量。**

简单记忆：

> **闭包 = 函数 + 它记住的外层变量。**

---

## 2. 典型例子

```
def outer():
    x = 10

    def inner():
        print(x)

    return inner


func = outer()
func()
```

输出：

```
10
```

这里：

```
x
```

是 `outer()` 的局部变量。

但是：

```
inner()
```

使用了 `x`。

并且：

```
return inner
```

把 `inner` 函数返回了出去。

虽然：

```
outer()
```

已经执行结束，但是：

```
func()
```

仍然可以访问：

```
x = 10
```

所以 `inner` 就形成了一个闭包。

---

## 3. 闭包的三个特点

典型闭包一般有：

```
① 函数里面再定义函数

② 内层函数使用外层函数的变量

③ 外层函数返回内层函数
```

例如：

```
def outer():
    x = 10

    def inner():
        print(x)

    return inner
```

---

## 4. free variable 自由变量

在：

```
def inner():
    print(x)
```

中，`x` 没有在 `inner()` 里面定义，而是来自外层的 `outer()`。

所以：

```
x
```

对于 `inner()` 来说就是：

> **free variable（自由变量）**

简单理解：

> 自由变量 = 内层函数使用的外层变量。

---

## 5. cell

Python 为了让闭包能够长期保存外层变量，会把这些变量保存到一个特殊的容器中：

```
cell
```

可以理解成：

```
inner
  ↓
cell
  ↓
x = 10
```

所以：

> **cell = Python 保存闭包变量的小容器。**

---

## 6. `__closure__`

函数对象可以通过：

```
__closure__
```

查看自己保存的闭包变量。

例如：

```
print(func.__closure__)
```

如果存在闭包，会看到类似：

```
(<cell ...>,)
```

还可以查看里面保存的值：

```
print(func.__closure__[0].cell_contents)
```

输出：

```
10
```

所以：

> `__closure__` = 查看函数保存的闭包 `cell`。

---

## 7. `nonlocal`

如果内层函数只是读取外层变量：

```
def inner():
    print(x)
```

不需要 `nonlocal`。

但是如果要修改：

```
def outer():
    count = 0

    def inner():
        nonlocal count
        count += 1

    return inner
```

就需要：

```
nonlocal count
```

意思是：

> **不要创建新的局部变量，我要修改外层函数里的** `**count**`**。**

---

## 8. 闭包有什么用

闭包最大的作用之一是：

> **让函数保存自己的状态。**

例如计数器：

```
def counter():
    count = 0

    def add():
        nonlocal count
        count += 1
        return count

    return add


c = counter()

print(c())   # 1
print(c())   # 2
print(c())   # 3
```

这里 `count` 不会因为 `counter()` 执行结束就消失。

`add()` 会一直记住它。

因此：

```
第一次调用：count = 1
第二次调用：count = 2
第三次调用：count = 3
```

---

## 9. 闭包和工厂函数

例如：

```
def multiplier(n):

    def multiply(x):
        return x * n

    return multiply
```

使用：

```
double = multiplier(2)
triple = multiplier(3)
```

这里：

```
double 记住 n = 2
triple 记住 n = 3
```

所以：

```
double(10)   # 20
triple(10)   # 30
```

`multiplier()` 就是一个：

```
factory function（工厂函数）
```

因为它可以生成不同的闭包函数。

---

# 最重要的理解

闭包不是单纯保存一个函数。

而是保存：

```
函数
+
函数需要使用的外层变量
```

可以理解成：

```
闭包
│
├── inner 的代码
│
└── 它记住的外层变量
        └── x = 10
```

---

# 一句话记忆

> **闭包 = 内层函数记住并继续使用外层函数变量。**


free variable
= 内层函数使用、但自己没有定义的外层变量。

cell
= Python 保存闭包变量的小容器。

nonlocal
= 在内层函数中修改外层函数变量。

__closure__
= 查看函数保存的闭包 cell。

factory function
= 用来创建并返回另一个函数的函数。

late binding
= 闭包里的变量通常在函数真正调用时才读取当前值。```
