# `__closure__`

### 是什么

`__closure__` 是函数对象的一个属性。

它可以用来查看：

> 这个函数有没有保存闭包变量。

例如：

```
def outer():
    x = 10

    def inner():
        print(x)

    return inner


func = outer()
```

现在：

```
func
```

实际上就是：

```
inner
```

执行：

```
print(func.__closure__)
```

可能看到：

```
(<cell at 0x...: int object at 0x...>,)
```

这里的：

```
cell
```

就是前面讲的闭包单元。

里面保存：

```
x
```

的值。

---

还可以：

```
print(func.__closure__[0].cell_contents)
```

得到：

```
10
```

整个关系可以理解成：

```
func
 │
 └── __closure__
        │
        └── cell
              │
              └── 10
```

### 什么时候是 `None`

例如：

```
def test():
    x = 10
    print(x)
```

执行：

```
print(test.__closure__)
```

通常得到：

```
None
```

因为这里没有闭包。

`x` 本身就是：

```
test()
```

自己的局部变量。

### 记忆

> `__closure__` = 查看一个函数背后有没有保存闭包变量。
