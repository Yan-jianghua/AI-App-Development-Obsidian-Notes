# `late binding` 晚绑定

这是闭包里面比较容易踩坑的地方。

### 是什么

简单来说：

> 闭包里的自由变量，通常不是在“函数创建时”立即固定值，而是在“函数调用时”才去查它现在的值。

这就叫：

```
late binding
晚绑定
```

例如：

```
funcs = []

for i in range(3):
    funcs.append(lambda: i)
```

很多初学者会以为：

```
funcs[0]()  # 0
funcs[1]()  # 1
funcs[2]()  # 2
```

但实际上：

```
print(funcs[0]())
print(funcs[1]())
print(funcs[2]())
```

得到：

```
2
2
2
```

为什么？

因为：

```
lambda: i
```

创建的时候，并没有把：

```
i = 0
i = 1
i = 2
```

分别复制进去。

它们记住的是：

```
我要使用变量 i
```

循环结束后：

```
i = 2
```

等真正调用：

```
lambda
```

的时候，它才去读取：

```
i
```

所以全部得到：

```
2
```

---

### 怎么解决

可以利用默认参数：

```
funcs = []

for i in range(3):
    funcs.append(lambda i=i: i)
```

这时：

```
print(funcs[0]())
print(funcs[1]())
print(funcs[2]())
```

得到：

```
0
1
2
```

因为：

```
i=i
```

会在函数创建时把当前的 `i` 保存下来。
