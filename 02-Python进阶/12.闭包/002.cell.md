# `cell`

这个概念是理解闭包底层机制非常重要的一步。

### 是什么

当 Python 发现：

```
外层函数的变量
```

需要被：

```
内层函数
```

长期使用时，不会简单地把变量直接丢掉。

Python 会创建一个特殊的对象：

```
cell
```

可以把它理解成：

> 专门装闭包变量的小盒子。

例如：

```
def outer():
    x = 10

    def inner():
        print(x)

    return inner
```

即使：

```
outer()
```

已经执行结束了，`x` 依然不能消失。

因为：

```
inner()
```

以后还要使用它。

所以 Python 大致相当于把：

```
x = 10
```

保存进一个 `cell` 里面。

可以理解为：

```
cell
 ↓
10
```

然后：

```
inner
```

保存这个 `cell`。

所以闭包真正保存的并不是一个普通变量副本，而是保存变量对应的 **cell**。

### 记忆

> `cell` = Python 保存闭包变量的容器。
