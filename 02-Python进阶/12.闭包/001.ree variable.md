## `ree variable` 自由变量

### 是什么

**一个变量在当前函数内部没有定义，但是当前函数却使用了它，这个变量就可能是自由变量。**

例如：

```
def outer():
    x = 10

    def inner():
        print(x)

    return inner
```

对于 `inner()` 来说：

```
x
```

不是：

- `inner()` 的参数
- `inner()` 内部创建的局部变量
- 全局变量

而是从外层函数：

```
outer()
```

里面找到的。

所以：

```
x
```

就是 `inner()` 的 **free variable（自由变量）**。

### 为什么叫“自由变量”

因为它不是当前函数自己的局部变量。

```
def inner():
    print(x)
```

`inner()` 自己没有：

```
x = ...
```

但它还是能使用 `x`。

因此它相对于 `inner()` 来说是一个自由变量。

### 记忆

> free variable = 内层函数自己没定义，却从外层函数拿来使用的变量。
