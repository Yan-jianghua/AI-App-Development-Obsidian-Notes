# `nonlocal`

### 是什么

`nonlocal` 用于：

> 在内层函数中修改外层函数的局部变量。

看这个例子：

```
def outer():
    count = 0

    def inner():
        count = count + 1

    inner()
```

这段代码会报错。

因为只要 Python 看见：

```
count = ...
```

就会认为：

```
count
```

是 `inner()` 自己的局部变量。

但是：

```
count = count + 1
```

右边又需要先读取 `count`。

此时 `inner()` 自己的 `count` 还没创建，所以报错。

---

加上：

```
nonlocal
```

就可以：

```
def outer():
    count = 0

    def inner():
        nonlocal count
        count += 1

    inner()
    print(count)


outer()
```

输出：

```
1
```

这里：

```
nonlocal count
```

是在告诉 Python：

> `count` 不是 `inner()` 自己的新变量，我要使用并修改外层函数的那个 `count`。

---

### 和 `global` 的区别

```
global
```

操作：

```
全局变量
```

而：

```
nonlocal
```

操作：

```
外层函数的局部变量
```

例如：

```
x = 100

def outer():
    y = 10

    def inner():
        global x
        nonlocal y
```

这里：

```
global x
```

表示：

```
使用全局 x
```

而：

```
nonlocal y
```

表示：

```
使用 outer() 中的 y
```

### 记忆

> `nonlocal` = 我要修改外层函数的变量，不要给我创建新的局部变量。
