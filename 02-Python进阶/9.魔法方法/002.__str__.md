### `__str__` 字符串显示方法

- `__str__` 是 Python 类中的**魔法方法**。
- 作用：规定对象被 `print()` 时显示什么内容。
- 必须返回一个**字符串**。

```
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __str__(self):
        return f"姓名：{self.name}，年龄：{self.age}"


s1 = Student("张三", 18)
print(s1)
```

输出：

```
姓名：张三，年龄：18
```

如果不写 `__str__`：

```
print(s1)
```

通常会看到类似：

```
<__main__.Student object at 0x...>
```

**一句话记忆：**

> `__str__` = 决定对象被 `print()` 时怎么显示。
