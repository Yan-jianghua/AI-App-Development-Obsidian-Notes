### `init__` 初始化方法

- `__init__` 是 Python 类中的**魔法方法**。
- 创建对象后会**自动调用**。
- 主要作用：**初始化对象的属性**。

```
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

s1 = Student("张三", 18)
```

其中：

```
self.name = name
```

- `self`：当前对象
- `self.name`：实例属性
- `name`：传入的参数

### 类属性和实例属性

```
class Student:
    school = "河北金融学院"   # 类属性

    def __init__(self, name):
        self.name = name     # 实例属性
```

- 类属性：所有对象共享
- 实例属性：每个对象可以不同

### 继承时

```
class Student(Person):
    def __init__(self, name, score):
        super().__init__(name)
        self.score = score
```

`super().__init__()`：调用父类的初始化方法。

**一句话记忆：**

> `__init__` = 对象创建后，自动给对象初始化属性的方法
