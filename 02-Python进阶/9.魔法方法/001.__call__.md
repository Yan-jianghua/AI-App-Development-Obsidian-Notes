### `__call__` 对象调用方法

- `__call__` 是 Python 类中的**魔法方法**。
- 作用：让一个对象可以像函数一样用 `()` 调用。

```
class Student:
    def __init__(self, name):
        self.name = name

    def __call__(self):
        print(f"{self.name} 被调用了")


s1 = Student("张三")
s1()
```

输出：

```
张三 被调用了
```

这里：

```
s1()
```

实际上相当于：

```
s1.__call__()
```

`__call__` 也可以接收参数：

```
class Add:
    def __call__(self, a, b):
        return a + b


add = Add()
print(add(2, 3))
```

输出：

```
5
```

**一句话记忆：**

> `__call__` = 让对象也能像函数一样被调用
