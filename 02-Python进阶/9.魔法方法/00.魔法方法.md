Python 的魔法方法是一类由双下划线包围的特殊方法，例如

[[003.__init__]]
[[005.__repr__]]![[029 84-87h 魔法方法.docx]]
它们也常被称为“双下方法”（dunder methods）。Python 会在特定操作发生时自动调用它们，一般不需要手动调用。

例如：

```
class Student:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        return f"学生：{self.name}"


student = Student("小明")
print(student)
```

运行过程：

- 创建对象 `Student("小明")` 时，Python 自动调用 `__init__`
- 执行 `print(student)` 时，Python 自动调用 `__str__`

常见魔法方法：

|魔法方法|触发方式|作用|
|---|---|---|
|`__init__`|`Student()`|初始化对象|
|`__str__`|`print(obj)`、`str(obj)`|返回面向用户的字符串|
|`__repr__`|`repr(obj)`|返回面向开发者的对象描述|
|`__len__`|`len(obj)`|定义对象长度|
|`__call__`|`obj()`|让对象可以像函数一样调用|
|`__eq__`|`obj1 == obj2`|定义相等比较|
|`__add__`|`obj1 + obj2`|定义加法行为|
|`__getitem__`|`obj[key]`|定义索引或键访问|
|`__enter__`、`__exit__`|`with obj:`|支持上下文管理|
|`__del__`|对象被销毁时|对象终结处理，不等同于 `del`|

核心理解：

> 魔法方法是 Python 数据模型提供的接口，用来规定自定义对象如何响应初始化、打印、运算、比较、索引等语言操作。

也就是说，魔法方法能够让自己创建的类像 Python 内置类型一样自然地使用。
