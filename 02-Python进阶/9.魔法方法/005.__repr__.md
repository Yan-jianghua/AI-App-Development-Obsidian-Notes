`__repr__` 是 Python 的魔法方法，用来定义对象的“官方字符串表示”，主要方便开发者调试。

```
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __repr__(self):
        return f"Student(name={self.name!r}, age={self.age!r})"


student = Student("小明", 18)

print(repr(student))
print(student)
```

输出：

```
Student(name='小明', age=18)
Student(name='小明', age=18)
```

调用关系：

```
repr(student)
```

实际上会触发：

```
student.__repr__()
```

不过通常应使用 `repr(student)`，不要直接调用魔法方法。

`__repr__` 也会在容器显示对象时被调用：

```
students = [
    Student("小明", 18),
    Student("小红", 19)
]

print(students)
```

输出：

```
[Student(name='小明', age=18), Student(name='小红', age=19)]
```

### 与 __str__的区别

```
class Student:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        return f"学生：{self.name}"

    def __repr__(self):
        return f"Student(name={self.name!r})"
```

```
student = Student("小明")

print(str(student))   # 学生：小明
print(repr(student))  # Student(name='小明')
```

- `__str__`：给普通用户看，强调易读。
- `__repr__`：给开发者看，强调明确和便于调试。
- 如果没有定义 `__str__`，`str(obj)` 通常会使用 `__repr__` 的结果。
- `__repr__` 必须返回字符串，否则会报错。

一句话记忆：

> `__repr__` 决定一个对象在调试、解释器和容器中“长什么样”。
