### `__del__` 析构方法

- `__del__` 是 Python 类中的**魔法方法**。
- 作用：对象被销毁前，执行一些清理操作。
- 一般不需要手动调用。

```
class Student:
    def __init__(self, name):
        self.name = name

    def __del__(self):
        print(f"{self.name} 对象被销毁了")


s1 = Student("张三")
del s1
```

可能输出：

```
张三 对象被销毁了
```

常见用途：释放资源、关闭连接等。

**一句话记忆：**

> `__del__` = 对象销毁前自动执行的清理方法。

注意：`__del__` 的执行时间不一定完全可控，实际项目中关闭文件、数据库连接等资源时，通常更推荐 `with` 等方式。
