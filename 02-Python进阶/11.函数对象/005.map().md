# `map()`

## 作用

`map()` 用来：

> 对可迭代对象中的每一个元素执行同一个函数。

语法：

```python
map(函数, 可迭代对象)
```

典型例子：

```python
nums = [1, 2, 3]

result = map(
    lambda x: x * 2,
    nums
)

print(list(result))
```

执行过程：

```text
1 → 1 * 2 → 2

2 → 2 * 2 → 4

3 → 3 * 2 → 6
```

最终：

```python
[2, 4, 6]
```

所以 `map()` 的重点是：

> 每一个元素都要经过一次函数处理。

它并不是筛选数据，而是：

> 把每个元素转换成新的结果。

### 为什么要 `list()`

`map()` 返回的是一个 `map` 可迭代对象。

所以通常写：

```python
list(result)
```

把结果取出来变成列表。

### 记忆

> `map()` = 每个元素都处理一次。
