## 什么是高阶函数

只要一个函数满足下面任意一种情况：

```text
1. 接收另一个函数作为参数

或者

2. 返回一个函数
```

它就是高阶函数。

典型例子：

```python
def double(x):
    return x * 2


def calculate(func, x):
    return func(x)
```

调用：

```python
result = calculate(double, 10)
```

这里：

```python
double
```

作为函数对象传给：

```python
func
```

所以进入 `calculate()` 后：

```python
func = double
x = 10
```

于是：

```python
func(x)
```

相当于：

```python
double(10)
```

结果：

```text
20
```

因此：

```python
calculate()
```

就是高阶函数。

### 记忆

> 高阶函数 = 能接收函数或者返回函数的函数。
