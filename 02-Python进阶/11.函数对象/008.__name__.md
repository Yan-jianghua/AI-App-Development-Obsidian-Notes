# `__name__`

## 作用

`__name__` 可以查看函数或模块的名字。

对于函数：

```python
def hello():
    pass


print(hello.__name__)
```

结果：

```text
hello
```

这里：

```python
hello.__name__
```

只是查看：

> 这个函数叫什么名字。

并不会执行函数。

这在：

```text
回调
日志
调试
装饰器
框架
```

中比较常见。

例如：

```python
def hello():
    print("你好")


def run(callback):
    print("即将执行：", callback.__name__)
    callback()


run(hello)
```

输出：

```text
即将执行： hello
你好
```

说明程序不仅可以拿到函数本身，还可以知道：

> 这个函数叫什么。

### 注意

Lambda：

```python
f = lambda x: x * 2
```

它的：

```python
f.__name__
```

通常是：

```text
<lambda>
```

因为 lambda 本身没有正常的函数名。

### 记忆

> `__name__` = 查看函数或模块的名字。
