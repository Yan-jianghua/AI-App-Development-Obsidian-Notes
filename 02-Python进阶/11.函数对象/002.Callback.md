# Callback 回调函数

## 什么是回调函数

回调函数就是：

> 把一个函数本身传给另一个函数，让另一个函数决定什么时候调用它。

典型例子：

```python
def hello():
    print("你好")


def run(callback):
    callback()


run(hello)
```

这里最重要的是：

```python
run(hello)
```

传进去的是：

```python
hello
```

这个函数本身。

进入 `run()` 后：

```python
callback
```

就指向了 `hello`。

可以理解成：

```python
callback = hello
```

于是：

```python
callback()
```

实际上就是：

```python
hello()
```

最终输出：

```text
你好
```

整个过程：

```text
run(hello)

↓

hello 函数传给 callback

↓

callback = hello

↓

callback()

↓

hello()

↓

输出“你好”
```

---

## 为什么不能写 `run(hello())`

因为：

```python
hello()
```

表示：

> 现在就执行 hello。

如果：

```python
run(hello())
```

执行顺序是：

```text
先执行 hello()

↓

输出“你好”

↓

hello 没写 return

↓

默认返回 None

↓

实际上变成：

run(None)
```

然后 `run()` 中：

```python
callback()
```

就会变成：

```python
None()
```

于是报错。

所以：

```python
run(hello)
```

表示：

> 把函数给 `run`，让 `run` 再调用。

而：

```python
run(hello())
```

表示：

> 先把函数执行完，再把执行结果传进去。

### 记忆

> Callback = 把函数本身传进去，让别人之后调用。
