![[031 90-93h 函数对象.docx]]**函数对象**就是：在 Python 里，**函数本身也是一个对象**。

比如：

```
def hello():
    print("你好")

print(hello)
```

这里的 `hello` 不加括号，表示的是**函数对象本身**；而：

```
hello()
```

才表示**调用函数**。

你可以把它理解成：

```
hello     # 函数对象
hello()   # 执行这个函数
```

因为函数是对象，所以它可以像普通变量一样：

```
def hello():
    print("你好")

a = hello
a()
```

输出：

```
你好
```

这里相当于：

```
hello ──→ 函数对象
a     ──→ 同一个函数对象
```

函数对象还可以被**作为参数传递、作为返回值返回、放进列表/字典中**。例如：

```
def add(a, b):
    return a + b

def calculate(func, x, y):
    return func(x, y)

print(calculate(add, 10, 20))
```

输出：

```
30
```

这里传进去的是：

```
calculate(add, 10, 20)
```

不是：

```
calculate(add(), 10, 20)
```

你现在记一句就够：

> **函数对象 = 函数本身；函数名不加 `()` 是对象，加 `()` 是调用函数。**
