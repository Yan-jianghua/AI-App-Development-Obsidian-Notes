# 5. `sorted()`

## 作用

`sorted()` 用来排序，并返回一个新的列表。

语法：

```python
sorted(数据, key=None, reverse=False)
```

其中最重要的是：

```python
key
```

它表示：

> 每个元素应该拿什么值作为排序依据。

典型例子：

```python
students = [
    {"name": "张三", "score": 80},
    {"name": "李四", "score": 95},
    {"name": "王五", "score": 70}
]

result = sorted(
    students,
    key=lambda x: x["score"]
)
```

这里：

```python
lambda x: x["score"]
```

是一个函数。

`sorted()` 会把每个学生依次传给这个函数。

例如：

```python
{"name": "张三", "score": 80}
```

传进去以后：

```python
x["score"]
```

得到：

```text
80
```

三个学生最终分别得到：

```text
张三 → 80
李四 → 95
王五 → 70
```

然后 `sorted()` 根据：

```text
80、95、70
```

进行排序。

最终顺序：

```text
王五
张三
李四
```

所以：

```python
key
```

不是排序结果，而是：

> 告诉 `sorted()`“应该根据什么值排序”。

### 记忆

> `sorted()` = 排序。  
> `key` = 决定按什么排序。
