# `functools.partial`

## 作用

`partial()` 用来：

> 提前固定一个函数的一部分参数，得到一个新的可调用对象。

需要：

```python
from functools import partial
```

典型例子：

```python
def power(base, exponent):
    return base ** exponent
```

如果经常计算平方：

```python
power(5, 2)
power(10, 2)
power(20, 2)
```

每次都要传：

```python
exponent=2
```

于是可以：

```python
square = partial(
    power,
    exponent=2
)
```

这里相当于：

> 提前把 `exponent` 固定成 `2`。

以后：

```python
square(5)
```

相当于：

```python
power(5, exponent=2)
```

结果：

```text
25
```

注意：

```python
square = partial(...)
```

并没有立即执行 `power()`。

它只是生成了一个新的可调用对象。

所以：

```python
callable(square)
```

结果是：

```text
True
```

### 记忆

> `partial()` = 提前给函数填好一部分参数。
