# `filter()`

## 作用

`filter()` 用来：

> 根据条件筛选数据。

语法：

```python
filter(函数, 可迭代对象)
```

这个函数需要返回真假值。

规则：

```text
True
→ 保留

False
→ 不保留
```

典型例子：

```python
nums = [1, 2, 3, 4]

result = filter(
    lambda x: x > 2,
    nums
)

print(list(result))
```

判断过程：

```text
1 > 2 → False → 不保留

2 > 2 → False → 不保留

3 > 2 → True → 保留

4 > 2 → True → 保留
```

结果：

```python
[3, 4]
```

所以 `filter()` 不负责修改元素。

它只负责判断：

> 这个元素要不要留下。
