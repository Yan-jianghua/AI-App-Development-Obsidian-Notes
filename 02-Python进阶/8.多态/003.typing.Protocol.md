# `typing.Protocol`

## 什么是 Protocol

`Protocol` 用来描述：

> 一个对象只要具有哪些属性或方法，就符合这个类型要求。

需要：

```python
from typing import Protocol
```

---

## 示例

```python
from typing import Protocol


class Speaker(Protocol):

    def speak(self) -> None:
        ...
```

这里规定：

> Speaker 类型应该拥有 `speak()` 方法。

但是实际类：

```python
class Cat:

    def speak(self) -> None:
        print("喵喵")
```

`Cat` 并没有写：

```python
class Cat(Speaker):
```

但是因为它具有：

```python
speak()
```

类型检查工具仍然可以认为它符合：

```text
Speaker
```
