# 多态

多态让不同对象通过相同接口完成同一类操作。Python 常用鸭子类型：只要对象提供所需方法就能使用，不必共享同一父类；`typing.Protocol` 可把结构化契约告诉静态检查器。

```python
from typing import Protocol

class Sender(Protocol):
    def send(self, message: str) -> None: ...

def notify(sender: Sender, message: str) -> None:
    sender.send(message)
```

抽象基类适合需要显式继承与运行时检查的场景；Protocol 适合按行为接受已有对象。调用方依赖能力而非具体类，测试可传入 fake 实现。

## 练习

分别用打印到终端和写入列表的 Sender 调用同一个 `notify`，说明何时需要运行时校验。
