# `isinstance()`

## 作用

判断对象是不是某个类或其子类的实例。

### 示例

```python
class Animal:
    pass


class Cat(Animal):
    pass


cat = Cat()
```

```python
print(isinstance(cat, Cat))
```

结果：

```text
True
```

```python
print(isinstance(cat, Animal))
```

也是：

```text
True
```

因为：

```text
Cat 是 Animal 的子类
```
