# `@abstractmethod`

## 作用

定义抽象方法：

> 子类必须实现的方法。

### 示例

```python
from abc import ABC, abstractmethod


class Animal(ABC):

    @abstractmethod
    def speak(self):
        pass
```

然后：

```python
class Cat(Animal):

    def speak(self):
        print("喵喵")
```

这样 `Cat` 实现了父类要求的：

```python
speak()
```

---

## 子类没有实现会怎样

```python
class Dog(Animal):
    pass
```

如果尝试：

```python
dog = Dog()
```

会报：

```text
TypeError
```

因为：

```text
Dog 没有实现 speak()
```

# 抽象类里能不能有普通方法

可以。

例如：

```python
from abc import ABC, abstractmethod


class Animal(ABC):

    @abstractmethod
    def speak(self):
        pass

    def eat(self):
        print("吃东西")
```

这里：

```python
speak()
```

是抽象方法。

而：

```python
eat()
```

是普通方法。

所以：

> 抽象类里的方法不必全部都是抽象方法。
> 
> # 为什么使用抽象基类

例如开发一个支付系统：

```python
class Payment(ABC):

    @abstractmethod
    def pay(self, amount):
        pass
```

不同支付方式：

```python
class Alipay(Payment):
    def pay(self, amount):
        print("支付宝支付", amount)


class WeChatPay(Payment):
    def pay(self, amount):
        print("微信支付", amount)
```

这样所有支付类都必须提供：

```python
pay()
```

这相当于制定了一套统一规范。

### 一句话记忆

> 抽象基类 = 规定子类必须遵守的接口规范。
