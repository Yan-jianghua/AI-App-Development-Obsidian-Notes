# `@property` + `@setter`

典型结构：

```python
class Student:

    def __init__(self, age):
        self._age = age

    @property
    def age(self):
        return self._age

    @age.setter
    def age(self, value):
        self._age = value
```

外部：

```python
print(s1.age)

s1.age = 20
```

内部实际操作：

```python
self._age
```
