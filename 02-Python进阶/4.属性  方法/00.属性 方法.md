# 属性与方法

实例属性属于具体对象，类属性由类共享。方法表达行为；`@property` 把计算或校验后的访问写成属性语法。避免把可变列表/字典放在类属性上当实例默认值，否则实例之间会共享。

```python
class Rectangle:
    def __init__(self, width: float, height: float) -> None:
        self.width = width
        self.height = height

    @property
    def area(self) -> float:
        return self.width * self.height
```

动态访问工具的正确名称是 `getattr`、`setattr`、`hasattr`、`delattr`；现有个别文件名中的 `setatter`、`delatter` 是拼写错误，不应照抄为代码。属性 setter 用于维护不变量，但复杂的业务操作更适合显式方法。
