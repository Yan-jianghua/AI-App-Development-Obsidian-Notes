# `getattr()`

## 作用

根据**字符串形式的属性名**获取对象属性。

### 语法

```python
getattr(对象, "属性名")
```

### 示例

```python
class Student:
    def __init__(self):
        self.name = "张三"

s1 = Student()

print(getattr(s1, "name"))
```

结果：

```text
张三
```

相当于：

```python
s1.name
```

---

## 设置默认值

```python
getattr(s1, "age", 0)
```

如果 `age` 不存在：

```text
返回 0
```

而不是报错。

### 一句话记忆

> `getattr()` = 根据属性名字符串获取属性。
