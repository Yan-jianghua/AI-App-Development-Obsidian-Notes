# `@property`

## 作用

把一个方法变成**像属性一样访问**。

例如原本：

```python
class Student:

    def get_age(self):
        return self._age
```

需要：

```python
s1.get_age()
```

使用 `@property`：

```python
class Student:

    @property
    def age(self):
        return self._age
```

就可以：

```python
print(s1.age)
```

而不是：

```python
s1.age()
```

### 一句话记忆

> `@property` = 把方法伪装成属性访问。
