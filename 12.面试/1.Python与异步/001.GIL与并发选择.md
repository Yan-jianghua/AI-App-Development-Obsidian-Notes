# GIL与并发选择

## 是什么

CPython 的 GIL 影响同一进程中 Python 字节码的并行执行，I/O 与 CPU 任务适合不同策略。

## 何时用、怎么做

I/O 密集可用 async 或线程，CPU 密集考虑进程池、原生扩展或外部任务。

## 易错点与验收

面试回答要说明解释器和工作负载，不能断言线程总无用。
