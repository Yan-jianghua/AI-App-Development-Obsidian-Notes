# Python 与异步面试题

## 语言与对象

**1. `is` 和 `==` 有何不同？** `is` 比较对象身份，`==` 调用相等性比较。判断是否为 `None` 用 `is None`；比较值用 `==`。不要依赖小整数或字符串驻留现象。

**2. 浅拷贝与深拷贝？** 浅拷贝创建外层容器但内部对象仍共享；深拷贝递归复制可复制对象，可能昂贵且对连接、锁等资源不适用。先明确是否真的需要复制。

**3. 可变默认参数为何危险？** 默认值在函数定义时创建，多次调用共享同一对象。使用 `None` 作为哨兵，在函数内新建列表。

**4. 装饰器是什么？** 接收可调用对象并返回新的可调用对象，用于日志、权限和缓存等横切逻辑。用 `functools.wraps` 保留元数据；装饰顺序从内到外构造，调用顺序反过来进入。

**5. 生成器和迭代器？** 迭代器实现 `__iter__`/`__next__`；含 `yield` 的函数调用后返回生成器，它是迭代器。惰性计算节省峰值内存，但只消费一次且异常/资源清理要注意。

## 并发与异步

**6. `async` 是否让程序更快？** 对 I/O 等待可让单进程并发处理更多请求；CPU 密集计算仍需进程、原生库或专用服务。阻塞函数放在事件循环里会拖慢其他请求。

**7. 协程、任务、线程、进程区别？** 协程在事件循环中协作切换；任务调度协程；线程共享进程内存；进程拥有独立内存与解释器。根据 I/O、CPU、隔离和开销选择。

**8. `asyncio.gather` 有什么风险？** 无上限并发会耗尽连接、文件描述符或外部配额；异常和取消行为需明确。用信号量/队列限并发并设置超时。

**9. GIL 是什么？** 在常见 CPython 构建中，解释器锁影响多个线程同时执行 Python 字节码；I/O 线程仍有价值，CPU 并行通常考虑多进程或释放 GIL 的原生扩展。具体行为随 Python 版本与构建方式变化。

## 工程题

**10. 如何定位内存上涨？** 先确认趋势与负载相关性，检查缓存无界、全局列表、连接/文件未关闭、任务堆积；用采样和对象统计定位，修复后做长时间回归。

**11. 类型提示会在运行时校验吗？** Python 注解本身不会；静态检查器、Pydantic 或显式校验各有作用。

**12. 为什么使用上下文管理器？** 把获取与释放资源成对组织，即使异常也执行清理；文件、数据库会话、锁都适用。
