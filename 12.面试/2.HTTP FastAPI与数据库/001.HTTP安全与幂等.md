# HTTP安全与幂等

## 是什么

安全方法不应改变可见资源状态，幂等方法重复执行应有相同预期效果。

## 何时用、怎么做

解释 GET、PUT、DELETE 与 POST 的典型用法，并说明业务幂等键。

## 易错点与验收

方法语义不保证实现正确，必须检查服务端副作用。

## 自测

用本节的场景举一个正常用例、一个边界用例和一个失败用例；说明你会观察哪些结果或指标来判断实现正确。
