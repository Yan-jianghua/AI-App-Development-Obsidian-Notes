# LLM、RAG 与 Agent 面试题

**1. Token 与上下文窗口？** Token 是模型处理单位；窗口限制一次输入和输出总量。长历史要检索、摘要和预算管理。

**2. 低温是否保证确定性？** 不能。模型服务版本、并行实现和上下文变化也会影响结果；用评测集验证行为。

**3. 结构化输出与工具调用区别？** 前者约束模型给用户的最终数据结构；后者让模型提出应用执行动作。工具必须在服务端校验权限与参数。

**4. RAG 与微调区别？** RAG 在推理时读取可更新证据，适合最新/私有事实与引用；微调改变模型行为或风格，不是实时事实库。可以组合。

**5. RAG 的主要失败点？** 解析、切分、索引、检索、重排、生成、引用和权限都可能失败。先检查正确证据是否被召回，再查生成。

**6. 向量检索与 BM25？** 向量擅长语义相近表达；BM25 擅长精确词、编号。混合检索经常更稳，但需数据集验证。

**7. 如何评价 RAG？** 检索层看 Recall@K/MRR/nDCG；答案层看忠实度、引用有效率、拒答与任务成功率，并关注延迟和成本。

**8. 提示注入如何防？** 外部内容视为数据；服务端限定工具权限、目标资源、预算与审批，不能只靠提示词“忽略恶意指令”。

**9. Agent 何时比工作流有价值？** 当下一步难以预先固定且工具选择能带来收益；固定流程用显式代码更可靠。Agent 要限制步骤、成本和副作用。

**10. 如何保证工具调用安全？** 模式校验、身份与对象级授权、最小权限、超时、幂等、审计和人工审批。

**11. 模型服务不可用怎么办？** 设超时、有限重试、熔断和降级；可返回缓存或明确失败，不能把重试风暴转嫁给上游。

**12. 如何控制成本？** 按任务选模型、压缩无关上下文、缓存稳定结果、限制输出/步骤/并发、记录用量并设租户预算。
