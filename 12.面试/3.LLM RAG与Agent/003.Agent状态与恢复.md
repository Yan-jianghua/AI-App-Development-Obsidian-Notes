# Agent状态与恢复

## 是什么

Agent 状态记录任务进度、工具结果和待审批动作，checkpoint 支持中断后恢复。

## 何时用、怎么做

说明恢复时如何避免工具副作用重复执行。

## 易错点与验收

仅保存聊天记录不足以恢复外部系统状态。
