# Python 常用数据结构

## 选择表

| 需求 | 结构 | 注意 |
|---|---|---|
| 按索引读取与末尾追加 | `list` | 中间插入/头部删除需搬移 |
| 不可变记录 | `tuple` | 内部对象仍可能可变 |
| 按键查找 | `dict` | 键需可哈希 |
| 去重/成员判断 | `set` | 无索引，顺序不作业务契约 |
| 双端队列 | `collections.deque` | 适合 BFS 和任务队列 |
| 最小堆 | `heapq` | 适合 Top-K 和优先级 |
| 计数 | `collections.Counter` | 方便频次统计 |

## 堆与 Top-K

```python
import heapq

scores = [4, 9, 1, 7, 3]
print(heapq.nlargest(2, scores))  # [9, 7]
```

维护大小为 `k` 的最小堆可在大量元素中找最大 `k` 个，时间约 `O(n log k)`，额外空间 `O(k)`。若数据量小，直接排序更简单。

## 队列

```python
from collections import deque

queue = deque(["a", "b"])
queue.append("c")
print(queue.popleft())  # a
```

`list.pop(0)` 频繁使用会导致搬移；`deque.popleft()` 适合先进先出。进程内 deque 不等于持久任务队列，服务重启会丢数据。

## 哈希表与可哈希性

字典通过哈希定位键。不可变不总等于可哈希：元组只有所有元素都可哈希时才可作键。自定义类若覆盖相等性，必须保证相等对象哈希一致。
