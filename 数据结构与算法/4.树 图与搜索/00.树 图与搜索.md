# 树、图与搜索

## 树

树由节点与边组成，没有环。常见遍历：前序、中序、后序和层序。二叉搜索树按大小组织节点，但若不平衡可能退化成链表；数据库索引通常使用适合磁盘/页访问的 B-tree 类结构。

## 图

图可表示依赖、社交关系、工作流和服务调用。邻接表适合稀疏图；邻接矩阵适合节点少且边密集的图。搜索要用 `visited` 防止环导致无限循环。

## BFS

无权图最短步数通常用广度优先搜索：

```python
from collections import deque

def shortest_steps(graph: dict[str, list[str]], start: str, goal: str) -> int | None:
    queue = deque([(start, 0)])
    visited = {start}
    while queue:
        node, steps = queue.popleft()
        if node == goal:
            return steps
        for neighbor in graph.get(node, []):
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, steps + 1))
    return None
```

复杂度 `O(V+E)`，其中 V 是节点数、E 是边数。带非负权重的最短路需考虑 Dijkstra；负权时不能直接使用。

## DFS 与拓扑排序

DFS 适合探索连通分量、路径和依赖循环。DAG 的拓扑排序可安排任务执行顺序；若发现环，依赖关系不合法。Agent/工作流图也需限制可循环路径和最大步数。
