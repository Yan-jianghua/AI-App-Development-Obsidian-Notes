# 查找、排序与双指针

## 二分查找

前提是数据按比较规则有序。用半开区间 `[left, right)` 可减少边界歧义：

```python
def lower_bound(nums: list[int], target: int) -> int:
    left, right = 0, len(nums)
    while left < right:
        mid = (left + right) // 2
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid
    return left
```

返回首个 `>= target` 的索引，可能等于列表长度。时间 `O(log n)`，空间 `O(1)`。Python 实际可用 `bisect` 标准库。

## 排序

Python `sorted()` 返回新列表，`list.sort()` 原地修改；两者支持 `key` 和 `reverse`。排序稳定，相同 key 的元素保留原先相对顺序。复杂度通常 `O(n log n)`，但不要依赖其作为算法题唯一答案。

## 双指针与滑动窗口

有序数组求两数之和：左指针小、右指针大，根据和移动一侧，`O(n)`。滑动窗口适合连续子数组/子串，但窗口条件必须能随着指针移动被维护。

```python
def two_sum_sorted(nums: list[int], target: int) -> tuple[int, int] | None:
    left, right = 0, len(nums) - 1
    while left < right:
        total = nums[left] + nums[right]
        if total == target:
            return left, right
        if total < target:
            left += 1
        else:
            right -= 1
    return None
```

## 后端关联

游标分页依赖稳定排序；数据库索引常利用有序结构；流式 Top-K 使用堆。算法思想要和存储、I/O 成本一起看。
