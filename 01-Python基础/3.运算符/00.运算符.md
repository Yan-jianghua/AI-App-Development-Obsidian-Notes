# 运算符

## 核心分类

- 算术：`+ - * / // % **`。`/` 总得到浮点数；`//` 向下取整，负数要特别留意。
- 比较：`== != < <= > >=`，结果为布尔值。
- 逻辑：`and or not`，`and`/`or` 短路并返回某个操作数，不一定是 `bool`。
- 成员：`in`、`not in`；身份：`is`、`is not`。
- 赋值：`= += -=` 等，复合赋值对可变对象可能原地修改。

```python
print(-7 // 3)        # -3，向负无穷方向取整
print(0 or "默认")   # 默认
print([] is [])      # False，不是同一个对象
print(3 in [1, 2, 3]) # True
```

优先使用括号表达复杂条件的意图；判断 `None` 用 `is None`，比较数值用 `==`。不要把浮点数直接用于精确金额相等比较。

## 练习

预测 `not 1 == 2`、`"" or "x"`、`-5 % 2` 的结果，再执行验证并解释原因。
