# `get()`

## 作用

根据键获取对应的值。

### 语法

```python
字典.get(key, 默认值)
```

### 示例

```python
student = {"name": "张三", "age": 20}

print(student.get("name"))
```

输出：

```text
张三
```

如果键不存在：

```python
print(student.get("score"))
```

输出：

```text
None
```

也可以指定默认值：

```python
print(student.get("score", 0))
```

输出：

```text
0
```
主要分这几种情况：

print(student.get("score", 0))

| `student`         | 结果     | 原因                        |
| ----------------- | ------ | ------------------------- |
| `{"score": 90}`   | `90`   | `score` 存在，返回它自己的值        |
| `{"score": 0}`    | `0`    | `score` 存在，而且值就是 0        |
| `{"score": 60}`   | `60`   | `score` 存在，不管是不是 0，都返回实际值 |
| `{"name": "张三"}`  | `0`    | `score` 不存在，才返回默认值 0      |
| `{"score": None}` | `None` | `score` 存在，所以返回实际值 `None` |


### 和 `[]` 的区别

```python
student["score"]
```

键不存在时会报：

```text
KeyError
```

而：

```python
student.get("score")
```

不会报错。

### 一句话记忆

> `get()`：安全地根据 key 获取 value。
