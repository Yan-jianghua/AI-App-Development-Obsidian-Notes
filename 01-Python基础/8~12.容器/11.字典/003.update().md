# 字典的 `update()`

`dict.update(other)` 把另一组键值对写入当前字典：新键会加入，已有键的值会被覆盖。它原地修改并返回 `None`，因此不要写 `d = d.update(...)`。

```python
profile = {"name": "小林", "role": "reader"}
profile.update({"role": "editor", "active": True})
print(profile)
# {'name': '小林', 'role': 'editor', 'active': True}
```

输入可以是另一个映射、键值对序列或关键字参数。`profile | patch`（较新 Python 版本支持）会创建新字典，`profile.update(patch)` 修改原字典；浅层合并不会递归合并嵌套字典。

## 易错点

- 对不可信请求体直接 `user.__dict__.update(data)` 可能让客户端改写 `role`、`id` 等服务端字段；应使用字段白名单和数据校验模型。
- `update` 不会检测业务冲突，已有值会被覆盖。
- 嵌套值仍可能共享引用；需要复制时明确是浅拷贝还是深拷贝。
