# `setdefault()`

## 作用

如果键不存在，就**添加这个键和值**；如果键已经存在，就不修改。

### 语法

```python
字典.setdefault(key, 默认值)
```

### 示例

```python
student = {"name": "张三"}

student.setdefault("age", 20)

print(student)
```

结果：

```python
{"name": "张三", "age": 20}
```

如果已经存在：

```python
student = {"age": 20}

student.setdefault("age", 30)

print(student)
```

结果仍然是：

```python
{"age": 20}
```

不会改成 `30`。
