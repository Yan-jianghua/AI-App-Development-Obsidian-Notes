# 字典 `dict`

字典把可哈希键映射到值，适合按 ID、名称快速查找。键唯一，重复赋值会覆盖旧值；遍历字典默认得到键。现代 Python 字典保留插入顺序，但若业务依赖排序，应显式排序。

```python
user = {"id": 7, "name": "小林"}
print(user.get("email"))          # None，不抛 KeyError
print(user.get("role", "reader")) # 默认值
for key, value in user.items():
    print(key, value)
```

`d[key]` 在键缺失时抛 `KeyError`；`get` 适合缺失有正常意义的场景。`setdefault` 可初始化后返回值，但不要为了简单读取而意外修改字典。需要区分键不存在和键对应 `None` 时，用 `key in d`。
