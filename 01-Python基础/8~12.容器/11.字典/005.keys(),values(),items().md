# `keys()`

## 作用

获取字典中的**所有 key**。

### 示例

```python
student = {
    "name": "张三",
    "age": 20
}

print(student.keys())
```

可以遍历：

```python
for key in student.keys():
    print(key)
```

输出：

```text
name
age
```

实际上遍历字典时：

```python
for key in student:
```

也默认遍历 key。

### 一句话记忆

> `keys()`：拿所有键。

---

# `values()`

## 作用

获取字典中的**所有 value**。

### 示例

```python
student = {
    "name": "张三",
    "age": 20
}

for value in student.values():
    print(value)
```

输出：

```text
张三
20
```

### 一句话记忆

> `values()`：拿所有值。

---

# `items()`

## 作用

同时获取字典的：

```text
key + value
```

### 示例

```python
student = {
    "name": "张三",
    "age": 20
}

for key, value in student.items():
    print(key, value)
```

输出：

```text
name 张三
age 20
```

这里：

```python
key, value
```

就是你刚学的**拆包**。

`items()` 每次产生类似：

```python
("name", "张三")
```

然后拆成：

```python
key = "name"
value = "张三"
```

### 一句话记忆

> `items()`：同时拿 key 和 value。
