
### 作用

`endswith()` 用来判断**字符串是否以指定内容结尾**。

返回值：

- 是 → `True`
    
- 不是 → `False`
    

### 语法

```
字符串.endswith(suffix, start, end)
```

- `suffix`：要判断的结尾内容，必填
    
- `start`：从哪个位置开始判断，可选
    
- `end`：判断到哪个位置结束，可选
    

### 基本用法

```
filename = "test.py"

print(filename.endswith(".py"))
```

输出：

```
True
```

因为 `"test.py"` 是以 `".py"` 结尾的。

### 判断失败

```
filename = "test.py"

print(filename.endswith(".txt"))
```

输出：

```
False
```

### 同时判断多个结尾

可以传入**元组**：

```
filename = "photo.jpg"

print(filename.endswith((".jpg", ".png", ".gif")))
```

输出：

```
True
```

只要符合其中一个结尾，就返回 `True`。

### 常见实际用途

判断文件类型：

```
filename = "data.json"

if filename.endswith(".json"):
    print("这是 JSON 文件")
```

判断图片：

```
filename = "cat.png"

if filename.endswith((".jpg", ".png", ".jpeg")):
    print("这是图片文件")
```

### 注意

`endswith()` **区分大小写**：

```
"TEST.PY".endswith(".py")
```

结果：

```
False
```

### 一句话记忆

> `endswith()`：判断字符串是不是以指定内容结尾，返回 `True` 或 `False`。
