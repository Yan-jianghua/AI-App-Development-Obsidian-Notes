## 

### 作用

`startswith()` 用来判断**字符串是否以指定内容开头**。

返回值：

- 是 → `True`
    
- 不是 → `False`
    

### 语法

```
字符串.startswith(prefix, start, end)
```

- `prefix`：要判断的开头内容，必填
    
- `start`：从字符串哪个位置开始判断，可选
    
- `end`：判断到哪个位置结束，可选
    

### 基本用法

```
name = "Python学习"

print(name.startswith("Python"))
```

输出：

```
True
```

因为 `"Python学习"` 是以 `"Python"` 开头的。

### 判断失败

```
name = "Python学习"

print(name.startswith("Java"))
```

输出：

```
False
```

### 指定开始位置

```
text = "hello Python"

print(text.startswith("Python", 6))
```

输出：

```
True
```

相当于从索引 `6` 开始判断。

### 同时判断多个开头

可以传入**元组**：

```
filename = "test.py"

print(filename.startswith(("test", "main", "app")))
```

输出：

```
True
```

只要满足其中一个就返回 `True`。

### 常见实际用途

判断网址：

```
url = "https://www.baidu.com"

if url.startswith("https://"):
    print("这是 HTTPS 地址")
```

判断特殊字符串：

```
command = "/help"

if command.startswith("/"):
    print("这是一个命令")
```

### 注意

`startswith()` **区分大小写**：

```
"Python".startswith("python")
```

结果：

```
False
```

### 一句话记忆

> `startswith()`：判断字符串是不是以指定内容开头，返回 `True` 或 `False`。
