`split()` 是字符串方法，用来按照指定的分隔符，把一个字符串拆分成列表。

基本语法：

```
字符串.split(分隔符, 最大分割次数)
```

例如：

```
text = "Python,Java,Go"

result = text.split(",")

print(result)
```

输出：

```
["Python", "Java", "Go"]
```

不指定分隔符时，会按照任意连续空白字符拆分：

```
text = "  Python   Java\nGo  "

print(text.split())
```

输出：

```
["Python", "Java", "Go"]
```

指定最大分割次数：

```
text = "a-b-c-d"

print(text.split("-", 2))
```

输出：

```
["a", "b", "c-d"]
```

注意，指定分隔符与不指定分隔符的结果可能不同：

```
text = "a  b"

print(text.split())     # ['a', 'b']
print(text.split(" "))  # ['a', '', 'b']
```

常见应用：

```
name, age = "小明,18".split(",")

print(name)  # 小明
print(age)   # 18
```

与 `join()` 配合：

```
text = "Python,Java,Go"

items = text.split(",")
result = " | ".join(items)

print(result)  # Python | Java | Go
```

相关方法 `rsplit()` 从右侧开始限制分割：

```
text = "a-b-c-d"

print(text.rsplit("-", 1))  # ['a-b-c', 'd']
```

一句话记忆：

> `split()` 把一个字符串拆成列表，`join()` 把多个字符串连接起来。
