## `encode()`

### 作用

把**字符串** `**str**` **转换成字节** `**bytes**`。

可以理解成：

```
字符串 → 编码 → 字节
```

### 语法

```
字符串.encode(encoding="utf-8")
```

最常用编码：

```
utf-8
```

### 示例

```
text = "你好"

data = text.encode("utf-8")

print(data)
print(type(data))
```

输出类似：

```
b'\xe4\xbd\xa0\xe5\xa5\xbd'
<class 'bytes'>
```

说明：

```
"你好"          # str
```

经过：

```
encode()
```

变成：

```
bytes
```

---

## `decode()`

### 作用

把**字节** `**bytes**` **转换成字符串** `**str**`。

可以理解成：

```
字节 → 解码 → 字符串
```

### 语法

```
字节.decode(encoding="utf-8")
```

### 示例

```
data = b'hello'

text = data.decode("utf-8")

print(text)
print(type(text))
```

输出：

```
hello
<class 'str'>
```

---

## `encode()` 和 `decode()` 对比

```
text = "你好 Python"

data = text.encode("utf-8")
print(data)

new_text = data.decode("utf-8")
print(new_text)
```

过程：

```
"你好 Python"
      ↓ encode()
bytes 字节数据
      ↓ decode()
"你好 Python"
```

## 为什么需要它们？

计算机中的：

- 文件
    
- 网络传输
    
- 图片
    
- HTTP 请求
    
- Socket
    
- 数据存储
    

很多底层操作处理的都是**字节** `**bytes**`，而 Python 中平时写的文本通常是：

```
str
```

因此经常需要：

```
str → bytes
```

使用：

```
encode()
```

以及：

```
bytes → str
```

使用：

```
decode()
```

---

## 编码必须对应

编码和解码最好使用相同编码：

```
text = "你好"

data = text.encode("utf-8")

text2 = data.decode("utf-8")
```

如果编码方式不匹配，可能出现：

```
乱码
```

或者：

```
UnicodeDecodeError
```
