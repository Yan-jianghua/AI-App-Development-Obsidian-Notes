## `lower()`

### 作用

把字符串中的**英文字母全部转换成小写**。

### 语法

```
字符串.lower()
```

### 示例

```
text = "Hello Python"

print(text.lower())
```

输出：

```
hello python
```

### 注意

`lower()` **不会修改原字符串**，而是返回一个新的字符串：

```
text = "Hello"

new_text = text.lower()

print(text)      # Hello
print(new_text)  # hello
```

---

## `upper()`

### 作用

把字符串中的**英文字母全部转换成大写**。

### 语法

```
字符串.upper()
```

### 示例

```
text = "Hello Python"

print(text.upper())
```

输出：

```
HELLO PYTHON
```

同样，`upper()` 也不会修改原字符串，而是返回新的字符串。

---

## 常见实际用途

### 忽略大小写进行比较

```
answer = input("请输入 yes：")

if answer.lower() == "yes":
    print("输入正确")
```

这样用户输入：

```
YES
Yes
yes
```

都可以识别。

### 统一数据格式

```
email = "TEST@QQ.COM"

email = email.lower()

print(email)
```

输出：

```
test@qq.com
```

---

## 一句话记忆

> `lower()`：全部转小写。  
> `upper()`：全部转大写。

注意：两者都会**返回新字符串，不会直接修改原字符串**。
