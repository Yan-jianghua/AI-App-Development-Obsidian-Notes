## `isdigit()`

### 作用

判断字符串中的字符是否**全部都是数字字符**。

### 语法

```
字符串.isdigit()
```

返回值：

- 全是数字 → `True`
    
- 只要有一个不是数字 → `False`
    

### 示例

```
"12345".isdigit()
```

结果：

```
True
```

```
"123a".isdigit()
```

结果：

```
False
```

```
"12.3".isdigit()
```

结果：

```
False
```

因为 `.` 不是数字。

### 常见用途

判断用户输入的是否是整数：

```
age = input("请输入年龄：")

if age.isdigit():
    print("输入的是数字")
```

## `isalpha()`

### 作用

判断字符串中的字符是否**全部都是字母字符**。

### 语法

```
字符串.isalpha()
```

返回值：

- 全是字母 → `True`
    
- 含数字、空格、符号等 → `False`
    

### 示例

```
"hello".isalpha()
```

结果：

```
True
```

```
"hello123".isalpha()
```

结果：

```
False
```

```
"hello world".isalpha()
```

结果：

```
False
```

因为中间有空格。

### 注意

中文字符也会被 `isalpha()` 认为是字母类字符：

```
"你好".isalpha()
```

结果：

```
True
```

## 对比记忆

```
"123".isdigit()      # True
"abc".isalpha()      # True
"abc123".isdigit()   # False
"abc123".isalpha()   # False
```

### 一句话记忆

> `isdigit()`：判断是不是全数字。  
> `isalpha()`：判断是不是全字母。
