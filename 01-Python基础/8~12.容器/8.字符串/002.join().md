`join()` 是字符串方法，用来把多个字符串元素连接成一个新字符串。

基本语法：

```
"连接符".join(可迭代对象)
```

例如：

```
words = ["Hello", "Python", "World"]

result = " ".join(words)

print(result)
```

输出：

```
Hello Python World
```

不同连接符：

```
items = ["Python", "Java", "Go"]

print(",".join(items))    # Python,Java,Go
print("-".join(items))    # Python-Java-Go
print("".join(items))     # PythonJavaGo
print("\n".join(items))   # 每个元素占一行
```

常见用法：

```
path = "/".join(["home", "user", "notes"])

print(path)  # home/user/notes
```

注意：参与连接的元素必须全部是字符串。

错误示例：

```
numbers = [1, 2, 3]

",".join(numbers)  # TypeError
```

需要先把数字转换成字符串：

```
numbers = [1, 2, 3]

result = ",".join(str(number) for number in numbers)

print(result)  # 1,2,3
```

`join()` 与 `split()` 的作用相反：

```
text = "Python,Java,Go"

items = text.split(",")
print(items)  # ['Python', 'Java', 'Go']

result = ",".join(items)
print(result)  # Python,Java,Go
```

一句话记忆：

> `split()` 负责拆分字符串，`join()` 负责连接字符串。
