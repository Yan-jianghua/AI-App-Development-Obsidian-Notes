`strip()` 是字符串方法，用来删除字符串两端的空白字符或指定字符。

```
text = "   hello   "

print(text.strip())
```

输出：

```
hello
```

默认删除两端的：

- 空格
- 换行符 `\n`
- 制表符 `\t`
- 回车符 `\r`

```
text = "\n\t hello \t\n"

print(text.strip())  # hello
```

它只删除两端，不会删除中间内容：

```
text = "  hello world  "

print(text.strip())  # hello world
```

还可以指定要删除的字符：

```
text = "###hello###"

print(text.strip("#"))  # hello
```

注意：参数表示“字符集合”，不是完整字符串：

```
text = "abcPythoncba"

print(text.strip("abc"))  # Python
```

Python 会不断删除两端所有属于 `a`、`b`、`c` 的字符。

相关方法：

```
text = "   hello   "

text.strip()   # 删除两端：'hello'
text.lstrip()  # 删除左侧：'hello   '
text.rstrip()  # 删除右侧：'   hello'
```

`strip()` 不会修改原字符串，而是返回一个新字符串：

```
text = "  hello  "
result = text.strip()

print(text)    # 原字符串不变
print(result)  # hello
```

一句话记忆：

> `strip()` 清理字符串两端，`lstrip()` 清理左端，`rstrip()` 清理右端。
