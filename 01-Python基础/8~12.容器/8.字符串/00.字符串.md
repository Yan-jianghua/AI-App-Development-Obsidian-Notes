# 字符串 `str`

字符串是不可变的 Unicode 文本序列。索引、切片和遍历按字符工作；编码成字节后按字节工作，两者长度可能不同。`str` 的方法通常返回新字符串，不原地修改。

```python
text = "  Python, 后端  "
clean = text.strip()
parts = clean.split(", ")
joined = " | ".join(parts)
print(joined)  # Python | 后端
print("你好".encode("utf-8"))
```

`strip` 去两端字符，`replace` 替换内容，`find` 未找到返回 `-1`，`index` 未找到抛异常。`split` 拆分，`join` 用分隔符连接。处理用户输入时要明确大小写、空白、编码和 Unicode 规范化规则；不要把 `.isdigit()` 当作完整整数解析器。
