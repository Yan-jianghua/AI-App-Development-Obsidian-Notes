`index()` 用来查找某个元素第一次出现的位置，字符串、列表、元组都可以使用。

### 字符串的 `index()`

```
text = "Hello Python"

print(text.index("Python"))  # 6
```

可以指定查找范围：

```
text = "Python Java Python"

print(text.index("Python"))     # 0
print(text.index("Python", 1))  # 12
```

如果找不到，会抛出异常：

```
text = "Hello Python"

text.index("Java")  # ValueError: substring not found
```

因此查找前可以先判断：

```
if "Java" in text:
    print(text.index("Java"))
```

### 列表的 `index()`

```
names = ["小明", "小红", "小刚"]

print(names.index("小红"))  # 1
```

如果有重复元素，只返回第一次出现的位置：

```
numbers = [10, 20, 10, 30]

print(numbers.index(10))  # 0
```

### `index()` 和 `find()` 的区别

```
text = "Hello Python"

text.find("Java")   # 找不到返回 -1
text.index("Java")  # 找不到抛出 ValueError
```

另外，只有字符串支持 `find()`，列表不支持：

```
names.index("小红")  # 可以
names.find("小红")   # 报错
```

一句话记忆：

> `index()` 找到时返回第一次出现的索引，找不到时直接报错。
