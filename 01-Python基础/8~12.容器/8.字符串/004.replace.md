`replace()` 是字符串方法，用来把字符串中的指定内容替换成新内容。

基本语法：

```
字符串.replace(旧内容, 新内容, 替换次数)
```

例如：

```
text = "I like Java"

result = text.replace("Java", "Python")

print(result)
```

输出：

```
I like Python
```

默认替换所有匹配内容：

```
text = "苹果 苹果 苹果"

print(text.replace("苹果", "香蕉"))
```

输出：

```
香蕉 香蕉 香蕉
```

可以限制替换次数：

```
text = "苹果 苹果 苹果"

print(text.replace("苹果", "香蕉", 2))
```

输出：

```
香蕉 香蕉 苹果
```

也可以用来删除内容，将新内容设置为空字符串：

```
text = "Hello World"

print(text.replace(" ", ""))  # HelloWorld
```

字符串不可变，因此 `replace()` 不会修改原字符串，而是返回一个新字符串：

```
text = "I like Java"
result = text.replace("Java", "Python")

print(text)    # I like Java
print(result)  # I like Python
```

如果想更新原变量，需要重新赋值：

```
text = text.replace("Java", "Python")
```

注意，`replace()` 直接匹配字符串，区分大小写：

```
text = "Python python"

print(text.replace("python", "Java"))
```

输出：

```
Python Java
```

一句话记忆：

> `replace()` 查找旧字符串，并返回替换后的新字符串。
