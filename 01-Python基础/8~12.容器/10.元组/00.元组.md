# 元组与拆包

元组是有序、不可增删元素的序列。它适合返回多个相关值、固定结构记录，以及在元素都可哈希时充当字典键。元组“不可变”指元素引用不能改，内部若包含列表，列表仍可修改。

```python
point = (3, 4)
x, y = point
first, *middle, last = [1, 2, 3, 4]
single = (42,)  # 单元素元组必须有逗号
```

拆包要求数量匹配，带 `*` 的目标收集剩余元素。`enumerate` 产生 `(index, value)` 对，适合循环时同时取编号和值。

## 练习

写函数返回最小值、最大值和平均值，再用拆包接收；空列表时明确处理方式。
