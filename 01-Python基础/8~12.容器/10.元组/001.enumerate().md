## `enumerate()`

### 作用

`enumerate()` 用来在遍历可迭代对象时，**同时获取索引和值**。

### 语法

```
enumerate(iterable, start=0)
```

- `iterable`：可迭代对象，例如列表、元组、字符串
    
- `start`：索引从几开始，默认是 `0`
    

---

## 基本用法

```
names = ["小明", "小红", "小刚"]

for index, name in enumerate(names):
    print(index, name)
```

输出：

```
0 小明
1 小红
2 小刚
```

其中：

```
index   # 索引
name    # 当前元素
```

---

## 指定索引从 1 开始

```
names = ["小明", "小红", "小刚"]

for index, name in enumerate(names, start=1):
    print(index, name)
```

输出：

```
1 小明
2 小红
3 小刚
```

实际项目中做编号时非常常用。

---

## 不使用 `enumerate()`

以前可能会这样写：

```
names = ["小明", "小红", "小刚"]

for i in range(len(names)):
    print(i, names[i])
```

使用 `enumerate()` 后：

```
for i, name in enumerate(names):
    print(i, name)
```

代码更简洁，也更推荐。

---

## 本质

`enumerate()` 每次会产生类似：

```
(索引, 元素)
```

例如：

```
names = ["A", "B", "C"]

print(list(enumerate(names)))
```

结果：

```
[(0, "A"), (1, "B"), (2, "C")]
```

所以：

```
for index, value in enumerate(names):
```

实际上就是把：

```
(0, "A")
```

分别拆给：

```
index
value
```

---

## 常见实际用途

给学生编号：

```
students = ["张三", "李四", "王五"]

for number, student in enumerate(students, start=1):
    print(f"{number}. {student}")
```

输出：

```
1. 张三
2. 李四
3. 王五
```
