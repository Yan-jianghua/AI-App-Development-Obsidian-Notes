# `frozenset`

## 作用

`frozenset` 是**不可修改的集合**。

普通集合：

```python
a = {1, 2, 3}
a.add(4)
```

可以修改。

而：

```python
a = frozenset([1, 2, 3])
```

创建之后不能：

```python
a.add(4)
```

因为 `frozenset` 没有 `add()`。

### 示例

```python
a = frozenset([1, 2, 3])

print(a)
```

结果类似：

```python
frozenset({1, 2, 3})
```

### 为什么需要它？

普通 `set` 可以修改，因此不能直接作为字典的 key。

但 `frozenset` 不可修改，可以作为字典键：

```python
data = {
    frozenset({1, 2}): "数据"
}
```

### 一句话记忆

> `frozenset`：冻结版 `set`，创建后不能修改。
