# `|` 并集

## 作用

获取两个集合中的**所有元素**，重复元素只保留一个。

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)
```

结果：

```python
{1, 2, 3, 4, 5}
```

也可以写：

```python
a.union(b)
```

### 图形记忆

```text
A：1 2 3
B：    3 4 5

A | B：1 2 3 4 5
```

### 一句话记忆

> `|`：两个集合全部都要。

# `&` 交集

## 作用

获取两个集合中**共同存在的元素**。

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a & b)
```

结果：

```python
{3}
```

也可以：

```python
a.intersection(b)
```

### 一句话记忆

> `&`：找双方都有的元素。

# `-` 差集

## 作用

找出：

> A 有，但是 B 没有的元素。

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a - b)
```

结果：

```python
{1, 2}
```

注意：

```python
a - b
```

和：

```python
b - a
```

不一样。

```python
print(b - a)
```

结果：

```python
{4, 5}
```

### 一句话记忆

> `A - B`：A 有、B 没有。
