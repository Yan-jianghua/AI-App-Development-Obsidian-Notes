# 集合 `set`

集合保存互不重复的可哈希元素，适合去重和成员判断；不提供按位置索引。`set()` 创建空集合，`{}` 创建空字典。

```python
a = {1, 2, 3}
b = {3, 4}
print(a & b)  # 交集 {3}
print(a | b)  # 并集
print(a - b)  # 差集
print(a ^ b)  # 对称差
```

`discard` 删除不存在元素时不报错，`remove` 会抛 `KeyError`。集合元素不能是列表等不可哈希对象；`frozenset` 自身不可变，可作字典键或另一个集合的元素。
