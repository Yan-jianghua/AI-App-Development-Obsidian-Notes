# `isdisjoint()`

## 作用

判断两个集合是否**完全没有共同元素**。

```python
a = {1, 2}
b = {3, 4}

print(a.isdisjoint(b))
```

结果：

```python
True
```

因为没有任何共同元素。

如果：

```python
a = {1, 2}
b = {2, 3}
```

那么：

```python
a.isdisjoint(b)
```

结果：

```python
False
```

因为双方都有：

```python
2
```

### 一句话记忆

> `isdisjoint()`：判断两个集合是否毫无交集。
