# `issubset()`

## 作用

判断一个集合是不是另一个集合的**子集**。

### 示例

```python
a = {1, 2}
b = {1, 2, 3, 4}

print(a.issubset(b))
```

结果：

```python
True
```

因为 `a` 中所有元素，`b` 都有。

可以理解为：

```text
a 是否完全包含在 b 里面？
```

### 一句话记忆

> `issubset()`：判断“我是不是被你完全包含”。

# `issuperset()`

## 作用

判断一个集合是不是另一个集合的**超集**。

```python
a = {1, 2}
b = {1, 2, 3, 4}

print(b.issuperset(a))
```

结果：

```python
True
```

因为：

```text
b 包含了 a 的全部元素
```

### 和 `issubset()` 对比

```python
a.issubset(b)
```

表示：

> a 是否包含在 b 中？

```python
b.issuperset(a)
```

表示：

> b 是否包含 a？

这两个在这里表达的是同一件事。

### 一句话记忆

> `issuperset()`：判断“我是不是完全包含你”。
