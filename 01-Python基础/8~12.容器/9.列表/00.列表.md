# 列表 `list`

列表有序、可变，可存不同类型对象；支持索引、切片、遍历与原地修改。索引从 0 开始，负索引从末尾计数；切片右边界不包含。

```python
tasks = ["读书", "写代码"]
tasks.append("复盘")
print(tasks[0], tasks[-1])
print(tasks[1:])
done = tasks.pop(0)
```

常用方法：`append` 加一个元素，`extend` 加入可迭代对象中的多个元素，`insert` 指定位置插入，`remove` 按值删首个匹配，`pop` 按索引删除并返回。`sort` 原地排序并返回 `None`；`sorted` 返回新列表。

列表末尾追加通常摊还 `O(1)`；头部插入/删除需搬移，约 `O(n)`。队列场景用 `collections.deque`。列表复制 `copy()`/切片是浅拷贝，嵌套对象仍共享。
