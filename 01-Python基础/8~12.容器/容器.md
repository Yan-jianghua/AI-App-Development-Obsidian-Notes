
# Python 容器总览

| 类型 | 有序 | 可变 | 重复元素 | 典型用途 |
|---|---|---|---|---|
| `str` | 是 | 否 | 可 | 文本 |
| `list` | 是 | 是 | 可 | 可修改序列 |
| `tuple` | 是 | 否 | 可 | 固定结构记录 |
| `dict` | 按插入顺序 | 是 | 键不可重复 | 按键查找 |
| `set` | 不提供索引顺序 | 是 | 不可重复 | 去重、成员判断 |

容器都可用 `len()` 求长度、用 `in` 做成员判断，但含义不同：字典的 `in` 检查键，不检查值。序列可切片；字典和集合不可按位置切片。遍历时修改容器要谨慎，尤其是字典和集合。

可以重点记这些“多个容器共同拥有的方法”：

| 方法         | 支持的容器                | 用法                | 作用           |
| ---------- | -------------------- | ----------------- | ------------ |
| `count()`  | `list` `tuple` `str` | `容器.count(元素)`    | 统计元素出现次数     |
| `index()`  | `list` `tuple` `str` | `容器.index(元素)`    | 返回元素第一次出现的位置 |
| `clear()`  | `list` `dict` `set`  | `容器.clear()`      | 清空容器         |
| `pop()`    | `list` `dict` `set`  | 不同容器用法不同          | 删除并返回元素      |
| `remove()` | `list` `set`         | `容器.remove(元素)`   | 删除指定元素       |
| `copy()`   | `list` `dict` `set`  | `新容器 = 容器.copy()` | 浅拷贝容器        |
| `update()` | `dict` `set`         | `容器.update(数据)`   | 批量添加或更新      |

同名方法也可能语义不同：`dict.pop(key)` 按键删除，`list.pop(index)` 按位置删除，`set.pop()` 删除并返回任意元素，不能把它们当作完全同一种操作。选择容器先看需求，再考虑复杂度；详见 [[数据结构与算法/数据结构与算法]]。
