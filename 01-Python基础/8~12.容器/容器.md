

可以重点记这些“多个容器共同拥有的方法”：

| 方法         | 支持的容器                | 用法                | 作用           |
| ---------- | -------------------- | ----------------- | ------------ |
| `count()`  | `list` `tuple` `str` | `容器.count(元素)`    | 统计元素出现次数     |
| `index()`  | `list` `tuple` `str` | `容器.index(元素)`    | 返回元素第一次出现的位置 |
| `clear()`  | `list` `dict` `set`  | `容器.clear()`      | 清空容器         |
| `pop()`    | `list` `dict` `set`  | 不同容器用法不同          | 删除并返回元素      |
| `remove()` | `list` `set`         | `容器.remove(元素)`   | 删除指定元素       |
| `copy()`   | `list` `dict` `set`  | `新容器 = 容器.copy()` | 浅拷贝容器        |
| `update()` | `dict` `set`         | `容器.update(数据)`   | 批量添加或更新      |
