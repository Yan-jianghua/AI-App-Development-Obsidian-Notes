# `nonlocal`

## 作用

在嵌套函数中修改**外层函数的局部变量**。

### 示例

```python
def outer():
    count = 10

    def inner():
        nonlocal count
        count = 20

    inner()
    print(count)

outer()
```

结果：

```text
20
```

这里：

```python
count
```

不是全局变量。

它属于：

```python
outer()
```

所以使用：

```python
nonlocal
```

### `global` 和 `nonlocal`

```text
global
↓
找全局变量
```

```text
nonlocal
↓
找外层函数变量
```

### 一句话记忆

> `nonlocal` = 修改外层函数中的变量。
