# 命名空间 Namespace

## 什么是命名空间

命名空间可以简单理解为：

> 存放“变量名 → 对象”对应关系的地方。

例如：

```python
age = 20
name = "张三"
```

可以简单理解成：

```text
命名空间
│
├── age  → 20
└── name → "张三"
```

---

## 常见命名空间

Python 常见：

```text
内置命名空间
全局命名空间
外层函数命名空间
局部命名空间
```

例如：

```python
x = 10

def test():
    y = 20
```

其中：

```text
x → 全局命名空间

y → test 的局部命名空间
```
