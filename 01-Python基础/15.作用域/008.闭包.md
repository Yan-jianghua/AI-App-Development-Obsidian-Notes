# 闭包 Closure

## 什么是闭包

简单理解：

> 内部函数使用了外层函数的变量，并且这个内部函数被返回出去。

### 示例

```python
def outer():
    message = "你好"

    def inner():
        print(message)

    return inner
```

调用：

```python
func = outer()
```

此时 `outer()` 已经执行结束。

但是：

```python
func()
```

仍然可以输出：

```text
你好
```

这是因为 `inner()` 仍然记住了：

```python
message
```

这就是闭包。

---

# 闭包的核心结构

一般长这样：

```python
def outer():
    外层变量 = 数据

    def inner():
        使用外层变量

    return inner
```

三个关键点：

```text
1. 有嵌套函数
2. 内部函数使用外层变量
3. 返回内部函数
```

# 闭包实际示例

创建不同倍率的乘法函数：

```python
def make_multiplier(n):

    def multiply(x):
        return x * n

    return multiply
```

创建：

```python
double = make_multiplier(2)
triple = make_multiplier(3)
```

调用：

```python
print(double(10))
print(triple(10))
```

结果：

```text
20
30
```

其中：

```python
double
```

记住：

```text
n = 2
```

而：

```python
triple
```

记住：

```text
n = 3
```

# `nonlocal` 和闭包

如果内部函数需要**修改闭包变量**：

```python
def outer():
    count = 0

    def inner():
        nonlocal count
        count += 1
        return count

    return inner
```

调用：

```python
counter = outer()

print(counter())
print(counter())
print(counter())
```

结果：

```text
1
2
3
```

这里 `count` 会一直被闭包保存。
