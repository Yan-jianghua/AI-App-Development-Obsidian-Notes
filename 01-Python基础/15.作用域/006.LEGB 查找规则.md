# LEGB 查找规则

Python 查找变量时通常按照：

```text
L → Local
E → Enclosing
G → Global
B → Built-in
```

即：

```text
局部
 ↓
外层函数
 ↓
全局
 ↓
内置
```

### 示例

```python
name = "全局"

def outer():
    name = "外层"

    def inner():
        name = "局部"
        print(name)

    inner()

outer()
```

输出：

```text
局部
```

因为 Python 首先在当前局部作用域找到了 `name`。

### 一句话记忆

> LEGB = 局部 → 外层 → 全局 → 内置。
