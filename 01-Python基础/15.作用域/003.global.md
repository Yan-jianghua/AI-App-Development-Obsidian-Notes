# `global`

## 作用

在函数内部声明：

> 我要修改的是全局变量，而不是创建局部变量。

### 示例

```python
count = 10

def test():
    global count
    count = 20

test()

print(count)
```

结果：

```text
20
```

如果没有：

```python
global count
```

例如：

```python
count = 10

def test():
    count = 20
```

这里函数内部的 `count` 是新的**局部变量**。

外面的：

```python
count
```

仍然是：

```text
10
```

### 一句话记忆

> `global` = 在函数内部修改全局变量。
