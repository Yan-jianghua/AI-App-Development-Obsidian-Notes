# 作用域

名字查找遵循 LEGB：局部 Local、外层 Enclosing、全局 Global、内置 Builtins。函数内赋值默认创建局部名字；要修改外层函数变量用 `nonlocal`，修改模块全局变量用 `global`，但更可维护的做法通常是显式参数与返回值。

```python
def counter():
    count = 0
    def next_value():
        nonlocal count
        count += 1
        return count
    return next_value
```

闭包保存对外层变量的引用，循环里创建闭包时要留意延迟绑定。后端服务不要把每个请求的用户状态放在模块全局变量里，多进程不共享且易串扰。
