# 遮蔽 Shadowing

## 什么是遮蔽

内层变量和外层变量**名字相同**时，内层变量会暂时把外层变量“挡住”。

### 示例

```python
name = "张三"

def test():
    name = "李四"
    print(name)

test()
```

输出：

```text
李四
```

函数外：

```python
print(name)
```

仍然是：

```text
张三
```

这里函数内部的：

```python
name = "李四"
```

遮蔽了全局：

```python
name = "张三"
```

---

## 内置函数也可能被遮蔽

例如：

```python
len = 100
```

这时候：

```python
len([1, 2, 3])
```

会出问题。

因为原来的内置函数：

```python
len()
```

被变量：

```python
len
```

遮蔽了。

所以不要随便使用这些名字当变量：

```python
list
dict
str
set
len
input
sum
```

### 一句话记忆

> Shadowing = 内层同名变量把外层变量挡住。
