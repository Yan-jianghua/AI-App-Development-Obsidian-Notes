`type()` 是 Python 的内置函数，用来查看对象的类型。

```
print(type(10))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type("hello"))   # <class 'str'>
print(type([1, 2]))    # <class 'list'>
```

对于自定义对象：

```
class Student:
    pass

student = Student()

print(type(student))
```

输出：

```
<class '__main__.Student'>
```

也可以用它判断类型：

```
type(10) is int       # True
type("hello") is str  # True
```

不过实际开发中，判断类型通常更推荐 `isinstance()`，因为它也能识别继承关系：

```
isinstance(10, int)          # True
isinstance(True, int)        # True
isinstance("hello", str)     # True
isinstance(10, (int, float)) # True
```

简单记忆：

- `type(obj)`：查看对象的具体类型
- isinstance(obj, 类型)`：判断对象是否属于某种类型
- `repr(obj)`：查看对象面向开发者的字符串表示
