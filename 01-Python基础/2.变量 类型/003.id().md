`id()` 是 Python 的内置函数，用来获取对象的唯一身份标识。

```
a = [1, 2]
b = a

print(id(a))
print(id(b))
```

因为 `a` 和 `b` 指向同一个对象，所以它们的 `id` 相同：

```
print(id(a) == id(b))  # True
print(a is b)          # True
```

如果内容相同，但属于两个不同对象：

```
a = [1, 2]
b = [1, 2]

print(a == b)  # True：内容相同
print(a is b)  # False：不是同一个对象
print(id(a) == id(b))  # False
```

区别可以记为：

- `==`：比较对象的内容或值
- `is`：判断是否为同一个对象
- `id(obj)`：获取对象的身份标识

在 CPython 中，`id()` 通常与对象的内存地址有关，但不应该把它当作永久内存地址使用。对象销毁后，它原来的 `id` 可能会被其他新对象重复使用。

常见用法：

```
print(id(None))
print(id(True))
print(id(object()))
```

一句话记忆：

> `id()` 相当于对象在本次程序运行期间的“身份证号码”。
