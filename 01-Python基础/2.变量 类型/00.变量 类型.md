# 变量、对象与类型

Python 变量是名字对对象的引用，不是固定类型的盒子。`a = b` 让两个名字引用同一对象；对可变对象的原地修改会被双方看见，重新赋值则只改变当前名字的绑定。

```python
a = [1]
b = a
b.append(2)
print(a)       # [1, 2]
b = [3]
print(a, b)    # [1, 2] [3]
```

常见类型有 `int`、`float`、`bool`、`str`、`NoneType` 和四种容器。`type` 查看精确类型，`isinstance` 考虑继承；`id` 可帮助理解对象身份，但不是业务 ID。浮点数有表示误差，金额优先用 `Decimal` 或整数最小单位。
