`isinstance()` 是 Python 的内置函数，用来判断一个对象是否属于某种类型。

基本语法：

```
isinstance(对象, 类型)
```

返回布尔值 `True` 或 `False`：

```
print(isinstance(10, int))        # True
print(isinstance(3.14, float))    # True
print(isinstance("hello", str))   # True
print(isinstance([1, 2], list))   # True
print(isinstance(10, str))        # False
```

可以同时判断多个类型，需要把类型放进元组：

```
number = 3.14

print(isinstance(number, (int, float)))  # True
```

### 与 type 的区别

`type()` 只判断具体类型：

```
class Animal:
    pass

class Dog(Animal):
    pass

dog = Dog()

print(type(dog) is Animal)        # False
print(isinstance(dog, Animal))    # True
```

因为 `Dog` 继承了 `Animal`，所以 `dog` 也是一种 `Animal`。

因此通常推荐：

```
isinstance(dog, Animal)
```

而不是：

```
type(dog) is Animal
```

一句话记忆：

> `isinstance()` 不仅检查对象本身的类型，还会考虑继承关系。
