## 学习验收

能解释变量与对象的关系、四种常用容器的选择、循环与函数的控制流、参数传递、作用域、文件编码与异常处理。每章至少自己改写一个示例，并预测改写后的输出。

## 综合练习

编写命令行“待办事项”程序：用 `input` 接收命令，用列表/字典保存任务，用函数组织创建、查询、完成操作，把数据以 UTF-8 JSON 写入文件；文件不存在或 JSON 损坏时给出友好错误，不直接吞掉所有异常。
