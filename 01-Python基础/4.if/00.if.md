# 条件分支 `if`

`if` 按顺序判断条件，命中第一个分支后跳过其余 `elif`/`else`。缩进决定代码块，条件表达式会转换为真值；空容器、空字符串、`0`、`None` 通常为假。

```python
def grade(score: int) -> str:
    if not 0 <= score <= 100:
        raise ValueError("score out of range")
    if score >= 90:
        return "A"
    elif score >= 60:
        return "Pass"
    else:
        return "Fail"
```

先处理非法输入和特殊情况，可减少深层嵌套。`if value is None` 与 `if not value` 不等价：后者还匹配 `0`、`""`、`[]`。检查权限时应显式写清条件，不能只靠前端控制。

## 练习

写一个登录状态函数，分别处理“未提供用户名”“用户名为空字符串”“密码错误”“登录成功”，观察条件顺序改变会怎样。
