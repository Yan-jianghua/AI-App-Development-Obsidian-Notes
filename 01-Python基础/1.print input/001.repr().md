`repr()` 是 Python 的内置函数，用来获取对象更明确、偏向开发者调试的字符串表示。

```
name = "小明\n同学"

print(str(name))
print(repr(name))
```

输出：

```
小明
同学
'小明\n同学'
```

区别：

- `str()`：方便用户阅读
- `repr()`：方便程序员调试，尽量清楚地展示对象的真实结构

在自定义类中，可以通过 _ _repr_ _ _()` 决定 `repr()` 的结果：

```
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __repr__(self):
        return f"Student(name={self.name!r}, age={self.age!r})"


student = Student("小明", 18)

print(repr(student))
```

输出：

```
Student(name='小明', age=18)
```

这里的 `!r` 表示对变量调用 `repr()`：

```
f"{self.name!r}"
```

相当于：

```
repr(self.name)
```

如果类没有定义 `__str__()`，执行 `str(obj)` 或 `print(obj)` 时，Python 通常会退而使用 `__repr__()`。

一句话记忆：

> `str()` 给用户看，`repr()` 给开发者看。


```
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

s = Student("小明", 18)
print(repr(s))
```

在 Windows 上运行，输出就是一行：

```
<__main__.Student object at 0x000001D9A1B2C3D0>
```

再拆开看这串东西对应什么：

表格

|模板部分|实际内容|说明|
|---|---|---|
|`<` `>`|尖括号|固定外壳，一眼识别这是默认模板|
|`__main__`|模块名|类定义所在的模块|
|`.`|点号|分隔符|
|`Student`|类名|类的限定名|
|`object`|固定字样|标志这是一个对象实例|
|`at`|固定字样|引出地址|
|`0x000001D9A1B2C3D0`|内存地址|`id(s)` 的十六进制，16 位大写补零|
