# 输入、输出与表示

`print(*objects, sep=' ', end='\n')` 把对象转换成适合阅读的字符串并写到标准输出；`input(prompt)` 显示提示并读取一行，返回值总是 `str`。需要数字时显式转换并处理非法输入。

```python
name = input("你的名字：").strip()
age_text = input("年龄：")
try:
    age = int(age_text)
except ValueError:
    print("年龄必须是整数")
else:
    print(f"你好，{name}；明年 {age + 1} 岁")
```

`str(obj)` 面向用户，`repr(obj)` 更偏调试，常显示引号和转义。后端程序通常通过 HTTP 请求而非 `input` 接收数据，但“输入需校验、输出需脱敏”的原则相同。
