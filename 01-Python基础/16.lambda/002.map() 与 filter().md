# `map()`

## 作用

把一个函数作用到可迭代对象的**每一个元素**上。

### 语法

```python
map(函数, 可迭代对象)
```

### 示例

```python
nums = [1, 2, 3]

result = map(lambda x: x * 2, nums)

print(list(result))
```

结果：

```python
[2, 4, 6]
```

过程：

```text
1 → 2
2 → 4
3 → 6
```

### 一句话记忆

> `map()` = 对每个元素做一次处理。

---

# `filter()`

## 作用

根据条件**筛选元素**。

### 语法

```python
filter(函数, 可迭代对象)
```

函数返回：

```text
True  → 保留
False → 删除
```

### 示例

```python
nums = [1, 2, 3, 4, 5]

result = filter(
    lambda x: x > 3,
    nums
)

print(list(result))
```

结果：

```python
[4, 5]
```

### 一句话记忆

> `filter()` = 根据条件筛选数据。

---

# `map()` 和 `filter()` 区别

```text
map
↓
修改每个元素
```

```text
filter
↓
决定哪些元素留下
```

例如：

```python
nums = [1, 2, 3]
```

```python
map(lambda x: x * 2, nums)
```

得到：

```python
[2, 4, 6]
```

而：

```python
filter(lambda x: x > 1, nums)
```

得到：

```python
[2, 3]
```

# `operator.itemgetter`

## 作用

从列表、元组、字典等对象中，按**索引或 key 获取值**。

首先：

```python
from operator import itemgetter
```

---

## 字典示例

```python
student = {
    "name": "张三",
    "score": 90
}
```

```python
get_score = itemgetter("score")

print(get_score(student))
```

结果：

```text
90
```

---

## 配合 `sorted()`

```python
students = [
    {"name": "张三", "score": 80},
    {"name": "李四", "score": 95},
    {"name": "王五", "score": 70}
]
```

可以写：

```python
sorted(students, key=itemgetter("score"))
```

它和：

```python
sorted(
    students,
    key=lambda x: x["score"]
)
```

效果基本相同。

### 一句话记忆

> `itemgetter()` = 按 key 或下标取值。
