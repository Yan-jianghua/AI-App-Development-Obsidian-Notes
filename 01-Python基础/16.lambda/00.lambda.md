## `lambda`

### 作用

`lambda` 用来定义**简单匿名函数**。

普通函数：

```python
def add(a, b):
    return a + b
```

可以写成：

```python
add = lambda a, b: a + b
```

调用：

```python
print(add(1, 2))
```

结果：

```text
3
```

### 语法

```python
lambda 参数: 表达式
```

例如：

```python
lambda x: x * 2
```

相当于：

```python
def f(x):
    return x * 2
```

### 注意

`lambda` 通常只能写一个表达式，不适合复杂逻辑。

### 一句话记忆

> `lambda` = 简短的一次性匿名函数
