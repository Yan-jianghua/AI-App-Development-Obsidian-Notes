# `sorted()`

## 作用

对可迭代对象进行排序，**返回一个新的列表**。

### 示例

```python
nums = [3, 1, 5, 2]

result = sorted(nums)

print(result)
```

结果：

```python
[1, 2, 3, 5]
```

原列表：

```python
print(nums)
```

仍然是：

```python
[3, 1, 5, 2]
```

---

## 倒序排序

```python
sorted(nums, reverse=True)
```

结果：

```python
[5, 3, 2, 1]
```

---

## 使用 `key`

```python
students = [
    {"name": "张三", "score": 80},
    {"name": "李四", "score": 95},
    {"name": "王五", "score": 70}
]
```

按成绩排序：

```python
result = sorted(
    students,
    key=lambda x: x["score"]
)
```

### 一句话记忆

> `sorted()` = 排序并返回新列表。
