# `operator.attrgetter`

## 作用

根据**对象属性名**获取属性。

首先：

```python
from operator import attrgetter
```

假设：

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score
```

创建：

```python
students = [
    Student("张三", 80),
    Student("李四", 95)
]
```

按成绩排序：

```python
result = sorted(
    students,
    key=attrgetter("score")
)
```

等价于：

```python
result = sorted(
    students,
    key=lambda x: x.score
)
```

### 一句话记忆

> `attrgetter()` = 按对象属性取值。
