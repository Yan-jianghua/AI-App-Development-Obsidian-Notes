# `itemgetter` 和 `attrgetter`

## 字典

```python
student["score"]
```

对应：

```python
itemgetter("score")
```

---

## 对象

```python
student.score
```

对应：

```python
attrgetter("score")
```

记忆：

```text
itemgetter
↓
[] 取值
```

```text
attrgetter
↓
.属性 取值
```

---

# 综合示例

```python
students = [
    {"name": "张三", "score": 80},
    {"name": "李四", "score": 95},
    {"name": "王五", "score": 70}
]
```

## 按成绩排序

```python
sorted(
    students,
    key=lambda x: x["score"]
)
```

## 找最高成绩

```python
max(
    students,
    key=lambda x: x["score"]
)
```

## 找最低成绩

```python
min(
    students,
    key=lambda x: x["score"]
)
```

## 筛选 80 分以上

```python
list(
    filter(
        lambda x: x["score"] >= 80,
        students
    )
)
```

## 只取姓名

```python
list(
    map(
        lambda x: x["name"],
        students
    )
)
```
