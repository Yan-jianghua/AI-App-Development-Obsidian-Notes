# 调用栈

## 什么是调用栈

调用栈记录：

> 当前有哪些函数正在执行，以及谁调用了谁。

例如：

```python
def a():
    b()

def b():
    c()

def c():
    print("执行 c")

a()
```

调用过程：

```text
a()
↓
b()
↓
c()
```

调用栈可以理解成：

```text
最上面：c
        b
最下面：a
```

`c()` 执行完：

```text
c 出栈
```

然后继续执行 `b()`。

`b()` 完成后：

```text
b 出栈
```

最后：

```text
a 出栈
```

### 报错信息中的调用栈

你以后看到：

```text
Traceback
```

其实就是 Python 在告诉你：

> 函数是怎么一层一层调用到报错位置的。

### 一句话记忆

> 调用栈：记录函数调用顺序。
