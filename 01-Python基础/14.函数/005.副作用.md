# 副作用

## 什么是副作用

函数除了返回结果之外，**还修改了外部状态或产生其他影响**，就叫副作用。

例如：

```python
students = []

def add_student(name):
    students.append(name)
```

这个函数修改了外部的：

```python
students
```

所以产生了副作用。

常见副作用包括：

```text
修改全局变量
修改传入的可变对象
写文件
操作数据库
发送网络请求
打印内容
```

例如：

```python
def test():
    print("hello")
```

`print()` 本身也是一种外部可观察行为。

### 一句话记忆

> 副作用：函数除了返回值，还影响了外部世界。
