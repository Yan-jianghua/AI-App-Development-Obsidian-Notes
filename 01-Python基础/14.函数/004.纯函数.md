# 纯函数

## 什么是纯函数

纯函数通常满足两个特点：

1. 相同输入，一定得到相同输出
    
2. 不修改函数外部的数据
    

### 示例

```python
def add(a, b):
    return a + b
```

调用：

```python
add(1, 2)
```

每次结果都是：

```text
3
```

而且没有修改外部变量。

所以它是典型的纯函数。

### 优点

纯函数：

- 更容易测试
    
- 更容易理解
    
- 更容易复用
    
- Bug 更少
    

### 一句话记忆

> 纯函数：只根据输入计算结果，不乱改外部数据。
