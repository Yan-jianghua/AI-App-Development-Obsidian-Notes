# 函数

函数把输入转换为输出并给一段逻辑命名。`return` 结束函数并交还结果；没有显式 `return` 时得到 `None`。参数和返回值应有清晰含义，复杂函数拆成小的业务步骤。

```python
def total_price(unit_price: int, quantity: int) -> int:
    """以分为单位计算总价。"""
    if unit_price < 0 or quantity < 0:
        raise ValueError("价格和数量不能为负")
    return unit_price * quantity
```

类型提示帮助阅读和静态检查，但本身不做运行时验证。纯函数只依赖输入并返回结果，便于测试；文件写入、打印和数据库更新属于副作用，应明确安排在边界层。
