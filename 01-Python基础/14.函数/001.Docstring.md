# Docstring

## 作用

Docstring 是**函数说明文档**。

写在函数内部第一行，通常使用三引号。

### 示例

```python
def add(a, b):
    """计算两个数字的和。"""
    return a + b
```

它主要用于说明：

- 函数做什么
    
- 参数是什么
    
- 返回什么
    

### 查看 Docstring

可以使用：

```python
help(add)
```

或者：

```python
print(add.__doc__)
```

### 一句话记忆

> Docstring：给函数写使用说明。
