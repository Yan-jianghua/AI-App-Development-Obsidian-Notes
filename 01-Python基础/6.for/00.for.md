# `for` 循环

`for` 从可迭代对象逐项取值，不限于数字计数。用 `range` 生成整数序列，`enumerate` 同时取索引和值，`zip` 并行遍历多个序列。

```python
names = ["小林", "小周"]
for index, name in enumerate(names, start=1):
    print(index, name)
```

`range(3)` 生成 0、1、2；右边界不包含。遍历字典默认取键，要取键值对用 `.items()`。若循环中修改正在遍历的列表，可能跳过元素；先创建新列表或遍历副本。

## 练习

统计一组订单金额的总和与最大值；空列表时明确返回什么，再比较内置 `sum`、`max` 的行为。
