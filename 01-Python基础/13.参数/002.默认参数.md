# 默认参数 `default`

## 作用

定义函数时提前给参数一个默认值。

### 示例

```python
def greet(name, message="你好"):
    print(message, name)
```

不传 `message`：

```python
greet("张三")
```

相当于：

```python
greet("张三", "你好")
```

也可以覆盖默认值：

```python
greet("张三", "欢迎")
```

### 规则

没有默认值的参数通常要放前面：

```python
def f(a, b=10):
    pass
```

不能普通地写成：

```python
def f(a=10, b):
    pass
```

会报语法错误。

### 一句话记忆

> 默认参数 = 不传就使用默认值。
