# `/` 之前仅位置参数

## 作用

函数参数中的 `/` 表示：

> `/` 前面的参数只能通过位置传递。

### 示例

```python
def test(a, b, /):
    print(a, b)
```

正确：

```python
test(10, 20)
```

错误：

```python
test(a=10, b=20)
```

因为：

```text
a
b
```

位于 `/` 前面。

所以只能按照位置传。

### 混合使用

```python
def test(a, /, b):
    print(a, b)
```

可以：

```python
test(10, b=20)
```

但不能：

```python
test(a=10, b=20)
```

### 一句话记忆

> `/` 前 = 只能位置传参。

---

# `*` 之后仅关键字参数

## 作用

单独的 `*` 表示：

> `*` 后面的参数只能使用关键字传递。

### 示例

```python
def test(a, *, b):
    print(a, b)
```

正确：

```python
test(10, b=20)
```

错误：

```python
test(10, 20)
```

因为：

```text
b
```

在 `*` 后面，只能写：

```python
b=20
```

### 一句话记忆

> `*` 后 = 只能关键字传参。

---

# `/` 和 `*` 一起使用

```python
def test(a, /, b, *, c):
    print(a, b, c)
```

含义：

```text
a → 只能位置参数

b → 位置参数或关键字参数都可以

c → 只能关键字参数
```

正确：

```python
test(1, 2, c=3)
```

也可以：

```python
test(1, b=2, c=3)
```

### 核心图

```text
a, /, b, *, c
↑     ↑     ↑
位置   都行   关键字
```
