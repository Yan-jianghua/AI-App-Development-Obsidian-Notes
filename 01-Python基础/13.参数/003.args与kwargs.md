# `*args`

## 作用

接收**任意数量的位置参数**。

### 示例

```python
def add(*args):
    print(args)

add(1, 2, 3)
```

输出：

```python
(1, 2, 3)
```

注意：

`args` 是一个：

```python
tuple
```

### 实际使用

```python
def add(*args):
    return sum(args)

print(add(1, 2, 3, 4))
```

结果：

```text
10
```

### 注意

真正起特殊作用的是：

```python
*
```

不是名字 `args`。

所以也能写：

```python
def test(*numbers):
    print(numbers)
```

只是大家习惯写：

```python
*args
```

### 一句话记忆

> `*args` = 收集多个位置参数，组成元组。

# `**kwargs`

## 作用

接收任意数量的**关键字参数**。

### 示例

```python
def student(**kwargs):
    print(kwargs)

student(name="张三", age=20)
```

输出：

```python
{"name": "张三", "age": 20}
```

注意：

`kwargs` 是一个：

```python
dict
```

### 遍历

```python
def student(**kwargs):
    for key, value in kwargs.items():
        print(key, value)
```

### 注意

真正起作用的是：

```python
**
```

名字不一定必须叫：

```python
kwargs
```

但这是标准习惯。

### 一句话记忆

> `**kwargs` = 收集多个关键字参数，组成字典。

---

# `*args` 和 `**kwargs`

```python
def test(*args, **kwargs):
    print(args)
    print(kwargs)

test(1, 2, name="张三", age=20)
```

结果：

```python
(1, 2)

{"name": "张三", "age": 20}
```

可以理解成：

```text
普通值 → *args → tuple

key=value → **kwargs → dict
```
