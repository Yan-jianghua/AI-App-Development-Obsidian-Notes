# 函数参数

定义时区分位置参数、仅限位置参数（`/`）、仅限关键字参数（`*`）、默认参数、`*args` 和 `**kwargs`；调用时区分传参位置与关键字。明确参数 API 有助于函数演进。

```python
def create_user(name: str, /, *, active: bool = True) -> dict:
    return {"name": name, "active": active}

create_user("小林", active=False)
```

可变默认参数会跨调用共享，使用 `None` 并在函数内创建新对象。`*args` 收集额外位置参数为元组；`**kwargs` 收集额外关键字参数为字典。滥用二者会隐藏函数真实契约。
