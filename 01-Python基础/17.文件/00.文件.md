# 文件操作

## 安全读取与写入

使用 `with` 自动关闭文件，明确编码。文本模式处理字符串，二进制模式处理字节；`w` 会覆盖，`a` 会追加。

```python
from pathlib import Path

path = Path("notes.txt")
path.write_text("你好\n", encoding="utf-8")
text = path.read_text(encoding="utf-8")
print(text)
```

大文件逐行迭代，避免 `read()` 一次加载到内存。写重要文件可先写同目录临时文件，再原子替换；仍需考虑断电、同步与备份。读取用户提供的路径要防路径遍历，并限制可访问目录。

## 练习

逐行读取日志，统计含 `ERROR` 的行数；分别测试空文件、文件不存在和非 UTF-8 内容。
