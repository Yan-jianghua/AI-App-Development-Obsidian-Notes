# `while` 循环

`while` 在条件为真时重复执行，适合“次数未知、直到满足条件”的场景。循环体必须能推进状态，否则会无限循环。

```python
attempts = 0
while attempts < 3:
    answer = input("输入 yes：")
    if answer == "yes":
        break
    attempts += 1
else:
    print("三次均未成功")
```

`else` 只在循环自然结束、未被 `break` 打断时运行。网络轮询还要设置间隔、总超时和取消条件，不能空转占满 CPU。

## 练习

实现最多 5 次猜数字；输入非法时是否计入次数由你决定，但要写在规则里并覆盖测试。
