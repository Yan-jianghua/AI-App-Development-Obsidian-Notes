# `break` 与 `continue`

`break` 立即退出最近一层循环；`continue` 跳过本轮剩余语句，进入下一轮。嵌套循环时它们只影响所在的最近一层。

```python
for value in [3, -1, 0, 8]:
    if value < 0:
        continue       # 跳过无效值
    if value == 0:
        break          # 停止处理后续输入
    print(value)
```

`for/while ... else` 的 `else` 在循环未被 `break` 终止时执行，常用于“没找到”。代码可读性优先，复杂嵌套建议提取函数并 `return`。
