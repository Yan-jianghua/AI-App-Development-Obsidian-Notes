# JSON

JSON 有对象、数组、字符串、数字、布尔和 `null`，与 Python 的 `dict`、`list`、`str`、`int/float`、`bool`、`None` 对应。JSON 不支持注释、末尾多余逗号或任意 Python 对象。

```python
import json
from pathlib import Path

data = {"name": "小林", "active": True}
Path("user.json").write_text(
    json.dumps(data, ensure_ascii=False, indent=2),
    encoding="utf-8",
)
loaded = json.loads(Path("user.json").read_text(encoding="utf-8"))
```

`dumps/loads` 处理字符串，`dump/load` 处理文件对象。解析不可信 JSON 时限制文件大小与嵌套复杂度；捕获 `JSONDecodeError` 后给出明确错误，不默默使用空数据覆盖损坏文件。
