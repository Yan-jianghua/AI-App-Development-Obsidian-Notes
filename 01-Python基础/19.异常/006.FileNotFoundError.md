# `FileNotFoundError`

## 作用

尝试打开一个**不存在的文件**。

### 示例

```python
with open("data.txt", "r", encoding="utf-8") as f:
    print(f.read())
```

如果：

```text
data.txt
```

不存在，就会报：

```text
FileNotFoundError
```

### 处理

```python
try:
    with open("data.txt", "r", encoding="utf-8") as f:
        data = f.read()

except FileNotFoundError:
    print("文件不存在")
```

### 一句话记忆

> `FileNotFoundError` = 要读取的文件找不到。
