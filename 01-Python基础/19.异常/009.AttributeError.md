# `AttributeError`

## 作用

访问对象不存在的属性或方法时产生。

### 示例

```python
class Student:
    pass

s1 = Student()

print(s1.name)
```

因为没有：

```python
name
```

所以报：

```text
AttributeError
```

---

## 调用不存在的方法

```python
s1.run()
```

如果 `Student` 没有：

```python
run
```

同样：

```text
AttributeError
```

---

## 常见解决方式

判断：

```python
if hasattr(s1, "name"):
    print(s1.name)
```

或者：

```python
name = getattr(s1, "name", None)
```

### 一句话记忆

> `AttributeError` = 对象没有你访问的这个属性或方法。
