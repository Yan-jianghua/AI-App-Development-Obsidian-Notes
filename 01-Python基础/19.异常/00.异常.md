# 异常处理

异常沿调用栈向上传播，直到被匹配的 `except` 捕获。只捕获自己能处理的具体异常；`finally` 常用于清理，`else` 只在 `try` 成功时执行。

```python
try:
    age = int(text)
except ValueError as exc:
    raise ValueError("年龄必须是整数") from exc
else:
    save(age)
finally:
    close_if_open()
```

业务异常可定义明确错误码和含义，交给 API 边界映射为 4xx；未知错误记录日志后返回通用 500。不要 `except Exception: pass`，这会吞掉真正故障。资源清理优先使用 `with`。
