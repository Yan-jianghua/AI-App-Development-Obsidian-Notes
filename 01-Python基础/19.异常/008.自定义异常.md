# 自定义异常

## 为什么需要自定义异常

有时候 Python 自带异常不能准确表达你的业务问题。

例如：

> 学生成绩不能小于 0 或大于 100。

可以自己定义异常。

---

# 定义自定义异常

### 语法

```python
class 自定义异常名(Exception):
    pass
```

例如：

```python
class ScoreError(Exception):
    pass
```

表示：

```text
ScoreError
```

继承：

```text
Exception
```

---

# 使用 `raise` 抛出异常

```python
class ScoreError(Exception):
    pass


def set_score(score):
    if score < 0 or score > 100:
        raise ScoreError("成绩必须在 0~100 之间")

    return score
```

调用：

```python
set_score(150)
```

会抛出：

```text
ScoreError
```

---

# 捕获自定义异常

```python
try:
    set_score(150)

except ScoreError as e:
    print(e)
```

输出：

```text
成绩必须在 0~100 之间
```

---

# 自定义异常为什么继承 `Exception`

```python
class ScoreError(Exception):
    pass
```

表示：

```text
ScoreError
        ↓
Exception
```

所以：

```python
except Exception:
```

也能捕获 `ScoreError`。

但更推荐：

```python
except ScoreError:
```

这样更明确。
