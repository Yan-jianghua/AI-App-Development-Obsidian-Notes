# `JSONDecodeError`

## 作用

JSON 字符串格式错误，导致**无法解析 JSON**。

需要：

```python
import json
```

### 示例

```python
import json

data = '{"name": "张三",}'

json.loads(data)
```

因为最后多了：

```text
,
```

不是合法 JSON。

会报：

```text
JSONDecodeError
```

---

## 捕获异常

`JSONDecodeError` 在：

```python
json
```

模块中，可以这样写：

```python
import json

try:
    data = json.loads('{"name": "张三",}')

except json.JSONDecodeError:
    print("JSON 格式错误")
```

### 一句话记忆

> `JSONDecodeError` = JSON 格式不合法。
