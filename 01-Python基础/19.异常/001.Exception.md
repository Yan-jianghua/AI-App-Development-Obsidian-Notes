## `Exception`

### 作用

`Exception` 是 Python 中大多数普通异常的**父类**。

很多常见异常都属于它的子类，例如：

```text
ValueError
TypeError
KeyError
IndexError
FileNotFoundError
```

### 示例

```python
try:
    x = int("abc")
except Exception as e:
    print(e)
```

### 注意

虽然可以写：

```python
except Exception:
```

但实际开发中更推荐尽量捕获**具体异常类型**。

### 一句话记忆

> `Exception` = 大多数普通异常的父类。
