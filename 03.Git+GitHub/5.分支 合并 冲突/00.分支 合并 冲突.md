## 为什么使用分支

分支让不同任务在互不影响的历史线上进行：

```text
main:       A──B─────────M
                \       /
feature:         C──D───
```

常见做法是从 `main` 创建功能分支，完成、测试和评审后再合并回 `main`。

## 基本流程

```bash
git switch main
git pull --ff-only
git switch -c feature/login
# 修改、测试、提交
git switch main
git merge feature/login
```

### 一句话记忆

> 一个分支处理一个目标，完成后通过合并把成果带回主线。
