# `git branch` 与 `git switch`

## 查看分支

```bash
git branch
git branch -a
git branch -vv
```

当前分支前会显示 `*`。`-a` 包含远程跟踪分支，`-vv` 显示上游关系和最近提交。

## 创建和切换

```bash
git branch feature/login
git switch feature/login
```

一步完成：

```bash
git switch -c feature/login
```

从指定位置创建：

```bash
git switch -c hotfix/login main
```

`git checkout -b feature/login` 是传统写法；现代 Git 中，切换分支优先使用含义更清晰的 `switch`。

## 重命名和删除

```bash
git branch -m feature/sign-in
git branch -d feature/login
git branch -D feature/login
```

- `-d`：只删除已经合并的分支，较安全。
- `-D`：强制删除，即使分支含未合并提交。

删除分支只删除分支引用。已合并提交仍在目标分支历史中。

## 分支很轻量

分支本质是指向提交的可移动引用，不是完整复制一份项目，所以创建和切换通常很快。

### 一句话记忆

> `branch` 管分支引用，`switch` 切换当前工作位置。
