# `git branch` 与 `git switch`

## 查看分支

```bash
# 列出本地分支，并用星号标出当前分支。
git branch
# 列出本地及远程跟踪分支。
git branch -a
# 列出本地分支及其上游、领先或落后信息。
git branch -vv
```

当前分支前会显示 `*`。`-a` 包含远程跟踪分支，`-vv` 显示上游关系和最近提交。

## 创建和切换

```bash
# 创建指向当前提交或指定提交的分支，但不切换。
git branch feature/login
# 切换到指定已有分支；后续 merge 的接收方就是这个当前分支。
git switch feature/login
```

一步完成：

```bash
# 创建并切换到新分支；末尾若有提交或分支名，则从那里创建。
git switch -c feature/login
```

从指定位置创建：

```bash
# 创建并切换到新分支；末尾若有提交或分支名，则从那里创建。
git switch -c hotfix/login main
```

`git checkout -b feature/login` 是传统写法；现代 Git 中，切换分支优先使用含义更清晰的 `switch`。

## 重命名和删除

```bash
# 重命名当前分支；不自动重命名远程分支。
git branch -m feature/sign-in
# 删除已合并的本地分支；未合并时 Git 会拒绝。
git branch -d feature/login
# 强制删除本地分支，即使未合并也会删除分支引用。
git branch -D feature/login
```

- `-d`：只删除已经合并的分支，较安全。
- `-D`：强制删除，即使分支含未合并提交。

删除分支只删除分支引用。已合并提交仍在目标分支历史中。

## 分支很轻量

分支本质是指向提交的可移动引用，不是完整复制一份项目，所以创建和切换通常很快。

### 一句话记忆

> `branch` 管分支引用，`switch` 切换当前工作位置。
