# `git blame`

## 作用

查看文件每一行最后由哪次提交修改：

```bash
git blame app.py
git blame -L 20,40 app.py
```

输出包含提交哈希、作者、时间、行号和内容。拿到哈希后继续查看原因：

```bash
git show <提交哈希>
```

## 正确用途

- 找到某段代码的历史背景。
- 定位引入行为变化的提交。
- 找到可能了解上下文的人。

`blame` 的目标是理解上下文，不是追责。代码可能经过移动、格式化或重构，单行最后修改者也不一定是原始设计者。

### 一句话记忆

> `blame` 是查一行代码的历史入口，不是追责工具。
