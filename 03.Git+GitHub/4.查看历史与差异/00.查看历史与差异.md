# 查看历史与差异

[[001.git diff]]
[[002.git log与git show]]
[[003.git blame]]

```text
# 查看当前分支及工作区、暂存区状态；-s 用简短格式显示。
git status → 当前有哪些变化
# 比较指定的两个提交或分支的文件内容。
git diff → 具体改了什么
# 查看提交历史；--oneline 压缩每条，--graph 画分支图，--all 包含所有引用，--decorate 标注分支/标签。
git log → 历史上发生过什么
# 查看指定提交或标签的详情；--stat 只看统计，提交:路径可看历史文件内容。
git show → 某次提交包含什么
# 查看文件每行最近一次修改的提交；-L 只看指定行号范围。
git blame → 某行最近由哪次提交改变
```

### 一句话记忆

> Git 不只负责保存历史，也负责解释变化。
