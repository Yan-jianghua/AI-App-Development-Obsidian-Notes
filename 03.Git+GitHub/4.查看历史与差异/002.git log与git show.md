# `git log` 与 `git show`

## 查看历史

```bash
git log
git log --oneline
git log --oneline --graph --all --decorate
git log -5
```

按作者或说明搜索：

```bash
git log --author="yjh"
git log --grep="login"
```

查看某个文件的历史：

```bash
git log --oneline -- app.py
git log -p -- app.py
```

## 查看某次提交

```bash
git show a3f97c1
git show --stat a3f97c1
git show a3f97c1:src/app.py
```

最后一条只输出该提交中的文件内容，不会修改当前文件。

### 一句话记忆

> `log` 浏览历史，`show` 打开一个具体历史节点。
