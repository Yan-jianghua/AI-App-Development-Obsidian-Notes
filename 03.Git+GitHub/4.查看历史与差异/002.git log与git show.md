# `git log` 与 `git show`

## 查看历史

```bash
# 查看提交历史；--oneline 压缩每条，--graph 画分支图，--all 包含所有引用，--decorate 标注分支/标签。
git log
# 只查看指定文件的提交历史；-- 将路径和选项分开。
git log --oneline
# 只查看指定文件的提交历史；-- 将路径和选项分开。
git log --oneline --graph --all --decorate
# 查看提交历史；--oneline 压缩每条，--graph 画分支图，--all 包含所有引用，--decorate 标注分支/标签。
git log -5
```

按作者或说明搜索：

```bash
# 按作者筛选提交历史。
git log --author="yjh"
# 按提交说明中的关键词筛选历史。
git log --grep="login"
```

查看某个文件的历史：

```bash
# 只查看指定文件的提交历史；-- 将路径和选项分开。
git log --oneline -- app.py
# 查看指定文件的提交历史及每次补丁。
git log -p -- app.py
```

## 查看某次提交

```bash
# 查看指定提交或标签的详情；--stat 只看统计，提交:路径可看历史文件内容。
git show a3f97c1
# 查看指定提交或标签的详情；--stat 只看统计，提交:路径可看历史文件内容。
git show --stat a3f97c1
# 查看指定提交或标签的详情；--stat 只看统计，提交:路径可看历史文件内容。
git show a3f97c1:src/app.py
```

最后一条只输出该提交中的文件内容，不会修改当前文件。

### 一句话记忆

> `log` 浏览历史，`show` 打开一个具体历史节点。
