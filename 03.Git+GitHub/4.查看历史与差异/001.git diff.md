# `git diff`

## 三种最常见比较

```bash
git diff             # 工作区与暂存区
git diff --staged    # 暂存区与最新提交
git diff HEAD        # 当前全部修改与最新提交
```

## 比较提交或分支

```bash
git diff HEAD~1 HEAD
git diff main feature/login
git diff main...feature/login
```

`main...feature/login` 常用于查看功能分支从共同祖先开始引入了哪些变化。

```bash
git diff --name-status main...feature/login
git diff --stat
```

## 如何读输出

```diff
-old_value = 1
+new_value = 2
```

- `-` 表示旧版本中被删除的行。
- `+` 表示新版本中新增的行。

`git diff` 没输出不一定没有改动。修改可能已暂存，此时使用 `git diff --staged`。

### 一句话记忆

> 普通 `diff` 看未暂存，`diff --staged` 看将要提交。
