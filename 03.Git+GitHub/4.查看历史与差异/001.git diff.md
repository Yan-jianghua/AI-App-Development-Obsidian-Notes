# `git diff`

## 三种最常见比较

```bash
# 比较工作区与暂存区，查看还没暂存的内容。
git diff             # 工作区与暂存区
# 比较暂存区与最新提交；--staged 和 --cached 等价。
git diff --staged    # 暂存区与最新提交
# 比较工作区最终内容与最新提交，包含已暂存和未暂存改动。
git diff HEAD        # 当前全部修改与最新提交
```

## 比较提交或分支

```bash
# 比较指定的两个提交或分支的文件内容。
git diff HEAD~1 HEAD
# 比较指定的两个提交或分支的文件内容。
git diff main feature/login
# 比较共同祖先到右侧分支的改动，适合看功能分支引入了什么。
git diff main...feature/login
```

`main...feature/login` 常用于查看功能分支从共同祖先开始引入了哪些变化。

```bash
# 只看差异文件名及新增、修改、删除状态。
git diff --name-status main...feature/login
# 只看差异的文件与增删行数统计。
git diff --stat
```

## 如何读输出

```diff
-old_value = 1
+new_value = 2
```

- `-` 表示旧版本中被删除的行。
- `+` 表示新版本中新增的行。

`git diff` 没输出不一定没有改动。修改可能已暂存，此时使用 `git diff --staged`。

### 一句话记忆

> 普通 `diff` 看未暂存，`diff --staged` 看将要提交。
