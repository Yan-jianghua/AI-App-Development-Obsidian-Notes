# `git fetch` 与 `git pull`

## `git fetch`

```bash
git fetch origin
```

下载远程的新对象和引用，更新 `origin/main` 等远程跟踪分支，但不自动改变当前工作区。

获取后先查看：

```bash
git log --oneline --graph --all --decorate
git diff main..origin/main
```

## `git pull`

概念上：

```text
git pull = git fetch + 整合到当前分支
```

整合方式可能是 merge、rebase 或仅快进，由参数与配置决定。

```bash
git pull --ff-only
git pull --rebase
```

- `--ff-only`：只有能直接快进时才更新，行为最保守。
- `--rebase`：把本地未推送提交重新应用到远程最新提交之后。

## 为什么推荐先理解 fetch

`pull` 一次完成两步，遇到冲突时初学者容易不知道冲突从哪里来。`fetch` 后先观察，再决定 merge 或 rebase，更容易理解。

### 一句话记忆

> `fetch` 只拿信息，`pull` 拿完后还会整合当前分支。
