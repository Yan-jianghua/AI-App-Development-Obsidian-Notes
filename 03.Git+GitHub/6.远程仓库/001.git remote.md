# `git remote`

## 查看远程仓库

```bash
git remote
git remote -v
git remote show origin
```

`origin` 只是默认常用名称，不是 Git 的关键字。

## 添加远程

```bash
git remote add origin https://github.com/OWNER/REPO.git
```

验证：

```bash
git remote -v
```

## 修改 URL

```bash
git remote set-url origin git@github.com:OWNER/REPO.git
```

常用于 HTTPS 与 SSH 地址之间切换。

## 重命名和删除

```bash
git remote rename origin github
git remote remove github
```

删除远程配置不会删除 GitHub 上的仓库，也不会删除已有本地提交。

## `remote origin already exists`

表示已经有名为 `origin` 的远程。先查看：

```bash
git remote -v
```

如果 URL 错了，用 `set-url`，不要重复 `add`。

### 一句话记忆

> remote 是远程地址的本地别名，`origin` 只是最常用的那个名字。
