# `git stash`

## 使用场景

正在开发功能但尚不适合提交，突然需要切换分支修复紧急问题，可以临时收起修改。

```bash
git stash push -m "WIP: 登录页面布局"
```

默认主要保存已跟踪文件的修改。

包括未跟踪文件：

```bash
git stash push -u -m "WIP: 登录页面布局"
```

## 查看和恢复

```bash
git stash list
git stash show -p stash@{0}
git stash apply stash@{0}
```

`apply` 恢复但保留 stash 记录。

```bash
git stash pop
```

`pop` 尝试恢复并在成功后删除对应记录。发生冲突时仍需手动解决。

## 删除

```bash
git stash drop stash@{0}
git stash clear
```

`clear` 删除全部 stash，恢复困难，使用前仔细确认。

## 注意

stash 适合短期切换现场，不应成为长期存档。重要进度更适合在独立分支创建清晰的 WIP 提交。

### 一句话记忆

> stash 是临时抽屉，不是长期仓库。
