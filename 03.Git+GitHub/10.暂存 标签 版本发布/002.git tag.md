# `git tag`

## 标签是什么

标签给某个提交一个稳定名字，常用于版本号：

```text
v1.0.0 → a3f97c1
```

分支会随新提交移动，标签通常固定不动。

## 附注标签

推荐创建包含标签者、时间和说明的附注标签：

```bash
git tag -a v1.0.0 -m "首次稳定版本"
```

给旧提交打标签：

```bash
git tag -a v0.9.0 a3f97c1 -m "测试版本"
```

## 查看标签

```bash
git tag
git tag -l "v1.*"
git show v1.0.0
```

## 推送标签

普通 `git push` 不一定推送标签：

```bash
git push origin v1.0.0
git push origin --tags
```

## 删除标签

```bash
git tag -d v1.0.0
git push origin --delete v1.0.0
```

已发布标签应尽量保持不可变。如果版本有问题，通常发布新修复版本，而不是悄悄把同名标签指向另一个提交。

### 一句话记忆

> 分支指向正在前进的工作线，标签固定标记一个版本点。
