# GitHub Release 与语义化版本

## Release

GitHub Release 通常基于 Git 标签，面向使用者提供：

- 版本说明。
- 变更摘要。
- 已知问题。
- 升级说明。
- 二进制包或其他构建产物。

标签是 Git 概念，Release 是 GitHub 在标签之上提供的发布页面。

## 语义化版本

常见格式：

```text
主版本.次版本.修订号
MAJOR.MINOR.PATCH
```

例如 `2.4.1`：

- MAJOR：不兼容的重大变化。
- MINOR：向后兼容的新功能。
- PATCH：向后兼容的问题修复。

预发布示例：

```text
v2.0.0-alpha.1
v2.0.0-beta.1
v2.0.0-rc.1
```

## 发布前检查

- 测试全部通过。
- 版本号和变更日志已更新。
- 数据库或配置迁移有说明。
- 标签指向正确提交。
- 构建产物可复现且不含秘密。

### 一句话记忆

> 标签标记代码位置，Release 解释这个版本对使用者意味着什么。
