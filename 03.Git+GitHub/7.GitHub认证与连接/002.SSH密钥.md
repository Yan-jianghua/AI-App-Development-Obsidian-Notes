# SSH 密钥

## 原理

SSH 使用一对密钥：

```text
私钥 → 只保存在自己的电脑，绝不分享
公钥 → 添加到 GitHub 账号
```

## 生成密钥

```bash
# 生成 SSH 公钥和私钥；只把公钥添加到 GitHub，私钥留在本机。
ssh-keygen -t ed25519 -C "your_email@example.com"
```

按提示选择保存位置并建议设置口令。

## 启动代理并添加私钥

Git Bash：

```bash
# 在 Bash 中启动 SSH 代理；PowerShell 的启动方式不同。
eval "$(ssh-agent -s)"
# 把指定私钥加载到 SSH 代理，供连接 GitHub 使用。
ssh-add ~/.ssh/id_ed25519
```

复制公钥文件 `~/.ssh/id_ed25519.pub` 的完整内容，添加到 GitHub 的 SSH keys 设置中。不要上传没有 `.pub` 后缀的私钥。

## 测试连接

```bash
# 测试 GitHub SSH 认证是否成功，不执行远程 Shell。
ssh -T git@github.com
```

第一次可能询问是否信任主机指纹。应与 GitHub 官方公布的指纹核对，再确认。

## SSH 远程地址

```text
git@github.com:OWNER/REPO.git
```

切换现有远程：

```bash
# 修改已配置远程的地址，例如 HTTPS 改为 SSH。
git remote set-url origin git@github.com:OWNER/REPO.git
```

### 一句话记忆

> 公钥交给 GitHub，私钥永远留在自己的设备上。
