# 日常协作流程

## 开始任务

```bash
git switch main
git pull --ff-only
git switch -c feature/task-name
```

## 开发过程中

```bash
git status
git diff
git add -p
git diff --staged
git commit -m "feat: 完成某项功能"
```

小步提交，但每次提交应保持逻辑完整。

## 推送并创建 PR

```bash
git push -u origin feature/task-name
```

在 PR 中说明问题、修改、验证方式和风险。

## 跟进主分支变化

按团队约定选择 rebase 或 merge：

```bash
git fetch origin
git rebase origin/main
```

如果已推送自己的分支，rebase 后通常需要：

```bash
git push --force-with-lease
```

仅对自己的功能分支这样做。

## 合并之后

```bash
git switch main
git pull --ff-only
git branch -d feature/task-name
git fetch --prune
```

`--prune` 清理本地已经失效的远程跟踪引用，不会删除仍存在的本地分支。

### 一句话记忆

> 从最新主线开分支，在功能分支提交，通过 PR 回到主线。
