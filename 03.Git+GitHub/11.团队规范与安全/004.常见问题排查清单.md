# 常见问题排查清单

## 不知道自己在哪里

```bash
# 查看当前分支及工作区、暂存区状态；-s 用简短格式显示。
git status
# 只显示当前分支名。
git branch --show-current
# 只查看指定文件的提交历史；-- 将路径和选项分开。
git log --oneline --decorate -5
```

## 提交后 GitHub 没变化

`commit` 只在本地。检查并推送：

```bash
# 查看当前分支及工作区、暂存区状态；-s 用简短格式显示。
git status
# 列出本地分支及其上游、领先或落后信息。
git branch -vv
# 把当前分支的提交推送到已配置的上游。
git push
```

## `nothing to commit`

可能是：

- 文件没有保存。
- 当前目录不是预期仓库。
- 文件被 `.gitignore` 忽略。
- 修改已经提交。

```bash
# 查看当前分支及工作区、暂存区状态；-s 用简短格式显示。
git status
# 比较工作区与暂存区，查看还没暂存的内容。
git diff
# 检查路径匹配哪条忽略规则；-v 显示规则来源。
git check-ignore -v <文件>
```

## `pathspec did not match`

常见于分支名或路径写错：

```bash
# 列出本地及远程跟踪分支。
git branch -a
# 查看当前分支及工作区、暂存区状态；-s 用简短格式显示。
git status
```

## 推送被拒绝

检查错误属于哪类：

```text
Authentication failed      → 凭据问题
Permission denied          → SSH 或仓库权限
non-fast-forward           → 远程有新提交
protected branch           → 必须走 PR 或满足规则
secret scanning blocked    → 移除并轮换秘密
```

## 安全求助信息

可以提供：

```bash
# 查看当前分支及工作区、暂存区状态；-s 用简短格式显示。
git status
# 列出远程名称及拉取、推送地址；不下载内容。
git remote -v
# 列出本地分支及其上游、领先或落后信息。
git branch -vv
# 只查看指定文件的提交历史；-- 将路径和选项分开。
git log --oneline --graph --decorate --all -15
```

分享前隐藏仓库私有地址、用户名、Token 和其他敏感信息。

### 一句话记忆

> 先读完整错误，再用 status、branch、remote 和 log 确认现场。
