# 常见问题排查清单

## 不知道自己在哪里

```bash
git status
git branch --show-current
git log --oneline --decorate -5
```

## 提交后 GitHub 没变化

`commit` 只在本地。检查并推送：

```bash
git status
git branch -vv
git push
```

## `nothing to commit`

可能是：

- 文件没有保存。
- 当前目录不是预期仓库。
- 文件被 `.gitignore` 忽略。
- 修改已经提交。

```bash
git status
git diff
git check-ignore -v <文件>
```

## `pathspec did not match`

常见于分支名或路径写错：

```bash
git branch -a
git status
```

## 推送被拒绝

检查错误属于哪类：

```text
Authentication failed      → 凭据问题
Permission denied          → SSH 或仓库权限
non-fast-forward           → 远程有新提交
protected branch           → 必须走 PR 或满足规则
secret scanning blocked    → 移除并轮换秘密
```

## 安全求助信息

可以提供：

```bash
git status
git remote -v
git branch -vv
git log --oneline --graph --decorate --all -15
```

分享前隐藏仓库私有地址、用户名、Token 和其他敏感信息。

### 一句话记忆

> 先读完整错误，再用 status、branch、remote 和 log 确认现场。
