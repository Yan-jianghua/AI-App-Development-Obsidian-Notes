# Repository 与 README

## 创建仓库时的选择

- Public：任何人可查看。
- Private：只有授权用户可查看。
- README：项目入口说明。
- `.gitignore`：忽略语言或工具生成文件。
- License：说明别人如何合法使用项目。

## 本地已有项目时

在 GitHub 创建空仓库时，通常不勾选初始化 README、`.gitignore` 和 License，避免本地与远程各有一次无关初始提交。

然后：

```bash
git remote add origin https://github.com/OWNER/REPO.git
git push -u origin main
```

## README 建议内容

```markdown
# 项目名称

一句话说明项目用途。

## 环境要求

## 安装

## 运行

## 测试

## 配置说明

## 许可证
```

README 应让第一次接触项目的人能回答：项目做什么、如何运行、如何验证。

### 一句话记忆

> Repository 装项目历史，README 帮人从零开始使用项目。
