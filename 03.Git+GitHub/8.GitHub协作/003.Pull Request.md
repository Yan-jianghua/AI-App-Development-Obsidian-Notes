# Pull Request

## PR 是什么

Pull Request 是“请求把一个分支的修改合并到另一个分支”，同时提供讨论、评审和自动检查页面。

## 创建前检查

```bash
git status
git log --oneline main..HEAD
git diff --stat main...HEAD
```

确认：

- 分支目标正确。
- 没有无关文件。
- 测试通过。
- 没有密钥和隐私数据。
- 提交历史可理解。

## 好的 PR 描述

```markdown
## 问题
登录接口在空密码时返回 500。

## 修改
- 增加空密码校验
- 返回明确的 400 错误
- 添加回归测试

## 验证
- `pytest tests/test_login.py` 通过
```

## 更新 PR

PR 创建后继续向同一分支 push，新提交会自动出现在 PR 中：

```bash
git add .
git commit -m "test: 补充空密码用例"
git push
```

## 合并方式

- Merge commit：保留完整分支和合并节点。
- Squash and merge：把 PR 多个提交压成一个。
- Rebase and merge：线性地重放提交。

选择应遵循仓库规范。

### 一句话记忆

> PR 是围绕一组修改进行检查、解释和协作的载体。
