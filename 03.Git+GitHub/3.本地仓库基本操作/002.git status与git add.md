# `git status` 与 `git add`

## `git status`

显示当前分支、未跟踪文件、已修改文件和已暂存内容：

```bash
git status
git status -s
```

建议每次 Git 操作前后都查看一次。

## `git add`

```bash
git add app.py                 # 暂存一个文件
git add app.py test_app.py     # 暂存多个文件
git add .                      # 暂存当前目录的全部变化
git add -p                     # 分块选择
```

`-p` 会把修改分成多个区块，让你决定每一块是否进入本次提交。

## 取消暂存

保留工作区修改，只把文件移出暂存区：

```bash
git restore --staged app.py
```

## 常见误区

`git add` 不只用于新文件。已跟踪文件修改后，也要重新 `add`，把新版本放进暂存区。

```text
编辑一次 → add → 又编辑一次
```

第二次编辑不会自动进入暂存区，需要再次 `add`。

### 一句话记忆

> `status` 看状态，`add` 选择下一次提交要包含的内容。
