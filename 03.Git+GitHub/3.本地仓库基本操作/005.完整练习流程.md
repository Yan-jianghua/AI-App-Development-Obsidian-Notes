# 本地仓库完整练习流程

## 1. 创建练习目录

```bash
mkdir git-practice
cd git-practice
git init -b main
```

## 2. 创建 `README.md`

```markdown
# Git Practice

这是我的 Git 练习项目。
```

## 3. 查看并暂存

```bash
git status
git add README.md
git status
```

观察它从 Untracked 变成 Staged。

## 4. 第一次提交

```bash
git commit -m "docs: 添加项目说明"
```

## 5. 修改并查看差异

在 `README.md` 增加一行，然后：

```bash
git diff
git add README.md
git diff --staged
git commit -m "docs: 补充学习目标"
```

## 6. 查看历史

```bash
git log --oneline --graph --decorate
```

## 自我检查

- `git add` 后为什么普通 `git diff` 变空？
- 为什么 `git diff --staged` 能看到差异？
- `commit` 保存工作区还是暂存区？

答案：`add` 把内容复制进暂存区；普通 `diff` 比较工作区和暂存区，`--staged` 比较暂存区和最新提交；`commit` 保存暂存区。

### 一句话记忆

> 亲手观察状态变化，比死记命令更容易理解 Git。
