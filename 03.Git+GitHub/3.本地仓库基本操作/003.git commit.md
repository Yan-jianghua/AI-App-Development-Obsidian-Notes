# `git commit`

## 创建提交

```bash
git commit -m "feat: 添加用户登录"
```

提交只记录暂存区内容，不会自动包含所有工作区修改。

## 提交前检查

```bash
git status
git diff --staged
```

## 好的提交说明

```text
feat: 添加邮箱登录
fix: 修复空密码导致的异常
docs: 补充本地启动步骤
refactor: 拆分用户校验逻辑
test: 添加登录失败用例
```

避免使用“修改”“最终版”“123”等无法说明意图的内容。

## 修改最近一次提交

漏加文件：

```bash
git add forgotten.py
git commit --amend --no-edit
```

修改说明：

```bash
git commit --amend -m "fix: 修复登录校验"
```

`amend` 会创建新提交替换旧提交，哈希值会变化。已经推送且被他人使用的提交不要随意 amend。

## `git commit -am` 的限制

```bash
git commit -am "fix: 修复问题"
```

它只会自动暂存已跟踪文件，不会包含新建的未跟踪文件。初学阶段建议分开使用 `add` 和 `commit`。

### 一句话记忆

> commit 是给已暂存内容拍快照，并用说明记录本次意图。
