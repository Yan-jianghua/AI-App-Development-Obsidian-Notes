# `git init` 与 `git clone`

## `git init`

把现有目录初始化为 Git 仓库：

```bash
cd my-project
git init
```

Git 会创建隐藏的 `.git` 目录，里面保存对象、引用和配置。

指定初始分支：

```bash
git init -b main
```

不要手动修改或删除 `.git`。删除它不会删除项目文件，但会失去其中的 Git 历史和本地分支信息。

## `git clone`

复制已有远程仓库：

```bash
git clone https://github.com/OWNER/REPO.git
git clone https://github.com/OWNER/REPO.git my-project
```

`clone` 通常会：

1. 创建本地目录。
2. 下载仓库对象和历史。
3. 添加名为 `origin` 的远程仓库。
4. 检出默认分支。

```text
本地新项目开始版本控制 → git init
已有 GitHub 项目下载本地 → git clone
```

不要在已经 `clone` 的目录里再次执行 `git init` 来“连接 GitHub”，因为它本来已经是仓库。

### 一句话记忆

> `init` 创建新仓库，`clone` 复制已有仓库。
