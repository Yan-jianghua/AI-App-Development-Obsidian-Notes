# `.gitignore`

## 作用

`.gitignore` 告诉 Git 哪些未跟踪文件不应加入版本控制。

Python 项目示例：

```gitignore
__pycache__/
*.py[cod]
.venv/
venv/
.env
.env.*
!.env.example
.pytest_cache/
.mypy_cache/
.coverage
htmlcov/
.vscode/
.idea/
```

## 常用规则

```gitignore
*.log          # 所有 .log 文件
build/         # 任意层级的 build 目录
/dist/         # 只忽略仓库根目录的 dist
temp?.txt      # ? 匹配一个字符
!important.log # 取消忽略
```

## 已跟踪文件不会自动消失

如果 `.env` 已经提交，再写进 `.gitignore` 仍会跟踪。要保留本地文件并从索引移除：

```bash
git rm --cached .env
git commit -m "chore: 停止跟踪环境变量文件"
```

如果含有真实密钥，还必须立即吊销并更换。删除当前文件不能抹掉历史中的秘密。

检查匹配规则：

```bash
git check-ignore -v .env
```

### 一句话记忆

> `.gitignore` 只影响未跟踪文件，不能替代密钥管理。
