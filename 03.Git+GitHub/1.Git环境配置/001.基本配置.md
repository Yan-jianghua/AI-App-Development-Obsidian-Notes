# Git 基本配置

## 配置用户名和邮箱

打开 Git Bash、PowerShell 或终端：

```bash
git config --global user.name "yjh"
git config --global user.email "19030725989@163.com"
```

它们会写入每次提交的作者信息，并不是 GitHub 登录账号或密码。

查看配置：

```bash
git config --global user.name
git config --global user.email
git config --global --list
git config --list --show-origin
```

## 只为当前仓库设置身份

进入仓库后，不带 `--global`：

```bash
git config user.name "公司使用的名字"
git config user.email "name@company.com"
```

仓库级配置会覆盖全局配置，适合区分个人项目和工作项目。

## 设置默认分支名

```bash
git config --global init.defaultBranch main
```

以后运行 `git init` 时，初始分支会命名为 `main`。

## 编辑或删除配置

```bash
git config --global user.name "新名字"
git config --global --unset user.name
git config --global --edit
```

## 常见误区

- `user.name` 可以不是 GitHub 用户名。
- 提交邮箱需在 GitHub 中验证，或使用 GitHub 提供的 `noreply` 邮箱，提交才容易关联到账号。
- 修改配置不会自动改变过去提交中的作者信息。

### 一句话记忆

> `user.name` 和 `user.email` 是提交签名信息，不是登录凭证。
