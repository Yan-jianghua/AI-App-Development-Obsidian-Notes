# 为常用 Git 指令设置别名

## Git 自带别名

推荐使用 Git 配置设置，Windows、macOS 和 Linux 都能使用：

```bash
# 设置 Git 命令别名，之后可以用缩写执行对应子命令。
git config --global alias.st status
# 设置 Git 命令别名，之后可以用缩写执行对应子命令。
git config --global alias.co checkout
# 设置 Git 命令别名，之后可以用缩写执行对应子命令。
git config --global alias.br branch
# 设置 Git 命令别名，之后可以用缩写执行对应子命令。
git config --global alias.cm commit
# 设置 Git 命令别名，之后可以用缩写执行对应子命令。
git config --global alias.lg "log --oneline --all --graph --decorate"
```

之后可以输入：

```bash
# 执行上面定义的 st 别名，等价于 git status。
git st
# 执行上面定义的 lg 别名，显示精简的全分支提交图。
git lg
```

查看和删除别名：

```bash
# 按正则表达式列出匹配的配置项，此处用于查看别名。
git config --global --get-regexp '^alias\.'
# 删除指定配置项；--global 表示删除用户级配置。
git config --global --unset alias.st
```

## Git Bash 的 Shell 别名

在用户主目录创建 `.bashrc`，写入：

```bash
alias git-log='git log --oneline --all --graph --decorate'
alias ll='ls -al'
```

让修改立即生效：

```bash
# 在当前 Bash 会话重新加载配置文件，使 Shell 别名等立即生效。
source ~/.bashrc
```

原笔记中的 `1s -a1` 使用了数字 `1`，正确命令应为小写字母 `l`：`ls -al`。

```text
Git 别名：git lg
Shell 别名：git-log
```

### 一句话记忆
