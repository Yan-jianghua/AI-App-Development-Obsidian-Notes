# 安装与版本检查

## 安装后先检查

```bash
# 显示 Git 版本，确认已安装。
git --version
```

正常会看到类似：

```text
git version 2.x.x.windows.x
```

如果提示找不到 `git`，通常是尚未安装，或安装目录没有加入系统 `PATH`。

## Windows 中的终端选择

- Git Bash：随 Git for Windows 安装，命令风格接近 Linux。
- PowerShell：Windows 自带，也能直接运行 Git。
- VS Code 终端：可以选择 PowerShell 或 Git Bash。

Git 仓库本身与使用哪一种终端无关。

## 查看帮助

```bash
# 打开指定 Git 子命令的完整帮助文档。
git help commit
# 查看 commit 帮助；--help 是完整手册，-h 是简短帮助。
git commit --help
# 查看 commit 帮助；--help 是完整手册，-h 是简短帮助。
git commit -h
```

前两种显示完整帮助，`-h` 通常显示简短参数说明。

### 一句话记忆

> `git --version` 验证安装，`git <命令> -h` 随时查用法。
