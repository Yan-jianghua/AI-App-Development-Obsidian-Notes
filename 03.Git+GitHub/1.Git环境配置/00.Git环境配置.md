## 配置分为哪几层

```text
系统级  --system   → 当前电脑的全部用户
全局级  --global   → 当前操作系统用户
仓库级  --local    → 当前仓库，优先级最高
```

学习和个人电脑通常先设置全局配置；如果某个工作仓库需要使用公司邮箱，再用仓库级配置覆盖。

## 建议的初始配置

```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
git config --global init.defaultBranch main
git config --global core.autocrlf true
```

Windows 通常使用 `core.autocrlf true`。团队已有明确规则时，以仓库中的 `.gitattributes` 为准。

### 一句话记忆
