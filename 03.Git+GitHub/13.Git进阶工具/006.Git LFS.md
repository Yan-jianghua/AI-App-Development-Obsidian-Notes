# Git LFS

## 为什么需要 LFS

Git 擅长管理文本源码，但大型二进制文件每次变化通常会保存新的完整对象，使仓库迅速变大。

Git LFS 用小型指针文件替代仓库中的大文件内容，真实内容存储在 LFS 服务中。

适合：

- 大型模型权重。
- 视频、音频和设计源文件。
- 经常更新的大型二进制数据。

## 基本使用

安装 Git LFS 后初始化：

```bash
git lfs install
```

跟踪文件模式：

```bash
git lfs track "*.psd"
git lfs track "models/*.bin"
```

这会更新 `.gitattributes`，需要一起提交：

```bash
git add .gitattributes
git add models/model.bin
git commit -m "chore: 使用 LFS 管理模型文件"
```

查看跟踪情况：

```bash
git lfs ls-files
```

## 注意

- LFS 存储和流量可能受平台配额限制。
- `git lfs track` 不会自动迁移已经存在于历史中的大文件。
- 克隆者需要安装 Git LFS 才能正常获取实际内容。
- 数据集和模型也要确认许可证、隐私和分发权限。

### 一句话记忆

> LFS 让 Git 跟踪大文件指针，真实大文件由专门存储管理。
