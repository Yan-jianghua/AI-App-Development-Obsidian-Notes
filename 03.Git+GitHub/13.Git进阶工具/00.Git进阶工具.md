## 什么时候学习本章

先熟练掌握提交、分支、合并、远程同步和撤销，再使用本章工具。它们能解决更复杂的问题，但有些操作会改写历史或影响团队工作流。

```text
整理本地提交         → rebase -i
复制某个独立提交     → cherry-pick
二分定位错误提交     → bisect
同时打开多个分支     → worktree
在 Git 操作前后自动检查 → hooks
管理大型二进制文件   → Git LFS
```

### 一句话记忆

> 进阶命令用于解决具体问题，不要为了“历史漂亮”而无目的改写历史。
