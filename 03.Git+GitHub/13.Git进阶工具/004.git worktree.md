# `git worktree`

## 解决什么问题

普通仓库同一时间只能在一个工作目录检出一个分支。`worktree` 允许同一仓库同时拥有多个工作目录。

例如正在功能分支开发，又需要查看主分支：

```text
project/          → feature/login
project-main/     → main
```

## 创建额外工作树

在仓库目录中：

```bash
# 在另一目录创建共享同一仓库的工作树；-b 同时新建分支。
git worktree add ../project-main main
```

创建新分支并添加：

```bash
# 在另一目录创建共享同一仓库的工作树；-b 同时新建分支。
git worktree add -b hotfix/login ../project-hotfix main
```

## 查看

```bash
# 列出当前仓库的所有工作树。
git worktree list
```

## 删除

完成工作后：

```bash
# 移除指定附加工作树。
git worktree remove ../project-hotfix
# 清理目录已不存在的陈旧工作树记录。
git worktree prune
```

有未提交修改时，remove 通常会拒绝，防止丢失工作。

## 注意

- 一个分支通常不能同时在两个 worktree 中检出。
- 每个 worktree 有独立工作区和暂存区，但共享 Git 对象和大部分仓库数据。
- 删除目录前优先用 `git worktree remove`，让 Git 正确清理记录。

### 一句话记忆

> worktree 让一个仓库同时打开多个分支目录，适合并行处理任务。
