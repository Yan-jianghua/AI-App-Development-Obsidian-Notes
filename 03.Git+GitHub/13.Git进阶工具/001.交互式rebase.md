# 交互式 `rebase`

## 作用

交互式 rebase 可以在推送前整理最近若干本地提交：

- 调整提交顺序。
- 合并多个提交。
- 修改提交说明。
- 拆分或删除提交。

整理最近 4 个提交：

```bash
git rebase -i HEAD~4
```

编辑器可能显示：

```text
pick a111111 添加登录接口
pick b222222 修复拼写
pick c333333 补充测试
pick d444444 调整错误信息
```

## 常用动作

```text
pick    保留提交
reword  保留内容，修改提交说明
edit    暂停，以便修改提交
squash  合并到前一个提交，并编辑说明
fixup   合并到前一个提交，丢弃当前说明
drop    删除提交
```

例如把拼写修复合入第一个提交：

```text
pick a111111 添加登录接口
fixup b222222 修复拼写
pick c333333 补充测试
pick d444444 调整错误信息
```

保存退出后 Git 会重写这些提交，每个被影响的提交都会得到新哈希。

## 冲突处理

```bash
# 编辑冲突文件
git add <文件>
git rebase --continue
```

放弃整个整理：

```bash
git rebase --abort
```

## 安全边界

只整理自己尚未共享的提交。已经推送并被他人基于其开发的提交，不应随意交互式 rebase。

开始前可以创建备份分支：

```bash
git branch backup/before-rebase
```

### 一句话记忆

> `rebase -i` 是本地提交编辑器，整理后哈希会改变。
