## 查资料的方法

遇到不认识的命令参数时：

```bash
git <命令> -h
git <命令> --help
```

GitHub 功能会随时间调整，尤其是认证、套餐权限、Rulesets 和 Actions 版本。学习时先理解本笔记中的原理，实际操作前再核对对应官方页面。
