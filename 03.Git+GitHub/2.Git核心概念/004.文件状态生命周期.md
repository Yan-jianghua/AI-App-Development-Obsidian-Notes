# 文件状态生命周期

## 四种常见状态

```text
Untracked   未跟踪
Unmodified  未修改
Modified    已修改
Staged      已暂存
```

```text
新文件 ─────────────→ Untracked
  │ git add
  ▼
Staged ── git commit → Unmodified
  ▲                       │ 编辑
  │ git add               ▼
  └────────────────── Modified
```

简短状态：

```bash
git status -s
```

```text
?? notes.md    未跟踪
 M app.py      工作区修改，未暂存
M  config.py   修改已暂存
MM user.py     已暂存后又继续修改
```

### 一句话记忆

> 不确定文件在哪个阶段，就先执行 `git status`。
