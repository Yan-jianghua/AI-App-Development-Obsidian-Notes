# 提交对象与 HEAD

## 什么是提交

一次提交包含文件快照、作者、时间、提交说明、父提交等信息。每个提交都有唯一哈希值，例如 `a3f97c1`。

## 什么是 HEAD

`HEAD` 表示当前检出的位置。通常它指向当前分支，当前分支再指向最新提交：

```text
HEAD → main → C3
              ↑
C1 ← C2 ← C3
```

```bash
# 只查看指定文件的提交历史；-- 将路径和选项分开。
git log --oneline --decorate -5
```

可能看到：

```text
a3f97c1 (HEAD -> main) 完成登录功能
95bd211 初始化项目
```

## 相对写法

```text
HEAD      当前提交
HEAD~1    上一个提交
HEAD~2    往前两个提交
main~1    main 分支的上一个提交
```

## detached HEAD

```bash
# 临时检出指定提交，进入分离 HEAD 状态，不在普通分支上。
git switch --detach a3f97c1
```

此时 HEAD 直接指向提交，适合查看旧版本。若要继续开发，应创建分支：

```bash
# 创建并切换到新分支；末尾若有提交或分支名，则从那里创建。
git switch -c fix/from-old-version
```

### 一句话记忆

> 提交是历史节点，分支是可移动标签，HEAD 表示当前站在哪里。
