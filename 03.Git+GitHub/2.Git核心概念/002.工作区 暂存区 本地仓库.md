# 工作区、暂存区、本地仓库

这是 Git 最重要的模型。

```text
工作区 Working Tree
    │ git add
    ▼
暂存区 Index / Staging Area
    │ git commit
    ▼
本地仓库 Repository
```

## 工作区

你正在编辑的真实文件。保存代码后，变化首先出现在工作区。

## 暂存区

准备放入“下一次提交”的内容清单：

```bash
git add app.py
```

它不是上传文件，而是把当前版本的 `app.py` 放入暂存区。

## 本地仓库

```bash
git commit -m "完成登录校验"
```

Git 会把暂存区内容保存为一次提交。

## 为什么需要暂存区

同时修改登录代码和文档时，可以分别提交：

```bash
git add login.py
git commit -m "feat: 添加登录校验"
git add README.md
git commit -m "docs: 修正文档错别字"
```

执行 `git add file.py` 后继续修改它，暂存区仍是第一次 `add` 时的版本。同一文件可能同时有已暂存和未暂存修改。

### 一句话记忆

> 工作区负责改，暂存区负责选，仓库负责永久记录。
