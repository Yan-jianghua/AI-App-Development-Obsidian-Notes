# Git 与 GitHub 的区别

## Git

Git 是安装在本地电脑上的版本控制工具。即使没有网络，也能初始化仓库、查看修改、创建提交、新建和合并分支、恢复版本。

## GitHub

GitHub 是在线代码托管与协作平台，提供远程仓库、Pull Request、Issues、Actions、Releases 和权限管理等功能。

## 两者的关系

```text
本地电脑                         GitHub
Git 仓库  ← fetch / pull ─── 远程仓库
Git 仓库  ─── push ─────────→ 远程仓库
```

GitHub 不是使用 Git 的必要条件。Git 仓库也能托管在其他平台或自己的服务器上。

## 常见误区

- `git commit` 只保存到本地，不会自动上传 GitHub。
- `git push` 才会把本地提交推到远程。
- GitHub 网页上的记录不代表本地文件已自动同步。

### 一句话记忆

> Git 是本地版本控制工具，GitHub 是远程托管与协作平台。
