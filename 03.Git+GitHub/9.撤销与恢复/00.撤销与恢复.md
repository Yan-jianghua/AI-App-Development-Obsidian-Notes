## 先判断修改在哪一层

```text
工作区错误      → git restore
暂存区选错      → git restore --staged
本地提交需重做  → git reset
已共享提交撤销  → git revert
引用移动后找回  → git reflog
```

执行撤销前先运行：

```bash
git status
git log --oneline --decorate -10
```

### 一句话记忆

> 撤销没有万能命令，先确定错误发生在工作区、暂存区还是提交历史。
