# Actions Secrets 与权限

## 使用 Secrets

在 GitHub 仓库设置中创建 Secret，例如 `DEPLOY_TOKEN`，工作流中引用：

```yaml
env:
  DEPLOY_TOKEN: ${{ secrets.DEPLOY_TOKEN }}
```

不要把真实值直接写进 YAML。

## 最小权限

`GITHUB_TOKEN` 是工作流内置令牌。显式声明所需权限：

```yaml
permissions:
  contents: read
```

只有确实需要写仓库内容时才提升：

```yaml
permissions:
  contents: write
```

## 不要输出秘密

避免：

```bash
echo "$DEPLOY_TOKEN"
```

即使平台会遮盖部分秘密，也不应依赖日志遮盖作为安全边界。

## 来自 Fork 的 PR

为了防止不受信任代码窃取凭据，Fork PR 通常无法直接获得仓库 Secrets。设计工作流时不要为了让测试方便而降低这个安全边界。

### 一句话记忆

> Secret 放平台保管，Token 权限只给任务真正需要的最小范围。
