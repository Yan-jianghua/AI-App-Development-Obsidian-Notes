# Workflow 基本结构

## 最小示例

```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Show message
        run: echo "CI is running"
```

## 结构解释

```text
name  工作流显示名称
on    触发事件
jobs  一组可并行或有依赖的任务
job   在某个 runner 上执行的任务
steps 任务内部按顺序执行的步骤
uses  使用现成 Action
run   执行命令
```

## 多任务依赖

```yaml
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - run: echo test

  deploy:
    needs: test
    runs-on: ubuntu-latest
    steps:
      - run: echo deploy
```

只有 `test` 成功后才运行 `deploy`。

## YAML 注意事项

- 缩进使用空格，不用 Tab。
- 列表项以 `-` 开头。
- 键名层级错误会改变含义或导致语法失败。

### 一句话记忆

> 事件触发 workflow，workflow 包含 jobs，job 包含顺序执行的 steps。
