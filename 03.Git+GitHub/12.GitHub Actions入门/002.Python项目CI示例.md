# Python 项目 CI 示例

```yaml
name: Python tests

on:
  push:
    branches: [main]
  pull_request:

jobs:
  test:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.12"
          cache: pip

      - name: Install dependencies
        run: |
          # 通过当前 Python 环境升级 pip。
          python -m pip install --upgrade pip
          # 安装项目依赖；-r 表示从 requirements.txt 读取包列表。
          pip install -r requirements.txt

      - name: Run tests
        run: pytest -q
```

## 为什么需要 checkout

runner 是新环境，不会自动包含仓库代码。`actions/checkout` 把当前提交取到 runner 中。

## 为什么锁定 Action 主版本

```yaml
uses: actions/checkout@v4
```

明确版本比使用不固定引用更可预测。对高安全要求的仓库，可以按团队策略固定到完整提交 SHA。

## 矩阵测试

```yaml
strategy:
  matrix:
    python-version: ["3.11", "3.12", "3.13"]
```

并在 setup 步骤中使用：

```yaml
python-version: ${{ matrix.python-version }}
```

这样可验证项目支持多个 Python 版本。
