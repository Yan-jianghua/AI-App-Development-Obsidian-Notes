## GitHub Actions 是什么

GitHub Actions 根据仓库事件自动运行任务，常用于：

- 安装依赖。
- 运行测试和静态检查。
- 构建软件包或镜像。
- 发布版本。
- 部署应用。

工作流文件放在：

```text
.github/workflows/*.yml
```

### 一句话记忆

> Actions 把“每次都应该执行的检查”变成可重复的自动流程。
