# 模型能力矩阵

## 是什么

模型选型应按任务质量、时延、成本、语言、上下文、结构化输出、工具、多模态、隐私和可用性比较，而非只看排行榜。

## 实践步骤

准备自己的真实样本、失败边界与预算；每个候选在同一数据集上测质量、P95、TTFT、有效答案成本和安全失败。定期复测并锁定上线版本。

## 容易错与验收

模型名和价格会变；记录测试日期、参数与供应商地区约束，不把实验结果当永久结论。
