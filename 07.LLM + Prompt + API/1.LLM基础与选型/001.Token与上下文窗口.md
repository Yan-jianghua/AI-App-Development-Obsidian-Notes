# Token与上下文窗口

## 是什么

Token 是模型处理文本的计量单位；上下文窗口限制本次请求能包含的输入与输出总量。不同模型分词方式、计费和缓存规则可能不同。

## 实践步骤

先预算系统指令、历史、检索证据、工具结果和输出上限；超过预算时有策略地裁剪或摘要。记录实际用量并按模型价格版本计算。

## 容易错与验收

不要按汉字数直接估算 token；长输入不仅增加成本，也可能降低对关键证据的注意力。
