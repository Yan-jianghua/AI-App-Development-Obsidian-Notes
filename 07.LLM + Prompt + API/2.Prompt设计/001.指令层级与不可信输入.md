# 指令层级与不可信输入

## 是什么

系统规则、开发者规则、用户意图和检索到的网页/文档具有不同信任级别。外部内容是数据，不能升格为工具授权或系统指令。

## 实践步骤

将任务、边界、证据和输出格式分隔；服务端校验工具参数、权限和 URL。对检索文本中的伪角色、隐藏指令与编码诱导做攻击测试。

## 容易错与验收

单靠“忽略恶意内容”提示不能保证安全；关键副作用需要独立审批。
