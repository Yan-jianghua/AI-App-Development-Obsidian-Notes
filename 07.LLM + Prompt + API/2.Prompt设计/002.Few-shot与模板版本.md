# Few-shot与模板版本

## 是什么

Few-shot 示例展示输入、期望输出和边界行为，可改善格式或分类一致性；但示例也可能引入偏见或过拟合。

## 实践步骤

模板变量明确类型与转义规则，示例覆盖正例、反例和拒答。版本记录模板、示例集、模型参数、输出 Schema 与评测结果。

## 容易错与验收

避免把真实个人数据放进示例；模板改动后要跑相同黄金集比较，而非凭感觉上线。
