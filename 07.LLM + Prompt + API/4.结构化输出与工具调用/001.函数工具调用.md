# 函数工具调用

## 是什么

函数调用是模型建议调用某个工具及参数，不等于模型直接拥有外部权限。执行权始终在应用服务端。

## 实践步骤

工具声明名称、用途、参数 Schema、权限、超时、幂等与副作用级别。模型输出先解析、校验、鉴权，再执行并把结果作为低信任数据返回上下文。

## 容易错与验收

测试越权参数、SQL/路径注入、重复动作、工具故障与假工具结果。退款、发信等动作需审批。
