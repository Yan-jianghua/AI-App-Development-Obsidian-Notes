# JSON Schema校验

## 是什么

结构化输出约束语法与字段，但不保证数据真实或业务规则成立。服务端必须再次校验模型结果。

## 实践步骤

设置必填、枚举、范围、额外字段策略与交叉字段检查；格式失败限次修复，语义冲突交人工或拒绝。保存校验错误，供评测集回归。

## 容易错与验收

不要把合法 JSON 直接写入生产数据库；字段可能来自不可信网页，仍需权限与业务验证。
