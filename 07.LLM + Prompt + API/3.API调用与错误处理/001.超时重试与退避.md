# 超时重试与退避

## 是什么

模型 API 故障可能是连接失败、超时、限流、服务端错误或请求本身无效。只有暂时性错误才适合受控重试。

## 实践步骤

设置连接/读取/总超时，重试次数和指数退避加抖动；解析重试提示。为任务设总截止时间与预算，失败后记录分类和请求 ID。

## 容易错与验收

非幂等工具动作不能盲重试；超时可能代表上游仍执行，需按请求 ID 对账。
