# 离线评测与线上监控

## 是什么

离线评测在固定样本上比较版本；线上监控观察真实流量、分布变化与事故。两者互补，不能只凭演示案例。

## 实践步骤

黄金集含正常、边界、对抗、拒答和多语言样本。报告分组质量、P95、成本、人工修改率与严重失败；上线后采集反馈并把新失败纳入回归。

## 容易错与验收

评分器可能偏置，关键样本做人工校准；平均分不能掩盖泄密或错误执行。
