# 多模态输入

## 是什么

图像、音频和文档输入有不同分辨率、时长、大小、隐私和费用边界；模型理解结果可能遗漏细节。

## 实践步骤

上传前验证格式、大小、病毒与权限；图像/OCR/语音转写保留原始来源与处理版本。对文字、图片、音频分别准备评测样本，并注明模型看到了哪种表示。

## 容易错与验收

不能把 OCR 文本等同原件；医疗、法律、财务等高风险结论须领域专家复核。
