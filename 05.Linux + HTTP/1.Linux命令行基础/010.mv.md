# mv

## 含义

移动或重命名文件，目标存在时行为取决于选项与平台。

## 最小用法

`mv old.log archived.log`

## 易错点

跨文件系统移动不一定原子，关键流程需校验结果。

## 检查自己是否掌握

改动示例中的一个输入或条件，预测结果，再用真实环境核对。解释这个术语与同章节相邻术语的区别。
