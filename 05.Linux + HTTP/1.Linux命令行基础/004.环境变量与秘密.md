# 环境变量与秘密

## 是什么

环境变量向进程传递配置，子进程通常继承父进程环境。

## 何时用、怎么做

用不同环境配置数据库地址和功能开关，秘密由专门的秘密管理机制注入。

## 易错点与验收

环境变量可能被日志、调试界面或子进程泄漏，绝不打印整份环境。
