# 路径与引号

## 是什么

绝对路径从根开始，相对路径依赖当前目录。Shell 会先解释空格、通配符和变量。

## 何时用、怎么做

含空格的路径加引号，脚本开头明确工作目录并用 pwd 检查。

## 易错点与验收

不要把未受信任的输入拼进 shell 命令，先用参数数组。
