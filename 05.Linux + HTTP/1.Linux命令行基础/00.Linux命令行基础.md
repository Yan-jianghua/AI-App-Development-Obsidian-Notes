# Linux 命令行基础

## 文件系统与路径

Linux 从根目录 `/` 开始。绝对路径从 `/` 写起；相对路径以当前目录为起点。`~` 通常表示当前用户主目录，`.` 是当前目录，`..` 是上一级。生产脚本应少依赖“当前正好在哪”，重要路径优先明确配置。

```bash
pwd                         # 当前目录
ls -lah                     # 包含隐藏文件，以易读大小显示
cd /var/log                 # 切换目录
mkdir -p app/data           # 连同缺失父目录一起创建
cp -a config config.bak     # 尽量保留属性地复制
mv old.txt new.txt          # 移动或改名
```

删除不可逆，执行前先用 `pwd`、`ls` 确认目标；不要把未检查的变量或通配符交给递归删除命令。

## 查看与搜索

```bash
cat file.txt                # 小文件一次输出
less app.log                # 大文件分页查看，/关键词搜索，q退出
tail -n 100 app.log         # 最后100行
tail -f app.log             # 持续追踪新增日志
find . -type f -name '*.py' # 按文件名搜索
grep -Rni 'ERROR' logs/     # 递归搜索文本并显示行号
```

现代开发环境可用 `rg` 替代多数递归文本搜索。二进制文件、大日志和权限不足都会影响结果，搜索不到不等于内容不存在。

## 管道、重定向和退出码

`|` 把左侧标准输出交给右侧；`>` 覆盖文件，`>>` 追加；`2>` 重定向错误。命令以退出码表达成功与否，通常 `0` 成功、非 `0` 失败。

```bash
grep 'ERROR' app.log | tail -n 20
python app.py >app.out 2>app.err
command && echo success     # 前一条成功才继续
command || echo failed      # 前一条失败才继续
echo $?                     # 最近命令退出码
```

管道默认容易只反映最后一条命令的状态，严谨脚本应启用合适的错误处理并对关键步骤显式检查。

## 权限

每个文件有所有者、所属组和其他用户三组权限：`r` 读、`w` 写、`x` 执行。目录的 `x` 表示可进入/遍历。

```bash
ls -l
chmod u+x deploy.sh
chmod 640 .env              # 所有者读写，组只读，其他无权限
chown appuser:appgroup file # 改所有者与组，通常需要管理员权限
```

不要用 `chmod 777` 逃避权限问题。服务使用独立低权限账户，只授予所需目录的最小权限。

## 文本和压缩

```bash
head -n 5 data.csv
wc -l data.csv
sort names.txt | uniq -c
cut -d, -f1 data.csv
tar -czf backup.tar.gz folder/
tar -xzf backup.tar.gz
```
