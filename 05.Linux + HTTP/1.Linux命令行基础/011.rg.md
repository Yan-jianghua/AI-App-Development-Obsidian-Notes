# rg

## 含义

递归搜索文本与文件名的工具，默认遵守忽略规则。

## 最小用法

`rg -n 'TODO' .`

## 易错点

需要搜索被忽略内容时应显式调整选项。

## 检查自己是否掌握

改动示例中的一个输入或条件，预测结果，再用真实环境核对。解释这个术语与同章节相邻术语的区别。
