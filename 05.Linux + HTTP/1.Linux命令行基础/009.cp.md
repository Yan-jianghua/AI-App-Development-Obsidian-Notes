# cp

## 含义

复制文件或目录，目录复制需递归选项。

## 最小用法

`cp config.example.toml config.toml`

## 易错点

覆盖目标可能丢失配置，先确认目标和权限。

## 检查自己是否掌握

改动示例中的一个输入或条件，预测结果，再用真实环境核对。解释这个术语与同章节相邻术语的区别。
