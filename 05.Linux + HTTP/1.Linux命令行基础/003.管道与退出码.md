# 管道与退出码

## 是什么

管道把前一命令的标准输出交给后一命令，退出码表达命令成功或失败。

## 何时用、怎么做

脚本分别处理标准输出、标准错误和退出码，避免只看有无文字。

## 易错点与验收

管道尾端成功不一定表示前端成功，设置并核对 shell 的管道失败策略。

## 自测

用本节的场景举一个正常用例、一个边界用例和一个失败用例；说明你会观察哪些结果或指标来判断实现正确。
