# ls

## 含义

列出目录条目，可配选项查看权限和隐藏文件。

## 最小用法

`ls -la`

## 易错点

文件名包含控制字符时终端显示可能误导，自动化优先用可靠的文件 API。

## 检查自己是否掌握
