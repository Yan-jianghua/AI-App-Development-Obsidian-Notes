# 标准流与日志重定向

## 是什么

进程有 stdin、stdout、stderr 三条常用标准流，日志系统可另行采集。

## 何时用、怎么做

服务将结构化日志写到标准输出并附请求 ID，错误走可识别的级别。

## 易错点与验收

把 stderr 丢弃会使启动失败难以排查，验证重启后仍能追踪原因。
