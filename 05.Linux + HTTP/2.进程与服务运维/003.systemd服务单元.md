# systemd服务单元

## 是什么

systemd 单元描述服务启动命令、依赖、身份和重启策略。

## 何时用、怎么做

设置专用用户、工作目录、环境来源和 Restart 策略，再用状态与日志命令核验。

## 易错点与验收

重启循环会掩盖配置错误，先读取退出码和最近日志。

## 自测

用本节的场景举一个正常用例、一个边界用例和一个失败用例；说明你会观察哪些结果或指标来判断实现正确。
