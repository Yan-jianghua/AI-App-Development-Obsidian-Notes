# systemctl

## 含义

查询和控制 systemd 单元的状态。

## 最小用法

`systemctl status myapp.service`

## 易错点

active 状态不等于应用就绪，仍需健康检查。

## 检查自己是否掌握

改动示例中的一个输入或条件，预测结果，再用真实环境核对。解释这个术语与同章节相邻术语的区别。
