# GET

## 含义

HTTP GET 请求读取资源，语义上应安全且幂等。

## 最小用法

`GET /users/42`

## 易错点

不要把有副作用的操作挂在 GET，缓存与预取可能自动访问。

## 检查自己是否掌握

改动示例中的一个输入或条件，预测结果，再用真实环境核对。解释这个术语与同章节相邻术语的区别。
