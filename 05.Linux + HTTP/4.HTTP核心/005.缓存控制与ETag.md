# 缓存控制与ETag

## 是什么

缓存头描述响应能否复用，ETag 支持条件请求和变化检测。

## 何时用、怎么做

对可公开的静态资源设缓存，对用户私有数据设置合适的 private 或 no-store。

## 易错点与验收

缓存键必须包含影响响应的身份与变体，测试权限切换后的响应。
