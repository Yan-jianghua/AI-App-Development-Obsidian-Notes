# 429 Too Many Requests

## 含义

客户端在时间窗口内发起过多请求。

## 接口场景

配额耗尽时返回 429 和可选 Retry-After。

## 易错点与验收

重试要遵守服务端提示并加入抖动。测试同一接口的成功、参数错误、认证、授权和上游故障，检查状态码与响应体契约一致。
