# 幂等与重试

## 是什么

幂等表示重复执行后资源的预期效果不变，网络重试可能让服务端收到多次。

## 何时用、怎么做

对创建类请求引入业务幂等键，并持久化结果以返回相同响应。

## 易错点与验收

超时不等于服务端未执行，重试前必须弄清副作用边界。

## 自测
