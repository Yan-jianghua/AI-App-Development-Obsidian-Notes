# PUT

## 含义

HTTP PUT 通常以给定表示替换目标资源，重复执行具有幂等语义。

## 最小用法

`PUT /profiles/42`

## 易错点

部分字段更新若按替换处理会清空未提交字段。

## 检查自己是否掌握

改动示例中的一个输入或条件，预测结果，再用真实环境核对。解释这个术语与同章节相邻术语的区别。
