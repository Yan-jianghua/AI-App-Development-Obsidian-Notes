# Cookie与会话

## 是什么

Cookie 是浏览器自动附带的状态载体，会话信息可存在服务端或签名令牌内。

## 何时用、怎么做

按场景设置 Secure、HttpOnly、SameSite、过期时间与路径。

## 易错点与验收

仅有 HttpOnly 不防 CSRF，跨站请求还需配合 SameSite 与令牌策略。
