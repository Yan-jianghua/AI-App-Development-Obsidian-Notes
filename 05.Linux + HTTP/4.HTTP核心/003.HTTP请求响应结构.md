# HTTP请求响应结构

## 是什么

HTTP 消息由方法、目标、头部和正文组成，响应另有状态码。

## 何时用、怎么做

用 curl 查看请求与响应头，确认内容类型、缓存、认证与请求 ID。

## 易错点与验收

请求体格式与 Content-Type 不一致时应有可解释的 4xx 错误。
