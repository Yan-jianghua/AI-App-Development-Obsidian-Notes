# POST

## 含义

HTTP POST 提交数据或触发处理，默认不能假定幂等。

## 最小用法

`POST /orders`

## 易错点

超时后的重复提交需要业务幂等键。

## 检查自己是否掌握

改动示例中的一个输入或条件，预测结果，再用真实环境核对。解释这个术语与同章节相邻术语的区别。
