# PATCH

## 含义

HTTP PATCH 提交局部修改，是否幂等由补丁语义决定。

## 最小用法

`PATCH /profiles/42`

## 易错点

递增型补丁重复执行会产生不同结果。

## 检查自己是否掌握

改动示例中的一个输入或条件，预测结果，再用真实环境核对。解释这个术语与同章节相邻术语的区别。
