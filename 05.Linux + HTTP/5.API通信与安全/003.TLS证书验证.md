# TLS证书验证

## 是什么

TLS 通过证书链和主机名校验确认连接对端并保护传输。

## 何时用、怎么做

生产客户端启用证书验证，验证过期、主机名不匹配和代理环境。

## 易错点与验收

关闭验证会让中间人攻击变得可能，不应作为常规故障修复。
