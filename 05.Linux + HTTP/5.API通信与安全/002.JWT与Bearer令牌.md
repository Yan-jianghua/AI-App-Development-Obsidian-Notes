# JWT与Bearer令牌

## 是什么

Bearer 表示持有令牌即可使用，JWT 是一种令牌编码格式，两者不是同义词。

## 何时用、怎么做

验证签名、签发者、受众、过期时间，并用最小权限的 scope。

## 易错点与验收

不能只解码不验签，也不能把敏感明文放进 JWT 负载。
