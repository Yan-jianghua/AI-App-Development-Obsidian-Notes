# curl

## 含义

命令行 HTTP 客户端，可显示头、状态与错误。

## 最小用法

`curl -i https://example.com/health`

## 易错点

不要把 Bearer 令牌写进可见的命令历史或日志。

## 检查自己是否掌握

改动示例中的一个输入或条件，预测结果，再用真实环境核对。解释这个术语与同章节相邻术语的区别。
