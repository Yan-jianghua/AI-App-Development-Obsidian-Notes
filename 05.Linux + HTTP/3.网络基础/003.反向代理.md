# 反向代理

## 是什么

反向代理位于客户端与应用之间，可负责 TLS 终止、路由、连接限制和转发头。

## 何时用、怎么做

只信任来自已知代理的转发头，并设置应用对真实客户端地址的解析规则。

## 易错点与验收

错误信任 X-Forwarded-For 会影响限流和审计。

## 自测

用本节的场景举一个正常用例、一个边界用例和一个失败用例；说明你会观察哪些结果或指标来判断实现正确。
