# TCP连接与端口

## 是什么

TCP 提供有序字节流，IP 加端口定位网络端点，监听地址决定可访问范围。

## 何时用、怎么做

排查连接失败依次检查 DNS、路由、防火墙、监听地址和应用日志。

## 易错点与验收

能 ping 通并不表示目标 TCP 端口可连接。

## 自测

用本节的场景举一个正常用例、一个边界用例和一个失败用例；说明你会观察哪些结果或指标来判断实现正确。
