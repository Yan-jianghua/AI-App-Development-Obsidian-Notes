# 安全赋值与链式索引

## 想给上海学生加一列标签

先运行 [[002.构造练习数据]]：

```python
students.loc[students["city"] == "上海", "city_group"] = "一线样例"
```

`.loc[行条件, 列名] = 值` 明确告诉 Pandas 修改哪一批行、哪一列。其他行的 `city_group` 会是缺失值。

## 为什么避免链式写法

```python
students[students["city"] == "上海"]["city_group"] = "一线样例"
```

这段代码先筛出一个中间对象，再给中间对象赋值，原 `students` 是否按预期更新不可靠。Pandas 版本之间提示/错误形式也可能不同。直接用 `.loc` 表达意图。

## 如果想得到新表而非修改原表

```python
shanghai = students.loc[students["city"] == "上海"].copy()
shanghai["city_group"] = "一线样例"
```

显式 `.copy()` 表示后续只改筛选结果。学习时保持“原表”和“派生表”命名清楚，能减少意外覆盖。

参考：[Pandas Copy-on-Write](https://pandas.pydata.org/docs/user_guide/copy_on_write.html)。
