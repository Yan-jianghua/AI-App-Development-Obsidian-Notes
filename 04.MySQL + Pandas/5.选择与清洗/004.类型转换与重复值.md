# 类型转换与重复值

## 类型转换

导入 CSV 后，`score` 可能是文本，例如 `"88"`。文本不能直接当数值做可靠统计：

```python
raw = pd.DataFrame({"score": ["88", "92", "缺考"]})
raw["score_num"] = pd.to_numeric(raw["score"], errors="coerce")
print(raw)
```

`errors="coerce"` 会把不能解析的“缺考”变成缺失值。这样做之前要保留原列，以免丢失“缺考”和“尚未录入”的区别。若无法解析应视为错误，使用默认抛错行为并逐条修正数据。

日期可用 `pd.to_datetime(...)` 转换；转换完成后用 `dtypes` 检查。不要凭打印出来的样子猜列类型。

## 重复记录

```python
print(scores.duplicated(subset=["student_id", "course"]).sum())
```

当前数据是 0。这里假定“一名学生一门课只应有一条成绩”。如果业务允许补考或多次考试，就需要把考试时间等字段也纳入判重规则。

```python
clean_scores = scores.drop_duplicates(
    subset=["student_id", "course"], keep="last"
)
```

`drop_duplicates` 不能替你判断哪条才是正确记录；`keep="last"` 只有在数据顺序有业务意义时才合适。
