# 布尔筛选与排序

## 条件产生真假序列

```python
mask = students["age"] >= 21
print(mask)
print(students.loc[mask, ["name", "age"]])
```

结果留下小周、小吴、小郑。可理解为 Pandas 根据每行条件的 `True` / `False` 决定是否保留。

## 多条件

```python
students.loc[
    (students["age"] >= 21) & (students["city"] == "上海"),
    ["name", "age"],
]
# 小郑
```

Pandas 对逐元素条件组合使用 `&`（且）、`|`（或）、`~`（非）；每个条件加括号。不要用 Python 的 `and`、`or` 连接整个 Series。

## 排序与取前几名

```python
students.sort_values(
    ["age", "student_id"],
    ascending=[False, True],
).head(2)
```

结果是小郑、小周。`sort_values` 默认返回新表，原变量通常不会被直接改动；如需保存排序结果，写 `sorted_students = ...`。

## 容易错在哪

`students["city"] == None` 不是可靠的缺失判断；用 `students["city"].isna()`。排序后如需重新编号显示，可在结果上 `.reset_index(drop=True)`。
