# 选列与 `.loc`、`.iloc`

## 选列

```python
students["name"]             # Series：一列
students[["name", "age"]]    # DataFrame：两列
```

## `.loc` 按标签选，`.iloc` 按位置选

```python
students.loc[0, "name"]           # 默认索引标签 0 → 小林
students.loc[0:2, ["name", "age"]] # 标签切片通常包含末端标签 2
students.iloc[0, 1]               # 第 0 行、第 1 列 → 小林
students.iloc[0:2, 1:3]           # 位置切片不包含末端位置 2 / 3
```

初始数据的行索引刚好是 0、1、2、3，很容易误以为标签和位置永远一样。筛选之后，行索引可能变成 `1, 3`：这时 `.loc[1]` 指标签 1，`.iloc[1]` 指剩余结果的第二行。

## 何时用哪一个

知道列名、行标签时用 `.loc`；需要“第几行第几列”时用 `.iloc`。对业务编号查学生，不要碰巧依赖行索引，明确写筛选条件：

```python
students.loc[students["student_id"] == 2, ["name", "age"]]
```
