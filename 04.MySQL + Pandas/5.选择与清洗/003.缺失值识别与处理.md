# 缺失值识别与处理

## 先确认缺失的含义

先运行 [[002.构造练习数据]]。小吴的城市未知，不代表“无城市”；SQL 分数未知，也不等于 0 分。选不同处理方式会直接改变统计结论。

```python
print(students["city"].isna())
print(students.isna().sum())
print(scores["score"].notna().sum())  # 4 个已知分数
```

## 三种常见处理

```python
# 1. 只分析分数已知的成绩，保留原 scores
known_scores = scores.dropna(subset=["score"])

# 2. 为展示而填写“未知”，保留原 students
display_students = students.assign(
    city=students["city"].fillna("未知")
)

# 3. 统计时保留缺失状态
average = scores["score"].mean()  # 84.0，默认跳过缺失
```

`fillna(0)` 只有在业务明确“缺失等于零”时才合理；把未知成绩填 0 后，平均分会从 84 变成 67.2，意义已变。

## 易错点

`dropna()` 默认按行处理，并可能丢弃任何列含缺失的行；写 `subset=["score"]` 才明确只关心成绩列。清洗后最好检查行数变化，防止意外删掉大量数据。
