# MySQL + Pandas 学习导航

按“先存好数据 → 用 SQL 查询 → 用 Pandas 分析”的顺序学习。每章先读 `00.` 概览，再按编号读知识点；每篇都回答“是什么、什么时候用、怎么写、容易错在哪”。

## MySQL：把数据可靠地存起来

1. [[00.MySQL入门]]：数据库、表、字段、类型和练习数据。
2. [[00.DQL查询]]：从单表筛选、排序、聚合到多表查询。
3. [[00.DDL与DML]]：建表约束，以及新增、修改、删除数据。
4. [[00.事务与索引]]：事务、一致性、索引和慢查询入门。

## Pandas：把数据读进 Python 并分析

5. [[00.Pandas入门]]：Series、DataFrame、读写文件与查看数据。
6. [[00.选择与清洗]]：选行列、缺失值、类型、重复值。
7. [[00.分析与合并]]：分组统计、表连接、透视表。
8. [[00.时间序列与实战]]：日期、综合分析与 SQL/Pandas 对照。

## 建议练法

每学一个知识点，先预测示例结果，再执行代码，最后改一个条件观察变化。SQL 示例以 MySQL 8.4 常用语法为基准；Pandas 示例以当前官方用户指南中的常用 API 为基准。不同版本的细节请以所用版本文档为准。
