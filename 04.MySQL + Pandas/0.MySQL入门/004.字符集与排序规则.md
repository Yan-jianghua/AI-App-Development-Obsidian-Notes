# 字符集与排序规则

## 是什么

字符集决定字符如何编码，排序规则决定比较和排序。建库、建表、列可以分别设置，列级配置会覆盖上层默认值。

## 何时用、怎么做

先统一采用能保存多语言文本的字符集，再针对大小写与重音敏感性选排序规则。用包含中英文与大小写的样本验证唯一约束。

## 易错点与验收

排序规则会改变等值判断，不能把显示相同当作字节相同。
