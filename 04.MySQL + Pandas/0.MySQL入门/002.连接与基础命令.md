# 连接与基础命令

## 连接

先安装并启动 MySQL 服务，再通过终端或图形客户端连接。终端常用写法：

```bash
mysql -u "你的数据库用户名" -p -h "你的数据库IP或域名"
```

`-u` 指用户名，`-p` 会让终端单独询问密码，`-h` 指数据库地址。不要把真实密码直接写在命令或笔记里。

## 进入后做什么

```sql
SELECT VERSION();              -- 看服务端版本
SHOW DATABASES;                -- 看有哪些数据库
CREATE DATABASE learning_lab
  CHARACTER SET utf8mb4;
USE learning_lab;               -- 后面的表操作使用它
SELECT DATABASE();             -- 确认当前数据库
SHOW TABLES;                   -- 看当前库里的表
```

SQL 语句通常以分号结束。关键字大小写不影响这里的含义，笔记统一用大写，便于分辨关键字与表名。

## 容易错在哪

- `CREATE DATABASE` 只创建库，不会自动切换；还要 `USE learning_lab`。
- `SHOW TABLES` 为空，先确认是不是选错了库。
- 连接失败先分清：服务没启动、地址或端口错、用户名密码错、用户没有权限。
- 后续建表会修改当前库；执行前用 `SELECT DATABASE()` 再确认一次。
