# 数据库与表

## 是什么

一张 `students` 表可以理解为“每行一个学生、每列描述一种属性”。例如 `student_id` 是学生编号，`name` 是姓名。数据库可以包含多张表，表之间可以通过编号建立关系。

| 名称 | 作用 | 例子 |
|---|---|---|
| 数据库 | 放置相关的表 | `learning_lab` |
| 表 | 保存同类记录 | `students` |
| 字段 | 规定记录有哪些属性 | `name`、`age` |
| 记录 | 一条完整数据 | `(1, '小林', 20)` |
| 主键 | 唯一标识一行 | `student_id = 1` |
| 外键 | 指向另一张表的行 | `scores.student_id` |

## 为什么分表

学生姓名只存一次；成绩单里只记录学生编号、课程和分数。否则一位学生有五门课，姓名就要重复五次，更名时可能只改到其中四行。

```text
students: 学生基本信息
scores:   每位学生每门课的成绩
scores.student_id → students.student_id
```

主键强调“这一行是谁”；外键强调“这一行关联谁”。外键约束需要明确声明，单靠列名相同不会自动建立。

> 一张表只负责一种主要事实；用稳定的编号连接不同事实。
