# 练习数据与字段类型

后续 MySQL 章节都用下面两张表。请在自己的练习数据库执行；重复运行前先检查同名表是否已存在。

```sql
CREATE DATABASE IF NOT EXISTS learning_lab CHARACTER SET utf8mb4;
USE learning_lab;

CREATE TABLE students (
    student_id INT PRIMARY KEY,
    name VARCHAR(30) NOT NULL,
    city VARCHAR(30),
    age INT NOT NULL
);

CREATE TABLE scores (
    score_id INT PRIMARY KEY,
    student_id INT NOT NULL,
    course VARCHAR(30) NOT NULL,
    score DECIMAL(5, 2),
    FOREIGN KEY (student_id) REFERENCES students(student_id)
);

INSERT INTO students (student_id, name, city, age) VALUES
    (1, '小林', '上海', 20),
    (2, '小周', '北京', 22),
    (3, '小吴', NULL, 21),
    (4, '小郑', '上海', 23);

INSERT INTO scores (score_id, student_id, course, score) VALUES
    (1, 1, 'SQL', 88.00),
    (2, 1, 'Python', 92.00),
    (3, 2, 'SQL', 75.00),
    (4, 3, 'SQL', NULL),
    (5, 4, 'Python', 81.00);
```

## 类型怎么选

- `INT` 保存整数，例如编号、年龄。
- `VARCHAR(30)` 保存最长 30 个字符的变长文本。具体长度由业务需求决定。
- `DECIMAL(5,2)` 适合需要精确十进制表示的分数或金额：总共最多 5 位数字，小数点后 2 位。
- `DATE` 保存日期，`DATETIME` 保存日期和时间。
- `NULL` 表示缺失或未知，不是数字 0，也不是空字符串 `''`。

DESCRIBE students;
SELECT * FROM students;
