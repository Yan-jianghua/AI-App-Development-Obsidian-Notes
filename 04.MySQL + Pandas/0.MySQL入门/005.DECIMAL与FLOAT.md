# DECIMAL与FLOAT

## 是什么

DECIMAL保存十进制精确数，FLOAT和DOUBLE保存近似二进制浮点数。

## 何时用、怎么做

金额用DECIMAL并约定精度和舍入规则，测量数据可按误差容忍度选浮点。

## 易错点与验收

跨 SQL 和 Python 传递金额时使用 Decimal，测试 0.1 加 0.2 与边界舍入。
