# 聚合函数与 `GROUP BY`

## 聚合是什么

把多行概括成一个结果：`COUNT` 计数，`SUM` 求和，`AVG` 平均，`MIN` 最小，`MAX` 最大。

```sql
SELECT COUNT(*) AS total_rows,
       COUNT(score) AS known_scores,
       AVG(score) AS average_score
FROM scores;
```

本例 `COUNT(*) = 5`，`COUNT(score) = 4`。后者跳过 `score IS NULL`；`AVG(score)` 也只对 4 个非空分数求平均，结果为 84。不要把未知分数误当 0。

## 按组统计

```sql
SELECT course,
       COUNT(*) AS record_count,
       COUNT(score) AS known_count,
       ROUND(AVG(score), 2) AS avg_score
FROM scores
GROUP BY course;
```

这相当于“先按课程分堆，再分别统计”。SQL 课程有 3 条记录，但只有 2 条已知分数，平均 81.50；Python 课程有 2 条，平均 86.50。

## 容易错在哪

- `COUNT(*)` 数行；`COUNT(column)` 数该列非空值。
- 分组结果里，非聚合字段通常应是分组字段；不要随意挑一列来显示。MySQL 默认启用 `ONLY_FULL_GROUP_BY` 时也会检查这一点。
- `GROUP BY` 不保证输出顺序，需要时再加 `ORDER BY`。
