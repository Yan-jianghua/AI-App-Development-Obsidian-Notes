# `NULL` 与条件组合

## `NULL` 是什么

`NULL` 表示“目前不知道/没有值”。与普通值比较不会得到常规的真或假，而是未知，所以不能用 `= NULL` 找缺失值。

```sql
SELECT name FROM students WHERE city IS NULL;     -- 小吴
SELECT name FROM students WHERE city IS NOT NULL; -- 其余三人
```

`WHERE city = NULL` 查不出小吴。判断缺失必须用 `IS NULL`。

## 组合条件

```sql
SELECT name FROM students
WHERE city = '上海' AND age >= 21; -- 小郑

SELECT name FROM students
WHERE city = '上海' OR age >= 21;  -- 小林、小周、小吴、小郑
```

`AND` 两边都满足才留下；`OR` 至少满足一边。混用时加括号，表达你的真正意思：

```sql
WHERE (city = '上海' OR city = '北京') AND age >= 21
```

## 三值逻辑的直觉

对于小吴，`city = '上海'` 不是 `FALSE`，而是 `UNKNOWN`。`WHERE` 只保留条件为 `TRUE` 的行。因此仅写 `city <> '上海'` 也不会包括小吴。若业务想包含缺失城市，要明确写：

```sql
WHERE city <> '上海' OR city IS NULL
```

> `NULL` 不等于 0，也不等于空字符串；查缺失用 `IS NULL`。
