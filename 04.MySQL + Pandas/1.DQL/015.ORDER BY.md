# ORDER BY

## 含义

按照指定表达式排序结果，分页时应提供确定的并列排序键。

## 最小用法

`SELECT id FROM users ORDER BY created_at DESC, id DESC`

## 易错点

没有唯一尾键时翻页可能漏行或重复。
