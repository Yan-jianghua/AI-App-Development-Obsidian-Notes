# `DISTINCT` 与 `CASE`

## `DISTINCT`：只看不重复的值

```sql
SELECT DISTINCT city
FROM students;
```

结果有上海、北京和 `NULL` 三种城市状态；这里把缺失作为一个不同的结果展示。`DISTINCT` 作用于 **SELECT 后面的整组列**，例如 `SELECT DISTINCT city, age` 去重的是“城市 + 年龄”组合，而不是分别给两列去重。

想知道已知城市有几种：

```sql
SELECT COUNT(DISTINCT city) AS known_city_count
FROM students;
-- 2，COUNT 不把 NULL 算作已知城市
```

## `CASE`：按条件产生新列

```sql
SELECT name, age,
       CASE
           WHEN age >= 22 THEN '22岁及以上'
           ELSE '22岁以下'
       END AS age_group
FROM students;
```

按顺序检查 `WHEN`，命中第一个条件后给出对应值；都没命中则用 `ELSE`。若省略 `ELSE`，都不匹配时会得到 `NULL`。

处理未知分数时要明确业务含义：

```sql
SELECT score,
       CASE
           WHEN score IS NULL THEN '未录入'
           WHEN score >= 60 THEN '及格'
           ELSE '未及格'
       END AS status
FROM scores;
```

这比把未知分数归到“未及格”更准确。`CASE` 只改变查询输出，不会修改表中原值。
