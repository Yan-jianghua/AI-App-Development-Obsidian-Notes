# 子查询与 CTE

## 子查询：把查询结果交给外层

找出分数高于所有已知成绩平均值的成绩：

```sql
SELECT student_id, course, score
FROM scores
WHERE score > (SELECT AVG(score) FROM scores);
```

内层平均分是 84；外层留下 88 和 92。内层查询返回一个值，适合写在比较条件右侧。

## CTE：先给中间结果起名字

```sql
WITH course_average AS (
    SELECT course, AVG(score) AS avg_score
    FROM scores
    GROUP BY course
)
SELECT course, avg_score
FROM course_average
WHERE avg_score >= 85;
```

`WITH` 定义的 `course_average` 只在这条 SQL 中有效。这里结果为 Python 课程。步骤较多时，CTE 比层层嵌套更容易读。

## 选用原则

一步就能说清的条件可用普通子查询；需要拆成“先算 A，再用 A 算 B”的多步查询，可用 CTE。它们是组织查询的方式，不意味着必然更快。性能要看实际执行计划。
