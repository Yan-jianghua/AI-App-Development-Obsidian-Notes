# `ORDER BY` 与 `LIMIT`

## 排序

```sql
SELECT name, age
FROM students
ORDER BY age DESC, student_id ASC;
```

先按年龄从大到小；若年龄相同，再按编号从小到大。`ASC` 升序，`DESC` 降序。未写 `ORDER BY` 时，不要依赖数据库碰巧返回的行顺序。

## 只取几行

```sql
SELECT name, age
FROM students
ORDER BY age DESC, student_id ASC
LIMIT 2;
-- 小郑 23 岁，小周 22 岁
```

分页可以用 `LIMIT 2 OFFSET 2`，表示跳过前两行，再取两行。**先确定排序，再分页**，否则每页内容可能不稳定。用于排序的字段若会重复，补上唯一编号更稳妥。

## 容易错在哪

- `LIMIT 2` 指两行，不代表 `student_id <= 2`。
- `WHERE` 写在 `ORDER BY` 前面。
- 大表翻到很靠后的页面时，较大的 `OFFSET` 可能变慢；真实业务常改用“记住上一页最后一个排序键”继续查。
