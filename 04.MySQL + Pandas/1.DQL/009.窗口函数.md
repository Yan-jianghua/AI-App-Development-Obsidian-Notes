# 窗口函数：保留明细的同时计算排名

## 与 `GROUP BY` 的区别

`GROUP BY course` 会把每门课的多条成绩收成一行；窗口函数可以给每条成绩附加“所在课程内的排名”，原始明细仍保留。

```sql
SELECT course, student_id, score,
       ROW_NUMBER() OVER (
           PARTITION BY course
           ORDER BY score DESC, score_id ASC
       ) AS row_num
FROM scores;
```

`PARTITION BY course` 表示每门课程单独编号；`ORDER BY` 决定课程内部的顺序。加入唯一的 `score_id` 是为了分数相同也有稳定顺序。`ROW_NUMBER()` 会给每行不同编号；未知分数仍有一行，排序位置受 MySQL 的空值排序规则影响。

## 每门课取最高的一条已知成绩

```sql
WITH ranked AS (
    SELECT course, student_id, score,
           ROW_NUMBER() OVER (
               PARTITION BY course
               ORDER BY score DESC, score_id ASC
           ) AS rn
    FROM scores
    WHERE score IS NOT NULL
)
SELECT course, student_id, score
FROM ranked
WHERE rn = 1;
```

结果为 Python 课程的小林 92 分、SQL 课程的小林 88 分。先排除未知分数，是为了让“最高分”只在已知成绩中产生。

## 易错点

窗口函数算出的别名不能直接在同一层查询的 `WHERE` 中过滤；先放进 CTE 或子查询，再在外层 `WHERE rn = 1`。若并列第一都要保留，应考虑 `RANK()` 或 `DENSE_RANK()`，而不是 `ROW_NUMBER()`。

参考：[MySQL 窗口函数官方说明](https://dev.mysql.com/doc/refman/8.4/en/window-functions-usage.html)。
