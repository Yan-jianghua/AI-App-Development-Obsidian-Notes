# SELECT

## 含义

选择要返回的列或表达式，列名应由受信任的查询构造器确定。

## 最小用法

`SELECT id, name FROM users`

## 易错点

不要默认 SELECT 星号，核对列顺序和敏感字段是否泄漏。

## 检查自己是否掌握

改动示例中的一个输入或条件，预测结果，再用真实环境核对。解释这个术语与同章节相邻术语的区别。
