# `SELECT` 与 `WHERE`

## 是什么

`SELECT` 决定要展示哪些列；`FROM` 指定从哪张表读；`WHERE` 决定保留哪些行。

```sql
SELECT name, age
FROM students
WHERE age >= 21;
```

结果包含小周、小吴、小郑，不包含 20 岁的小林。列只显示姓名和年龄。

## 常见条件

```sql
SELECT * FROM students WHERE city = '上海';
SELECT * FROM students WHERE age BETWEEN 20 AND 22; -- 包含 20 和 22
SELECT * FROM students WHERE city IN ('上海', '北京');
SELECT * FROM students WHERE name LIKE '小%';       -- % 表示任意长度字符
SELECT * FROM students WHERE name LIKE '小_';       -- _ 表示恰好一个字符
```

`SELECT *` 适合探索小表；正式查询最好写出所需列，读起来更明确，也能避免取出不需要的数据。

## 容易错在哪

- SQL 判断相等用 `=`，不写 Python 的 `==`。
- 文本值用单引号，例如 `'上海'`。
- `BETWEEN` 两端都包含。
- `LIKE` 的 `%` 与 `_` 是通配符；是否区分大小写还受字符集/排序规则影响。

## 小练习

查出年龄大于等于 21 的上海学生。先写条件，再预测有几行。

```sql
SELECT name, age FROM students
WHERE age >= 21 AND city = '上海';
-- 结果：小郑 1 行
```
