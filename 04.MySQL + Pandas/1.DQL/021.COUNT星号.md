# `COUNT(*)`

## 含义

COUNT(*) 统计组内所有行，包括某些列为 NULL 的行。

## 最小用法

`SELECT COUNT(*) FROM users`

## 易错点

与 COUNT(column) 对照测试含 NULL 的记录。
