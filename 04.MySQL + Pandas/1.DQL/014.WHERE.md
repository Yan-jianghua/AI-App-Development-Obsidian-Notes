# WHERE

## 含义

在分组之前过滤单行，条件结果为 TRUE 的行才保留。

## 最小用法

`SELECT id FROM users WHERE active = 1`

## 易错点

NULL 条件不会按普通真假值工作，要另测 IS NULL。

## 检查自己是否掌握

改动示例中的一个输入或条件，预测结果，再用真实环境核对。解释这个术语与同章节相邻术语的区别。
