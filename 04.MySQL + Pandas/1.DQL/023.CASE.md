# CASE

## 含义

SQL 条件表达式，适合把有限业务规则映射为派生列。

## 最小用法

`SELECT CASE WHEN score >= 60 THEN 'pass' ELSE 'fail' END FROM exams`

## 易错点

多条件顺序影响结果，应测临界值。

## 检查自己是否掌握

改动示例中的一个输入或条件，预测结果，再用真实环境核对。解释这个术语与同章节相邻术语的区别。
