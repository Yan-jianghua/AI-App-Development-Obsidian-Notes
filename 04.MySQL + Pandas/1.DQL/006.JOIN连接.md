# `JOIN` 连接两张表

## 为什么连接

`scores` 只有 `student_id`，要看到姓名，就根据两表共同的编号连接。

```sql
SELECT s.name, c.course, c.score
FROM students AS s
INNER JOIN scores AS c
    ON s.student_id = c.student_id;
```

一条成绩对应一个学生，所以结果是 5 行。`s`、`c` 是表别名；写 `s.student_id` 可分清来自哪张表。

## `INNER JOIN` 与 `LEFT JOIN`

- `INNER JOIN`：只保留两边能配对的记录。
- `LEFT JOIN`：左表的记录全部保留；右表没配对时，右表列为 `NULL`。

想查“包括尚无成绩的所有学生”：

```sql
SELECT s.name, c.course, c.score
FROM students AS s
LEFT JOIN scores AS c
    ON s.student_id = c.student_id;
```

当前练习数据里每位学生至少有一条成绩，可自己加一位新学生观察差别。

## 重要陷阱

在 `LEFT JOIN` 后写 `WHERE c.course = 'SQL'`，右表未匹配的行会被过滤掉。若想保留所有学生，并仅匹配 SQL 课程，应把课程条件放进 `ON`：

```sql
SELECT s.name, c.score
FROM students AS s
LEFT JOIN scores AS c
  ON s.student_id = c.student_id AND c.course = 'SQL';
```

此时没有 SQL 成绩的小郑仍会出现，`c.score` 为 `NULL`。另一个陷阱是忘写连接条件，造成行数猛增。
