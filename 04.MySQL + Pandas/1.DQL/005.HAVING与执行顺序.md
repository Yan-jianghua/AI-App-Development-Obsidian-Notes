# `WHERE`、`HAVING` 与查询顺序

## 两者区别

`WHERE` 在分组前筛选原始行；`HAVING` 在分组后筛选组。

```sql
SELECT course, AVG(score) AS avg_score
FROM scores
WHERE score IS NOT NULL
GROUP BY course
HAVING AVG(score) >= 85;
-- 只留下 Python 课程
```

若写 `WHERE AVG(score) >= 85`，会出错：原始行还没有“课程平均分”。

## 怎么理解执行过程

书写顺序是 `SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT`，理解结果时可先想：

```text
FROM 找数据
→ WHERE 过滤行
→ GROUP BY 分组
→ HAVING 过滤组
→ SELECT 选择和计算输出列
→ ORDER BY 排序
→ LIMIT 截取
```

这是帮助理解的逻辑顺序；数据库实际物理执行计划可能不同。

## 常见问题

筛选“SQL 课程的分数记录”用 `WHERE course = 'SQL'`；筛选“平均分大于 85 的课程”用 `HAVING AVG(score) > 85`。能在分组前过滤的条件，通常放 `WHERE` 更清楚。
