# LIKE与通配符

## 是什么

LIKE 用百分号匹配任意长度，用下划线匹配单个字符，匹配还受到排序规则影响。

## 何时用、怎么做

把用户输入当数据绑定参数，并明确要做前缀、包含还是精确匹配。

## 易错点与验收

前置百分号往往难以利用普通 B 树索引，检查 EXPLAIN 和真实数据量。
