# `INSERT` 新增数据

## 基本写法

明确写列名，避免以后表增加列时插入值错位：

```sql
INSERT INTO students (student_id, name, city, age)
VALUES (5, '小陈', '杭州', 19);
```

一次插入多行：

```sql
INSERT INTO courses (course_id, course_name, credits)
VALUES (1, 'SQL', 2), (2, 'Python', 3);
```

检查刚写入的数据：

```sql
SELECT * FROM students WHERE student_id = 5;
```

## 常见报错怎么理解

- “Duplicate entry”：主键或唯一约束重复。先查询该编号/名称，判断是误重复，还是应更新已有记录。
- “Cannot add or update a child row”：外键引用的父表行不存在。写成绩前，先确认学生存在。
- “Column ... cannot be null”：必填列缺值。

不要为“让语句成功”随意去掉约束。约束往往是在提醒数据与业务规则矛盾。

## 练习

若已插入编号 5，再执行同一条 `INSERT` 会发生什么？预期是主键冲突，原有记录不会被第二条普通 `INSERT` 替换。
