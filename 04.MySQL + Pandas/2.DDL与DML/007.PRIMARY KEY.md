# PRIMARY KEY

## 含义

主键标识表中每一行且不能为 NULL。

## 最小用法

`CREATE TABLE users (id BIGINT PRIMARY KEY)`

## 易错点

业务标识可另加 UNIQUE，不要假定自增 ID 能去重业务请求。
