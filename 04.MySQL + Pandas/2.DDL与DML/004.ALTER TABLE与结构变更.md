# `ALTER TABLE` 修改表结构

## 常见操作

给学生表增加邮箱列：

```sql
ALTER TABLE students
ADD COLUMN email VARCHAR(100);
```

查看结果：

```sql
DESCRIBE students;
```

删除练习列：

```sql
ALTER TABLE students
DROP COLUMN email;
```

## 修改结构前想什么

- 新加 `NOT NULL` 列时，旧行怎么填？可以先允许空值，补齐旧数据后再收紧约束，或给合适默认值。
- 改字段类型时，现有值能否无损转换？例如把很长的文本改短，可能失败或截断。
- 给大表改结构可能耗时并影响使用，应先在测试环境验证，安排迁移过程。

`CREATE`、`ALTER`、`DROP` 等 DDL 在 MySQL 中有隐式提交行为，不能假定包在普通事务里就能像 DML 一样回滚。实际操作前请查对应版本文档并准备备份/迁移方案。
