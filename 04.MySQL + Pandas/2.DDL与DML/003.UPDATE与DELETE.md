# `UPDATE` 与 `DELETE`

## 先查，再改

```sql
SELECT student_id, name, age
FROM students
WHERE student_id = 2;

UPDATE students
SET age = 23
WHERE student_id = 2;

SELECT student_id, name, age
FROM students
WHERE student_id = 2;
```

`WHERE` 用主键锁定一行。省略 `WHERE` 会更新整张表的所有行。

## 删除行

```sql
SELECT * FROM students WHERE student_id = 5;
DELETE FROM students WHERE student_id = 5;
```

若编号 5 的学生在 `scores` 中被外键引用，直接删除可能失败；这是数据库在保护关联关系。先明确业务希望“禁止删除”“先删成绩”还是“级联删除”，不要盲目关掉外键检查。

## 安全操作习惯

1. 用相同的 `WHERE` 先 `SELECT`，核对影响哪些行。
2. 重要修改放进事务，确认后 `COMMIT`，发现错了 `ROLLBACK`。见 [[001.事务与提交回滚]]。
3. 改完后再次 `SELECT` 验证结果。

## 区别

`DELETE FROM students WHERE ...` 删除满足条件的行；`DROP TABLE students` 删除表及其结构。两者后果完全不同。
