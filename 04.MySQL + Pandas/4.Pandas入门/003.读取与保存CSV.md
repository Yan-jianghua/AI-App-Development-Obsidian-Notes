# 读取与保存 CSV

## 基本流程

CSV 是用分隔符组织的文本文件，不保存 DataFrame 的所有类型信息。已得到 [[002.构造练习数据]] 的 `students` 后，可试：

```python
students.to_csv("students.csv", index=False, encoding="utf-8-sig")
loaded = pd.read_csv("students.csv", encoding="utf-8-sig")
print(loaded.head())
print(loaded.dtypes)
```

`index=False` 表示不额外把 Pandas 行索引写成一列。`utf-8-sig` 有时便于电子表格软件识别中文；只在 Python 间交换文件，普通 `utf-8` 也常用。

## 为什么重新读取后要检查

CSV 没有严格类型元数据。日期可能被读为字符串，编号可能被读为数字，空白可能被读为缺失值。导入后用 `dtypes`、`head()`、`isna().sum()` 核对。若编号的前导零有意义，读取时可明确指定 `dtype={"student_id": "string"}`。

## 文件路径

`"students.csv"` 表示当前工作目录中的文件。找不到文件时先检查：

```python
from pathlib import Path
print(Path.cwd())
```
