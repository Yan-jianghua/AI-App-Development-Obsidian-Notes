# `Series` 与 `DataFrame`

## 先记住形状

- `Series`：一维数据，通常像“带索引的一列”。
- `DataFrame`：二维表格，有行索引和列名。一个 DataFrame 可以包含多列不同类型的数据。

```python
import pandas as pd

ages = pd.Series([20, 22, 21], name="age")
print(ages)

students = pd.DataFrame({
    "name": ["小林", "小周", "小吴"],
    "age": [20, 22, 21],
})
print(students)
```

`students["age"]` 返回一列，类型是 `Series`；`students[["age"]]` 用双层方括号指定列名列表，返回仍为 `DataFrame`。这一点会影响后续方法的输入形状。

## 行索引不是数据库主键

默认索引通常是 `0, 1, 2, ...`，它是 Pandas 给行贴的标签，不自动等于业务编号。真正的 `student_id` 应明确保留为一列。筛选或删除行后，索引可能不连续；不连续也不代表数据有错。
