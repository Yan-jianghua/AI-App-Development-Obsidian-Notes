# 构造练习数据

下面的数据与 MySQL 的 [[003.练习数据与字段类型]] 对应。每次打开新的 Python 会话或 Notebook 内核，先运行这段代码。

```python
import pandas as pd

students = pd.DataFrame({
    "student_id": [1, 2, 3, 4],
    "name": ["小林", "小周", "小吴", "小郑"],
    "city": ["上海", "北京", None, "上海"],
    "age": [20, 22, 21, 23],
})

scores = pd.DataFrame({
    "score_id": [1, 2, 3, 4, 5],
    "student_id": [1, 1, 2, 3, 4],
    "course": ["SQL", "Python", "SQL", "SQL", "Python"],
    "score": [88.0, 92.0, 75.0, None, 81.0],
})

print(students)
print(scores)
```

## 两个缺失值

小吴的 `city` 不知道；小吴的 SQL 分数也不知道。Pandas 会把这些位置识别为缺失值。数字列里出现缺失值时，默认常会显示为 `NaN`，具体底层类型随列类型和 Pandas 版本变化。

## 验证

```python
print(students.shape)  # (4, 4)：4 行 4 列
print(scores.shape)    # (5, 4)：5 行 4 列
```
