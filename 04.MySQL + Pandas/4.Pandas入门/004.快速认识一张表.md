# 快速认识一张表

先运行 [[002.构造练习数据]]。拿到一份新数据时，不要马上开始复杂统计，先问“有多少行列、各列是什么类型、有没有缺失值”。

```python
print(students.shape)         # 行数、列数
print(students.columns)       # 列名
print(students.head(3))       # 前 3 行
print(students.tail(2))       # 后 2 行
students.info()               # 类型、非空数量、内存概览
print(students.isna().sum())   # 每列缺失数量
```

`head()` 只是抽样查看，不能证明整表都干净。`describe()` 可快速给出数值列的数量、均值、标准差、分位数；它也不能代替理解业务含义。

```python
print(scores["score"].describe())
```

这列只有 4 个非空分数，所以 `count` 是 4，不是 5。其均值是 84。

## 建议检查清单

1. 列名有没有多余空格或拼写不一致？
2. 编号是否被错误读成小数或日期？
3. 缺失值代表未知、未发生，还是录入错误？
4. 是否存在同一业务记录重复多次？
