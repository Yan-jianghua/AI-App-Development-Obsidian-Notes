# 从 MySQL 读取到 Pandas

## 使用场景

MySQL 保存原始记录；Pandas 读取一小段需要分析的数据。先让 SQL 筛选所需行列，再在 Python 中继续处理，通常比把整张大表无条件读进内存更合适。

## 准备

在自己的 Python 环境安装 Pandas、SQLAlchemy 和 PyMySQL：

```bash
python -m pip install pandas sqlalchemy pymysql
```

数据库连接信息放在环境变量中，例如 `DB_USER="你的数据库用户名"`、`DB_PASSWORD="你的数据库密码"`、`DB_HOST="你的数据库IP或域名"`、`DB_NAME="你的数据库名"`；这里的双引号中文是待替换示意值，实际应由本机环境变量提供。不要在笔记或 Git 仓库写真实密码。示例假定目标库已有 [[003.练习数据与字段类型]] 的表。

## 参数化读取

```python
import os
import pandas as pd
from sqlalchemy import create_engine, text
from sqlalchemy.engine import URL

url = URL.create(
    "mysql+pymysql",
    username=os.environ["DB_USER"],
    password=os.environ["DB_PASSWORD"],
    host=os.environ["DB_HOST"],
    database=os.environ.get("DB_NAME", "learning_lab"),
)
engine = create_engine(url)

query = text("""
    SELECT student_id, course, score
    FROM scores
    WHERE course = :course
""")

try:
    with engine.connect() as connection:
        sql_scores = pd.read_sql(
            query, connection, params={"course": "SQL"}
        )
    print(sql_scores)
finally:
    engine.dispose()
```

`:course` 是参数占位符，参数值通过 `params` 单独传入。不要把用户输入用 f-string 拼进 SQL。`URL.create` 也能避免密码中含特殊字符时手工拼接连接地址出错。

## 读取后检查

```python
print(sql_scores.shape)
print(sql_scores.dtypes)
print(sql_scores.isna().sum())
```

预计有 3 条 SQL 课程记录，其中 1 条分数缺失。`DECIMAL` 读入 Pandas 后可能被转换为浮点数；涉及金额等高精度数据时，注意 `read_sql` 的类型转换选项并核对结果。

参考：[Pandas `read_sql`](https://pandas.pydata.org/docs/reference/api/pandas.read_sql.html)、[SQLAlchemy MySQL 方言](https://docs.sqlalchemy.org/en/20/dialects/mysql.html)。
