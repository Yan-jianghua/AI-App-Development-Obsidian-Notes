## 题 1：找出城市未知的学生

要求分别用 SQL 和 Pandas 写。

<details><summary>答案与解释</summary>

```sql
SELECT student_id, name FROM students WHERE city IS NULL;
```

```python
students.loc[students["city"].isna(), ["student_id", "name"]]
```

结果是小吴。`= NULL` 和 `== None` 都不是这里推荐的缺失判断。

</details>

## 题 2：每门课已知分数有几条？

<details><summary>答案与解释</summary>

```sql
SELECT course, COUNT(score) AS known_count
FROM scores GROUP BY course;
```

```python
scores.groupby("course")["score"].count()
```

Python 为 2，SQL 为 2；SQL 课程还有一条分数未知的记录，所以它的总记录数为 3。

</details>

## 题 3：为什么成绩表连接学生表后可能从 5 行变成 10 行？

<details><summary>答案与解释</summary>

最常见原因是学生表里的 `student_id` 不唯一：成绩表中一行可能匹配右表多行。先检查右表键是否重复；Pandas 可用 `validate="many_to_one"`，MySQL 可在学生编号上设主键。

</details>

## 题 4：未知分数填 0 后平均数为什么改变？

<details><summary>答案与解释</summary>

原本 4 个已知分数之和为 336，均值是 `336 / 4 = 84`。填 0 后变成 5 个数，均值为 `336 / 5 = 67.2`。填 0 改变了统计问题，只有“未知代表零分”时才合理。

</details>
