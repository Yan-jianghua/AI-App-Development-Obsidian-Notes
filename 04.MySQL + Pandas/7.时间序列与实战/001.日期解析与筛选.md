# 日期解析与筛选

## 为什么要转换

字符串看起来像日期，也不一定能直接做日期计算。先解析为日期时间类型：

```python
import pandas as pd

visits = pd.DataFrame({
    "day": ["2026-09-01", "2026-09-02", "2026-09-04"],
    "count": [10, 13, 8],
})
visits["day"] = pd.to_datetime(visits["day"], format="%Y-%m-%d")
print(visits.dtypes)
```

## 取时间范围

```python
start = pd.Timestamp("2026-09-02")
end = pd.Timestamp("2026-09-04")
selected = visits.loc[visits["day"].between(start, end)]
print(selected)  # 9 月 2 日和 9 月 4 日
```

`between` 默认包含边界；要做“左闭右开”的月份范围，可写 `>= 月初` 且 `< 下月月初`。

## 计算间隔

```python
visits = visits.sort_values("day")
visits["days_since_previous"] = visits["day"].diff().dt.days
```

首行没有前一天记录，差值为缺失。9 月 4 日与上条 9 月 2 日相隔 2 天。

## 容易错在哪

带时区与不带时区的时间不能随意混用。跨地区业务要先约定保存和展示时区；只表示日历日期时，确认是否真的需要精确到时分秒。
