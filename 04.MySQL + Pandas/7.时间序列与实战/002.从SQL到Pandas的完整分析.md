# 从 SQL 到 Pandas 的完整分析

## 目标

回答：“每门课程有多少条成绩、多少条已知分数、平均分多少？”先用数据库做，再用 Pandas 对同一口径复算。

## MySQL 查询

确保已运行 [[003.练习数据与字段类型]]：

```sql
SELECT course,
       COUNT(*) AS record_count,
       COUNT(score) AS known_count,
       ROUND(AVG(score), 2) AS avg_score
FROM scores
GROUP BY course
ORDER BY course;
```

预期：Python 为 `2 / 2 / 86.50`；SQL 为 `3 / 2 / 81.50`。

## Pandas 复算

先运行 [[002.构造练习数据]]：

```python
result = (
    scores.groupby("course", as_index=False)
    .agg(
        record_count=("score_id", "size"),
        known_count=("score", "count"),
        avg_score=("score", "mean"),
    )
    .sort_values("course")
)
result["avg_score"] = result["avg_score"].round(2)
print(result.to_string(index=False))
```

## 如何判断结果可信

两边数据必须来自相同版本、相同筛选条件；否则数字不同可能只是输入不同。再核对总记录数是 5、已知分数数是 4、分组后两组记录数之和仍是 5。

真实项目中可先让数据库完成过滤/聚合，再将需要的小结果集载入 Pandas；别把整张大表无条件读入内存。
