# MySQL 与 Pandas 操作对照

以下 Pandas 语句先运行 [[002.构造练习数据]]。两边概念相似，但**缺失值、连接键、排序和返回类型**等细节并不完全相同。

| 目标 | MySQL | Pandas |
|---|---|---|
| 选两列 | `SELECT name, age FROM students` | `students[["name", "age"]]` |
| 筛年龄 | `WHERE age >= 21` | `students.loc[students["age"] >= 21]` |
| 按年龄降序 | `ORDER BY age DESC` | `sort_values("age", ascending=False)` |
| 取前两行 | `LIMIT 2` | `head(2)`，先明确排序 |
| 查城市缺失 | `city IS NULL` | `students["city"].isna()` |
| 按课程算均分 | `GROUP BY course; AVG(score)` | `scores.groupby("course")["score"].mean()` |
| 按学生编号连接 | `JOIN ... ON ...` | `scores.merge(students, on="student_id")` |

## 怎么选工具

需要持久化、多用户访问、事务和约束时，用数据库；要在 Python 中探索、清洗、制作中间分析结果时，用 Pandas。常见流程是 MySQL 先筛选所需数据，再交给 Pandas 做分析。

## 两个差异要记住

1. SQL 查询**不写 `ORDER BY` 就不保证顺序**；Pandas 当前 DataFrame 有可见的行顺序，但操作后仍要明确排序规则。
2. SQL 的 `NULL` 不会通过普通等值连接互相匹配；Pandas `merge` 的空键可能匹配。两边结果不同时，先检查缺失连接键。
