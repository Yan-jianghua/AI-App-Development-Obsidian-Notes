# 统计结果核对

## 为什么核对

代码能运行不代表分析正确。筛选、去重、合并都可能悄悄改变行数或口径。最简单的核对办法是固定几个已知事实。

```python
assert len(students) == 4
assert len(scores) == 5
assert scores["score"].notna().sum() == 4
assert scores["score"].mean() == 84
```

## 连接前后

```python
detail = scores.merge(
    students[["student_id", "name"]],
    on="student_id",
    how="left",
    validate="many_to_one",
)
assert len(detail) == len(scores)
assert detail["name"].notna().all()
```

这里的断言只适用于本例的前提：每条成绩有合法学生编号，学生表编号唯一。换真实数据时，先写清你的前提，再设计检查。

## 三个核对问题

1. 输入多少行，输出多少行，为什么变化？
2. 缺失值参与统计了吗？`size` 和 `count` 是否符合口径？
3. 连接键是否唯一、是否有未匹配数据？

检查是为了尽早发现数据口径错误，而不只是排除 Python 报错。
