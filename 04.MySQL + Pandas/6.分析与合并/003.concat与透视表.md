# `concat` 与透视表

## `concat`：把相同结构的数据接起来

例如两批成绩列名相同，可纵向拼接：

```python
first = scores.iloc[:3]
second = scores.iloc[3:]
combined = pd.concat([first, second], ignore_index=True)
print(len(combined))  # 5
```

`concat` 按轴拼接，不会自动根据 `student_id` 配对。要按键关联两张不同结构的表，使用 `merge`。

## 透视表：把长表变宽表

```python
wide = scores.pivot_table(
    index="student_id",
    columns="course",
    values="score",
    aggfunc="mean",
)
print(wide)
```

原来每行是一条“学生 + 课程 + 分数”；现在每行是一名学生，课程变成列。小吴的 SQL 分数为空，他的整行可能不出现在默认透视结果中；需要保留所有学生时，应先明确目标行集合，再连接回 `students`。

## `pivot` 与 `pivot_table`

`pivot` 要求每个“行键 + 列键”组合只有一个值；有重复组合会报错。`pivot_table` 可以通过 `aggfunc` 汇总重复组合。决定用哪一个之前，先核查业务上重复组合是否合理。
