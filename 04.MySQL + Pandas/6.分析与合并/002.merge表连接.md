# `pd.merge()` 表连接

## 把姓名放进成绩表

```python
detail = scores.merge(
    students[["student_id", "name", "city"]],
    on="student_id",
    how="left",
    validate="many_to_one",
    indicator=True,
)
print(detail[["name", "course", "score", "_merge"]])
```

成绩表每个学生可有多行，学生表每个编号只应有一行，因此关系是“多对一”。`validate="many_to_one"` 会在右表编号不唯一时提醒；`indicator=True` 会增加 `_merge` 列，便于检查有没有找不到学生的成绩。当前结果仍是 5 行，全部为 `both`。

## `how` 怎么选

- `inner`：只保留两表都匹配的行。
- `left`：保留左表所有行，右表无匹配的列填缺失。
- `outer`：两侧任一表出现的键都保留。

这里与 SQL 的 `JOIN` 相似，见 [[006.JOIN连接]]。但 Pandas 与 SQL 对**空连接键**的行为可能不同：`merge` 中两边空键可能互相匹配；SQL 的 `NULL = NULL` 不成立。连接前应检查键是否缺失。

## 连接后必须核对

```python
print(len(scores), len(detail))
print(detail["_merge"].value_counts())
```

行数突然增多，通常意味着某侧连接键重复，形成多对多匹配。别只看前五行就认定连接正确。
