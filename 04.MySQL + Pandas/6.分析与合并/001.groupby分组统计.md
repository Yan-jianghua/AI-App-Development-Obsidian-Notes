# `.groupby()` 分组统计

## 先分组，再聚合

```python
summary = (
    scores.groupby("course", as_index=False)
    .agg(
        record_count=("score_id", "size"),
        known_count=("score", "count"),
        avg_score=("score", "mean"),
    )
)
print(summary)
```

预期：Python 课程 2 条、已知 2 条、平均 86.5；SQL 课程 3 条、已知 2 条、平均 81.5。

## `size` 和 `count` 区别

- `size` 数该组的行数，包括分数缺失的行。
- `count` 数指定列的非缺失值。
- `mean` 默认跳过缺失分数。

这对应 MySQL 中 `COUNT(*)`、`COUNT(score)` 和 `AVG(score)` 的常见用法，见 [[004.聚合与GROUP BY]]。

## 为什么用 `as_index=False`

默认分组键会进入结果索引；`as_index=False` 让 `course` 保持普通列，便于继续合并或导出。需要索引形式时可使用默认设置。

## 常见坑

按 `city` 分组时，缺失城市组默认可能被排除。若业务想保留这组，可写 `groupby("city", dropna=False)`。统计前先问自己：缺失项是否应成为一组？
