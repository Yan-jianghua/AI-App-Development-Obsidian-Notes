# Agent、工具调用与多智能体测试学习导航

## 本卷目标

这一卷按“一个关键概念一篇、一个重要工具一篇”组织。建议先读核心关键词，再动手运行工具示例，最后把练习组合进综合项目。

## 推荐学习顺序

1. 先理解关键词解决的工程问题。
2. 用每篇的 Given-When-Then 练习写出测试规格。
3. 选择与当前技术栈有关的工具运行最小示例。
4. 把失败样本加入回归数据集。
5. 回到 [[总导航]] 进入下一卷。
