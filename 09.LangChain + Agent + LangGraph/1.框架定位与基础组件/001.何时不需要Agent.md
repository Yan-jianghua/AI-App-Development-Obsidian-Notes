# 何时不需要Agent

## 是什么

Agent 适合需要动态选择工具和多步决策的任务；固定的“检索→生成”流程通常普通函数或确定性工作流更简单。

## 实践步骤

先写出任务状态、分支与工具清单。如果所有路径可事先枚举，就用显式流程；只有存在受控的动态决策需求时再让模型规划。

## 容易错与验收

复杂框架不能自动带来正确性；用完成率、时延、成本和安全失败衡量增益。
