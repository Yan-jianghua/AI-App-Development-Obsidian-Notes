# 多Agent协作边界

## 是什么

多个 Agent 分工可提升可维护性，但角色之间传递的信息也可能失真或重复执行。

## 实践步骤

为每个角色定义职责、输入输出、可用工具和预算；共享事实用结构化证据而非互相转述。设主控负责冲突合并、停止和审批。

## 容易错与验收

没有可衡量收益时优先单 Agent 或固定流水线；测试角色串权、循环对话和信息丢失。
