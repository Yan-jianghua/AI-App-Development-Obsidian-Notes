# Agent轨迹评测

## 是什么

只评价最终答案会漏掉工具越权、无效循环和高成本路径；Agent 应评测完整执行轨迹。

## 实践步骤

样本包含初始状态、允许工具、期望中间检查点、最终答案和禁止动作。统计任务完成率、工具参数正确率、无效步骤、人工接管、成本和恢复成功率。

## 容易错与验收

加入恶意网页、工具失败、重复消息与模型偏离计划；安全违规不应被总分平均掉。
