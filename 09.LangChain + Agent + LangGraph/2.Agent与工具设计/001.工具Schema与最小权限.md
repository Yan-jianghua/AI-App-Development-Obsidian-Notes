# 工具Schema与最小权限

## 是什么

模型给出的工具名和参数是不可信建议，工具执行前仍需应用验证权限、类型和业务规则。

## 实践步骤

工具声明参数 Schema、超时、速率、可重试性和副作用等级；只暴露任务必需能力。读操作与写操作分开，高影响写操作强制审批。

## 容易错与验收

测试越权参数、路径穿越、注入文本、重复动作与工具响应伪造。
