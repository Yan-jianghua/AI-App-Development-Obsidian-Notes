# 计划与停止条件

## 是什么

Agent 规划把目标拆成动作，但规划过程可能循环或不断扩大范围，必须预设步数、时间和费用上限。

## 实践步骤

每一步记录目标、候选动作、选择理由、结果与下一状态；失败时可重试、替代或停止。明确“证据不足”“需人工判断”“预算耗尽”三类终止。

## 容易错与验收

测试重复搜索、无结果、互相矛盾和模型输出非法动作，不能让循环继续耗费 token。
