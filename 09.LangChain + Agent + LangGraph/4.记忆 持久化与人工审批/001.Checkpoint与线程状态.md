# Checkpoint与线程状态

## 是什么

Checkpoint 保存执行点与状态，使长任务重启、暂停、人工审批后能够恢复。会话记忆和可恢复执行状态是两个不同概念。

## 实践步骤

持久化流程版本、任务 ID、节点状态、工具结果引用与预算；对外部副作用配幂等键。恢复时检查旧状态与新代码兼容。

## 容易错与验收

故障注入运行中断与重复投递；恢复不能重复退款、发邮件或采集同一来源。
