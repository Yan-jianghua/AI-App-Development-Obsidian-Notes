# 节点边与条件路由

## 是什么

节点做一项明确工作，边定义固定或条件迁移；控制流应显式可观察。

## 实践步骤

把检索、验证、生成、审批分节点，节点输出结构化结果；条件路由根据可验证状态而非自由文本猜测。错误路径进入补偿或人工处理。

## 容易错与验收

测试每条边、异常分支、循环上限和不可达状态；隐藏在 Prompt 里的路由规则难以验证。
