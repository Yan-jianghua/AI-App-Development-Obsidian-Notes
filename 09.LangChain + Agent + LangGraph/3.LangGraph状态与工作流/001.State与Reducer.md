# State与Reducer

## 是什么

有状态工作流的 State 是节点之间传递的业务事实；Reducer 决定并行节点更新同一字段时如何合并。

## 实践步骤

状态字段区分不可变输入、累积消息、当前步骤、证据、预算与审批信息。合并规则应幂等、确定且可测试；不要把敏感原文无限追加。

## 容易错与验收

测试并行更新顺序、重复事件和版本升级后的状态兼容；只靠全局字典会在多进程中丢状态。
